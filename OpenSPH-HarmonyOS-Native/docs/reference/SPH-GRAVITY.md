# SPH 材料自引力

> 类型：当前物理参考；适用版本：0.34.0；验证日期：2026-09-08（Asia/Shanghai）。

## 接入范围

岩质碰撞和旋转岩球可选择材料自引力。`sph_gravity.h` 保留原压力／固体应力方程，开启 `ForceEnum::SELF_GRAVITY`，通过固定导入的 OpenSPH `GravitySolver` 和 `BruteForceGravity` 累加加速度。每步更新位置，使用默认三次样条对应的引力软化核与两粒子平滑长度均值，实际 SI 单位计算；未另写视觉吸引效果或修改导入内核。

逐对求和总开销为 O(N²)，首批粒子预算上限为 1200，实际采样数量可能略多。旧实验默认关闭；开启后需要应用参数重新计算。模型身份及保存行为见 [CLI](../CLI.md#sph-材料自引力)。

## 独立数值检查

`tests/sph_gravity.cpp` 用独立 Simpson 球壳密度积分求包围质量，再求引力与势能，不调用生产引力核作为参照。覆盖三种软化尺度、重合点、不同粒子质量／平滑长度、核内外及边界，共 36 个双粒子条件。

鸿蒙实测最大无量纲加速度误差约 1.31×10⁻¹¹，势能误差约 2.22×10⁻¹¹；双粒子归一化动量残差约 1.45×10⁻¹⁶。误差按各条件的 Gm/h²、Gm₁m₂/h 等尺度归一化，不能解释为整场景相对精度。

另一组测试直接调用 `IRun`，建立无自转、无撞击体、半径 100 km、默认玄武岩密度 2700 kg/m³ 的球体。预算 200／600／1200 分别采样为 210／641／1263 粒子；固定步长 0.03125 s 运行 4 s，并比较关闭自引力和开启自引力，以及开启后步长减半。

| 粒子预算 | 细步长平均径向速度 m/s | 粗细步长差 m/s |
| --- | --- | --- |
| 200 | −0.18912295 | 0.00033212 |
| 600 | −0.20009264 | 0.00035478 |
| 1200 | −0.20679650 | 0.00036698 |

关闭时保持静止；开启时向内运动且均方根半径减小。每步检查有限值、质量、动量和质心。桌面与鸿蒙九组数据最大归一化差约 5.67×10⁻¹⁶。原始 [桌面数据](../evidence/gravity-0.34.0-desktop.jsonl)、[鸿蒙数据](../evidence/gravity-0.34.0-emulator.jsonl) 与 [分析](../evidence/gravity-0.34.0-analysis.json) 保留。

## 复现与边界

鸿蒙运行 `scripts/test-sph-gravity-emulator.sh 127.0.0.1:5555`；独立程序只使用临时目录。桌面按 [既有兼容副本流程](SPH-DIAGNOSTICS.md) 编译 `tests/sph_gravity.cpp`，额外包含 `entry/src/main/cpp`，再用 `scripts/analyze-sph-gravity.mjs` 比较两个 JSONL。测试持有默认调度器至进程结束，避免多次创建测试对象时反复销毁临时线程池；本轮桌面首次运行在该销毁路径等待，未将不完整数据算作通过，也未修改上游线程池。

应用验收脚本 `scripts/test-sph-gravity-ui-emulator.mjs` 会改变当前实验及单槽回放，执行前备份。它检查草稿与求解设置分离、非法参数拒绝、16 秒碰撞、回放诊断与模型恢复。

本次不是静力平衡松弛，也不是软化／分辨率收敛证明。没有验证完整引力、弹性和材料能量预算，没有分层行星、碎片辨识或再聚合；环仍为无质量中心力模型。下一步优先建立稳定岩球初态、能量账本与长时稳定性，再推进撞击后结构演化。
