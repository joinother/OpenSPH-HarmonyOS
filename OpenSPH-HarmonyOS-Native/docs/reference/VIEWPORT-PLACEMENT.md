# 主星图放置与碰撞接入

> 类型：当前实现与接入顺序；适用版本：0.42.0；更新日期：2026-09-08（Asia/Shanghai）。

## 已有预研与此前缺口

[Universe Sandbox 博客／论坛研究](../research/UNIVERSE-SANDBOX-BLOG-FORUM-2026-09-07.md) 已讨论预览／确认、母星参考系、初始条件事务、近距保护和点质量到局部 SPH 的转换。预研确实存在，但此前放置仅在面板小图中操作；0.39／0.40 的团块观察没有打通主星图放置与轨道行星撞击。本轮重新调整交付优先级，不把观察工具累计当成完整碰撞完成度。0.42 参考 REBOUND 官方接触检测说明，独立实现球体接触；没有导入新的同行代码。

## 当前可操作流程

自定义系统点“＋ 放置行星”，主视口显示所有已应用初始天体与半透明候选。单指点击／拖动决定位置，双指缩放；箭头表示相对恒星速度方向，长度为便于阅读的显示缩放，不是固定时间内的位移。无关工具栏和时间轴暂时收起。参数抽屉提供质量、倾斜平面、速度、外观及瞄准目标；“返回星图放置”只收起抽屉，“取消”或返回键退出事务。

瞄准按目标初始位置生成直线方向，并叠加恒星的初始速度；它不是对移动目标的拦截解。反向使相对速度背离目标；圆轨道／静止／掠过恢复原有切向模式。瞄准模式不绘制不适用的圆轨道二体引导线。各方式最终仍交给同一多体引力积分器。

候选外观种子在进入放置时固定，复制沿用来源种子；确认保留该种子。月面预览也按需请求已有地图。无效输入移除候选实体，但保留草稿供修正，不显示上一次有效候选冒充当前输入。

## 投影与事务

渲染使用独立、不可变的初始预览帧，不清空 Engine 历史或重建 XComponent。预览中心为母星初始位置。主视口逆投影使用最近实际呈现帧的相机、尺寸与构图，解当前倾斜轨道面两个基向量的投影。近平行／退化视角拒绝移动，提供正对轨道面操作；尺寸变化期间拒绝旧帧坐标。屏幕变化本身不改变候选初值。

进入放置暂停正在运行的实验与回放播放，取消恢复原运行状态、镜头与编辑草稿。确认仍是“修改初始条件并从零重新计算”，支持原有撤销／重做。当前没有在正在运行的任意时刻注入天体；因此预览明确标出初始时刻。所有新控件与 CLI 使用同一动作和校验。

接触基础已落地；局部 SPH、行星破裂与随时添加仍未完成，下一核心验收是支持岩体尺度下的事件转换。现有 [数值基线](SPH-BASELINE.md) 和 [环与完整碰撞](RING-AND-COLLISION.md) 的开放问题继续保留。

## 验证入口

`tests/placement_projection_test.cpp` 检查多种宽高比、倾角与构图的正逆投影、侧视退化与非法输入。`tests/cli_transport.test.mjs` 检查共用操作、暂停／恢复、目标方向、无效预览、取消和单次确认。

`scripts/test-viewport-placement-emulator.mjs` 在指定开发模拟器上验证主星图语义点位、实际点击与拖动、三种布局、倾斜平面、外观、取消及撤销。执行会改写当前实验，必须事先保存用户会话。验证结果与限制见 [0.41.0 发布记录](../releases/RELEASE-0.41.0.md)。
