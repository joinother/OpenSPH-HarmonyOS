# SPH 破坏与热软化

> 类型：当前材料模型参考；实现与验证日期：2026-09-08（Asia/Shanghai）；适用版本：0.52.0。

## 已接通的行为

“完整冷岩，相撞之后”“预热岩体，同样一撞”“已有裂隙，还能撑住吗”使用同样的百公里岩体、8 km/s 接近速度、45° 偏移参数、600 粒子预算和 60 秒窗口，仅改变初始比内能或初始损伤。偏移参数不是实际接触角。参数面板可调整两颗岩体共同的初始比内能和损伤，应用后重新生成；观察面板可切换热软化外观、剩余强度、损伤和材料团块，切换显示不会重算。

初始参数写入 OpenSPH 的 `BodySettingsId::ENERGY` 与 `DAMAGE`，不只用于渲染。求解仍采用导入的 Tillotson 状态方程、von Mises 屈服模型及 Grady–Kipp 标量损伤。裂隙是强度退化量，不是逐条几何裂纹；碎块仍使用现有几何连通判据，不能当成引力束缚天体。

## 物理量与显示量

固定材料参数来自本项目导入的 [Settings.cpp](../../third_party/opensph/core/system/Settings.cpp) 和 [Rheology.cpp](../../third_party/opensph/core/physics/Rheology.cpp)，本轮没有修改第三方代码。冷态无损伤屈服强度为 3.5 GPa，模型的零剪切屈服能量为 3.4 MJ/kg。它们是当前材料模型参数，不代表全部岩石的普适常数。

设 `u` 为比内能，`D` 为有效损伤，`u_m` 为 3.4 MJ/kg。上游存储的是 `D` 的立方根，应用输入有效损伤后先取立方根再传入，诊断时还原立方。

- 热软化 `s`：`u/u_m < 1e-5` 时为 0，否则截断 `u/u_m` 到 0–1；保留上游的小能量分支。
- 剩余屈服强度比例：`(1-D) × (1-s)`。这是可承受屈服强度的比例，不是当时实际应力，也不是液相比例。
- 热致零屈服强度质量：`u ≥ u_m` 的粒子质量占比；严重损伤质量使用 `D ≥ 0.9`，边界仅容许 1e-12 的数值舍入。
- 四项汇总均按真实粒子质量加权。初始损伤与初始比内能都对两颗岩体生效，不能分别设置。
- 热软化外观根据实际比内能显示红橙到亮黄，损伤区变暗。发光是示意映射，不是黑体光谱或测温结果；没有添加额外物理热量。

压力与体积功仍由 SPH 求解器处理。达到零剪切屈服强度不等于压力或引力消失；膨胀消耗内能时，模型可以恢复部分热致强度。这不是辐射冷却、潜热释放或结壳模型。

## 初态与回放

`initialEnergyMJkg` 为可选 0–6.8 MJ/kg，`initialDamage` 为可选 0–1；省略时均为 0。热／预损伤初态仅支持直接生成岩体，不能用于轨道、星系或预松弛。预热会产生初始压力膨胀，尚未构造静力平衡的热岩球。无效参数在替换当前场景前拒绝。

0.56.0 的新 SPH 回放采用 [v20 来源扩展](FRAGMENT-PROVENANCE.md)。普通材料使用以下 v15 基础布局：沿用 v10 的配置、结构与几何团块，配置后追加两项初态参数，每帧团块记录后追加四项双精度响应汇总。逐粒子比内能／损伤继续使用原标量记录。命名实验也保留初态参数与颜色 7／8。

旧 v1–14 继续读取。旧 SPH 回放缺少材料响应版本，因此不补造新响应，颜色 7／8 回退原色；轨道 v14 保持原格式和续算能力。v15 仍是观察回放，不是完整 SPH 求解检查点。开发测试专用的 `saveReplay(dir,false)` 可生成不含团块的旧格式；非零初始材料状态拒绝这种降级，以免丢失参数。

## 验证与边界

[原始证据](../evidence/material-response-0.52.0/native-tests.txt)包含 18 组实际上游应力测试，覆盖冷态、阈值小能量分支、半软化、零强度、超过阈值及三种损伤状态；检查剪切屈服与负压力削弱。四组原生引擎实验检验初态传递、撞击新增内能／损伤、质量保持、v15 精确回读和损坏文件无副作用。另运行 [SPH 回归](../evidence/material-response-0.52.0/sph-smoke.txt)，覆盖自引力／预松弛、不同预算、取消重启和旧格式。

[模拟器证据](../evidence/material-response-0.52.0/device.json)覆盖三组 600 预算的 60 秒实验、UI／CLI 材料输入、切换显示、回放、命名实验与无效参数拒绝。真实数量由采样器决定，本轮为 641。既有数值基线尚未证明破坏结果的分辨率收敛，本轮也未做新的收敛研究。

尚未实现：热容与潜热一致的相变、真实温度／液相比例、连续液态表面、辐射冷却结壳、轨道撞击自动转入局部 SPH、残骸回注和月球形成。下一步仍按 [产品路线](PRODUCT-ROADMAP.md)接通 P2 事件初值与 P3 相变能量账，不能将本批热软化称为完整熔融模拟。
