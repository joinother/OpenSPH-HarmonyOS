# 环与完整天体碰撞主线

> 类型：当前实现与优先级；更新日期：2026-09-08（Asia/Shanghai）；基线：0.41.0。

用户指出的核心缺口成立：此前固定环面与稀疏示踪点分离，SPH 岩体碰撞也尚未接入完整行星结构和再聚合。优先级调整为可验证的物理闭环，外观生成路线保留，但不能替代本主线。

## 本版真正连接了什么

8192 个等权无质量粒子在有预设缝隙的环面上按面积分层、确定性散列方位分布（避免规则黄金角采样在差分转动下出现人工螺旋队列）。每个粒子的位置由中心引力解析轨道求得；同一位置数组通过归一化 6×6 核沉积到 512×512 浓度图。环面透明度、投在行星上的环影都读取这张图，点显示也读取同一数组。静态普通环使用这套模型的零时刻图，没有额外固定环轮廓叠加。密度图覆盖中心正负 7 个行星半径，片元绘制范围按实际粒子外缘收紧。

局部扰动在零时刻对靠近初始方位 0、距离 1.75 个行星半径的区域注入向外径向速度；角度／半径用高斯衰减，峰值为当地圆轨道速度的 0–0.35 倍。切向速度仍为圆轨道速度的 1–1.2 倍。注入后沿各自有界二体轨道演化，改变强度会重置局部时间。没有实际撞击体；注入使能量改变，之后才要求单粒子能量和角动量守恒。

实现由初始速度计算偏心率向量、半长轴和初始偏近点角，再解开普勒方程。基本关系参考 [MIT 轨道动力学第 2 讲](https://ocw.mit.edu/courses/16-346-astrodynamics-fall-2008/dbce406df8d13e052f9229880ed96c02_lec_02.pdf)。本项目独立实现并以牛顿加速度、初始速度、守恒量和独立 leapfrog 收敛交叉检查；微小扰动使用 `e_x + k²` 避免 `1-D` 的消减误差。

浓度到透明度使用 `1-exp(-浓度)`，比例系数用于可视化。它不是 kg/m² 或经过标定的光学厚度；8192 是计算采样数，不代表真实环颗粒数量。暖色颗粒用于检查位置，不参与温度或粒径解释。预设缝隙不是卫星动态开出的间隙。

NASA 的环颗粒研究强调聚集、分离和碰撞会共同影响环的结构，所以单中心力不能代表完整环动力学。[Cassini 环颗粒研究介绍](https://science.nasa.gov/missions/cassini/predators-and-prey-fluffy-and-slick-br-the-ecology-of-saturns-ring-particles/)

NASA 关于冰卫星相撞与土星环起源的研究使用高分辨率模拟研究碎屑分布，可作为未来“冰卫星相撞 → 环与卫星”实验的物理参考。本版不能声称复现其结果。[NASA 研究介绍](https://www.nasa.gov/solar-system/new-simulations-shed-light-on-origins-of-saturns-rings-and-icy-moons/)

## 执行顺序

1. 已完成的基础继续保留：0.33 同源密度环，0.34 自引力，0.35 结构与能量，0.36 定时预松弛，0.37 自由释放，0.38 实验对照，0.39 几何团块，0.40 团块连续跟随。这些不等于完整行星撞击。
2. 0.41 接入 [主星图放置与定向发射](VIEWPORT-PLACEMENT.md)。下一项优先做真实尺寸接触检测和基本接触响应，验证接触时刻、守恒及回放身份；不能继续用观察面板或新皮肤替代。
3. 在支持的小岩体尺度连接主轨道与局部材料模拟，明确坐标、时钟、质量／动量、材料身份与残骸返回。完整行星的分层与平衡需继续 [SPH 基线](SPH-BASELINE.md) 中未收敛项，不能简单放大已有岩球。
4. 接触与局部 SPH 流程完成后，再扩展摄动卫星、环互撞、再聚合与同源表面，逐级增加冰卫星碎裂、落入环带和月球形成等完整实验。

手机、平板和电脑的物理预算须分别实测；模拟器通过不代表真机性能达标。未完成能力与验收条件继续按上表跟踪。
