# 产品实施路线

> 类型：当前执行路线；更新日期：2026-09-08（Asia/Shanghai）；源码版本：0.50.0。

目标是一个能在同一场景中持续放置、运行、撞击和观察的天体沙盒。此前预研分散在多个专题，局部功能并不等于完整体验。后续按下列依赖顺序交付；没有通过验收的阶段不能标为完成。每次推进更新此表，不再用新增调研篇数表示产品进度。

## 当前核对

| 用户操作 | 实际基础 | 缺口 |
| --- | --- | --- |
| 随时加入并控制时间 | 0.49.0 持续轨道时钟、当前帧插入、v14 续算 | 最多 8 体；SPH 与星系仍不支持同类连续插入 |
| 选行星后加卫星、投放或发射 | 0.50.0 三个选择操作，共用 UI／CLI；围绕所选母体构造相对速度；点质量场景确认时补估算半径 | 初始轨道采用二体估计，非长期稳定性保证；最小质量约 0.00333 地球质量，尚不支持小陨石质量范围 |
| 引力与相互作用 | orbit.cpp 逐对引力含反作用；实体球使用自适应子步与扫掠接触 | 没有潮汐形变、潮汐耗散、自转交换；外观环没有卫星摄动或环粒子互撞 |
| 撞击行星 | 实体表面检测、理想弹性响应与自动暂停；另有独立岩体 SPH 实验 | 两条求解路径尚未接通；弹性反弹不是行星撞击破碎 |
| 熔融、碎片与月球形成 | SPH 已有比内能、损伤、材料团块和自引力诊断 | 尚无温度／熔融分数模型、热表面、冷却、完整碎片回注；月球形成未实现 |

## 交付顺序与验收门槛

| 顺序 | 要交付的完整流程 | 验收门槛 | 状态 |
| --- | --- | --- | --- |
| P1 目标操作 | 点选母体 → 卫星／投放／发射 → 位置和速度预览 → 当前时刻加入 → 暂停、继续、保存 | 原天体时间和向量不变；取消无物理副作用；移动母体速度继承；卫星多圈轨道与反作用；实体撞击触发；设备 UI／CLI 一致 | 0.50.0 首批实现，证据见版本记录；质量预算与稳定性提示继续补 |
| P2 碰撞事件与局部 SPH | 在原场景捕获撞击双方 → 以质心系生成受支持岩体初态 → 局部演化 → 同一镜头观察 | 明确 AU／年与米／秒转换；质量、线动量、角动量预算；事件只消费一次；失败能恢复事件前状态；时间与材料身份可追踪 | 下一主任务。先做现有 40–200 km 主岩体、20–120 km 撞击体范围；须先扩展轨道小质量支持。行星尺度不偷偷缩小套用 |
| P3 撞击热状态与表面 | 接收耗散／比内能 → 材料热状态 → 局部发光、熔融区域及冷却显示 | 区分温度、熔融分数和视觉强度；定义热容、相变与辐射假设；冷却能量有账；随碰撞位置变化，暂停／回放一致 | 未开始。P2 的弹性碰撞不能凭空产生热量；艺术热效果若先行，明确标为示意 |
| P4 残骸回到主场景 | SPH 识别碎片 → 判定引力束缚 → 生成有质量残骸 → 与母体和卫星继续相互作用 | 质量与动量对账；转换往返和检查点；避免把几何连接当成束缚；分辨率／步长对照 | 未开始；依赖 P2 和可信团块判据 |
| P5 行星与环系统 | 分层行星初态、材料 EOS、碰撞形变、卫星摄动及同源环 | 平衡初态、材料参数、能量和收敛验证；外观环和动力学采用同一分布与时钟；手机／平板／电脑预算分档 | 分期研究；不是 P2 小岩体结果的直接放大 |

P2 完成前，优先修复 P1 暴露的操作与数值问题，随后推进 P2 的事件协议和独立转换回归。星系、星云、摄影背景、插件与国内资源服务保留既有专题队列；不将它们的进展计入行星碰撞完成度。

## 每次开发的完成定义

- 开始：确定表中一个可验收的流程和缺口，核对真实代码入口。
- 实现：UI 与 CLI 共用语义操作，失败保留当前世界，说明模型变更。
- 验收：主机数值／事务检查与设备操作分开记录；热视觉还需图像与回放验收。
- 交付：更新当前说明、证据与本表，写清仍缺什么。未实测的触摸、动画、真机性能不写“通过”。
