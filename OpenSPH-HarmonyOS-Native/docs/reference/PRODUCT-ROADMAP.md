# 产品实施路线

> 类型：当前执行路线；更新日期：2026-09-08（Asia/Shanghai）；源码版本：0.54.0。

目标是一个能在同一场景中持续放置、运行、撞击和观察的天体沙盒。此前预研分散在多个专题，局部功能并不等于完整体验。后续按下列依赖顺序交付；没有通过验收的阶段不能标为完成。每次推进更新此表，不再用新增调研篇数表示产品进度。

## 当前核对

| 用户操作 | 实际基础 | 缺口 |
| --- | --- | --- |
| 随时加入并控制时间 | 0.49.0 持续轨道时钟、当前帧插入、v14 续算 | 最多 8 体；SPH 与星系仍不支持同类连续插入 |
| 选行星后加卫星、投放或发射 | 0.50.0 三个选择操作，共用 UI／CLI；围绕所选母体构造相对速度；点质量场景确认时补估算半径 | 初始轨道采用二体估计，非长期稳定性保证；0.51.0 支持最低 1e-18 太阳质量及物理单位；实体半径仍至少 1 km，尚非米级陨石 |
| 引力与相互作用 | orbit.cpp 逐对引力含反作用；实体球使用自适应子步与扫掠接触 | 没有潮汐形变、潮汐耗散、自转交换；外观环没有卫星摄动或环粒子互撞 |
| 撞击行星 | 实体表面检测、理想弹性响应与自动暂停；0.53.0 保留入射状态并完成质心初值核对；另有独立岩体 SPH 实验 | 0.54.0 可从真实入射启动局部 SPH 并返回；外部世界暂停、碎片未回注，尚非主世界完整碰撞 |
| 熔融、碎片与月球形成 | 0.52.0 已有能量与损伤初态、热软化外观和剩余强度；保留团块与自引力诊断 | 尚无温度／熔融分数模型、连续液态表面、冷却、完整碎片回注；月球形成未实现 |

## 交付顺序与验收门槛

| 顺序 | 要交付的完整流程 | 验收门槛 | 状态 |
| --- | --- | --- | --- |
| P1 目标操作 | 点选母体 → 卫星／投放／发射 → 位置和速度预览 → 当前时刻加入 → 暂停、继续、保存 | 原天体时间和向量不变；取消无物理副作用；移动母体速度继承；卫星多圈轨道与反作用；实体撞击触发；设备 UI／CLI 一致 | 0.50.0 首批操作、0.51.0 小质量与单位已实现；多体容量与稳定性提示继续补 |
| P2 碰撞事件与局部 SPH | 在原场景捕获撞击双方 → 以质心系生成受支持岩体初态 → 局部演化 → 同一镜头观察 | 明确 AU／年与米／秒转换；质量、线动量、角动量预算；事件只消费一次；失败能恢复事件前状态；时间与材料身份可追踪 | 进行中：0.54.0 已用真实向量生成并运行局部 SPH，完成初始守恒预算、v17、准备取消与父世界返回；外部场、世界时间耦合、接触瞬间全世界回滚、无缝镜头和碎片回注待做 |
| P3 撞击热状态与表面 | 接收耗散／比内能 → 材料热状态 → 局部发光、熔融区域及冷却显示 | 区分温度、熔融分数和视觉强度；定义热容、相变与辐射假设；冷却能量有账；随碰撞位置变化，暂停／回放一致 | 0.52.0 已着手：真实能量与损伤初态、上游热软化、示意热外观及 v15 已验证。相变／潜热／冷却待做；硬球接触不产热 |
| P4 残骸回到主场景 | SPH 识别碎片 → 判定引力束缚 → 生成有质量残骸 → 与母体和卫星继续相互作用 | 质量与动量对账；转换往返和检查点；避免把几何连接当成束缚；分辨率／步长对照 | 未开始；依赖 P2 和可信团块判据 |
| P5 行星与环系统 | 分层行星初态、材料 EOS、碰撞形变、卫星摄动及同源环 | 平衡初态、材料参数、能量和收敛验证；外观环和动力学采用同一分布与时钟；手机／平板／电脑预算分档 | 分期研究；不是 P2 小岩体结果的直接放大 |

按用户要求，0.52.0 提前推进 [P3 材料响应](SPH-MATERIAL-RESPONSE.md)，使现有 SPH 破坏与热软化可以直接实验。下一批继续 P2 的外部场、世界时钟与事件协议，再推进 P3 相变能量模型。其他专题不计入行星碰撞完成度。

## 公开用户样本带来的补充

2026-09-08 的[创作者样本调研](../research/TARGET-CREATOR-651227816-2026-09-08.md)读取了 215 个去重视频目录、29 份详情及 6 个评论区首页，未播放视频。这位作者的系统搭建、材料分析和过程视频题材支持下列需求假设；单个账号不代表全部用户，这些要求是否已实现，以本表和版本证据为准。

| 对应阶段 | 进入待办的要求 | 判断完成的依据 |
| --- | --- | --- |
| P1 | 优先降低质量下限，提供 km／km/s，并区分半径与直径、距中心与距表面；随后评估多卫星批量布置和 16／32 体预算 | 0.51.0 已补小质量和单位切换，并验证保存／续算；容量扩展与批量布置仍待做，数字仅为评估目标 |
| P2 | 事件转换时保留粒子的天体、材料与来源层身份；剖切作为观察工具 | 来源可追踪，剖切不移除物理粒子；单材料字段不能冒充多材料求解 |
| P3／P4 | 热状态可解释；残骸成分按来源粒子质量汇总，继续参加主场景演化 | 守恒预算和回放一致；不把母体平均配方直接赋给每个碎片 |
| P5 | 卫星摄动环与外观共用分布和时钟，之后再增加环自引力、互撞和再聚合 | 各物理能力分别验证；示踪环不能被宣传成可自行聚成月球 |
| 跨阶段 | 实验配方携带参数、模型与事件时间；固定视角、事件书签及可选录像参数叠加 | 实验与观察过程可复现；录像仍使用系统编码并待真机验收，不增加模拟器软件编码 |

这些补充服务于“搭建系统 → 改变条件 → 观察后果 → 记录过程”。下一主任务仍是 P1 必要修补及 P2 的连续碰撞接入；陨石坑、异形天体和完整气候模拟不抢占主线。

## P2 下一步代码入口

0.54.0 的 `Engine::startImpact` 根据修订号和接触身份建立可返回的局部分支，`Experiment::setUp` 用保存的三维入射向量生成岩质粒子，首次发布后显示局部演化，v17 保存来源。`restoreImpactLocked` 恢复进入前的轨道会话。细节见 [局部撞击](LOCAL-IMPACT-SPH.md)。

下一批需接入外部场与世界时钟、连续局部镜头、持久事件协议和残骸回注。父会话是已显示的接触响应后状态，不能当成接触瞬间全世界回滚；局部回放也不是可续算的完整检查点。当前模型冷态、无自转、均匀岩质，仍不适用于直接放大的分层行星。

## 每次开发的完成定义

- 开始：确定表中一个可验收的流程和缺口，核对真实代码入口。
- 实现：UI 与 CLI 共用语义操作，失败保留当前世界，说明模型变更。
- 验收：主机数值／事务检查与设备操作分开记录；热视觉还需图像与回放验收。
- 交付：更新当前说明、证据与本表，写清仍缺什么。未实测的触摸、动画、真机性能不写“通过”。
