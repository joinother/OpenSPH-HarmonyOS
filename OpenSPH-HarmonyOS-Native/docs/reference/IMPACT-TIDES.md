# 局部撞击的外部潮汐

> 类型：当前模型与接口；源码版本：0.55.0；实现与验证日期：2026-09-08（Asia/Shanghai）。

## 使用方式

轨道参数页新增“近恒星岩体撞击”，把 100 km 和 60 km、密度 2700 kg/m³ 的岩体放在距一太阳质量恒星约 0.02 AU 处。这是冷态材料的人工对照初态，没有恒星辐射加热，也不是平衡轨道或真实星历。启动后在接触处自动暂停，再在观察页选择“隔离撞击”或“含外部潮汐”。两者使用同一真实入射记录，后者将恒星与其他外部天体的线性差异引力加入每个 SPH 粒子的加速度。

共享动作是 `orbit.impact.tidesDemo`、`impact.simulateTides`；既有 `impact.simulate` 保留隔离模型。后者不要求外部快照，因此旧 v16 入射轨道仍能运行隔离撞击。原世界继续暂停，`impact.return` 恢复进入前的状态和显示历史。没有反作用、碎片回注或主世界时钟推进。

## 同时刻来源与模型

`OrbitSystem::step` 在扫掠漂移到接触点、施加弹性冲量之前，保存全部天体的质量、半径、三维位置和漂移半步速度。两颗入射岩体必须逐值等于这份世界快照中的对应条目。快照的接触时刻不同于已经完成子步的显示帧；不能用显示帧的外部位置冒充接触位置。

局部参考系保持原来的三维方向，以撞击双方的质心为原点，扣除原点的整体引力加速度。对于原点指向外部天体的向量 `D`，令 `n = D / |D|`，叠加：

```text
T = Σ GM / |D|³ · (3 n nᵀ − I)       [s⁻²]
a(r) = T r                           [m/s²]
φ(r) = −½ rᵀ T r                     [J/kg]
U_tide = Σ m_i φ(r_i)                 [J]
```

这是冻结于接触时刻的线性潮汐展开。沿引力源方向拉伸、横向压缩；原点差异加速度为零。不是把同一个恒星加速度加给所有粒子，也不是精确近场引力或随时间运动的外部轨道。实现通过导入上游的 `makeExternalForce` 和 `Factory::getSolver` 扩展方程项，保留现有软化自引力、压力、强度与损伤求解；外力项不直接修改材料比内能。

当前入口限 60 秒，检查预计局部范围小于各外部距离的 1%，外部相对漂移比例和动力学时间比例不超过 1%；粒子实际越过空间范围时停止并保留返回入口。这些是模型适用性筛选，不是误差上限或科学收敛证明，也不覆盖外部天体之间的全部快速相遇。接近外部表面、缺失快照或超出筛选的事件不开放潮汐按钮，仍可运行受支持的隔离撞击。

## 诊断与时间

`getImpactPlan.contact.tides` 返回 `available`、`reason`、`sourceCount`、`radiusLimitKm`、`motionRatio` 与按行排列的 9 个 `tensorS2` 分量。状态模型为 `sph-orbit-impact-tides-v1`，`simulation.impact.tides` 和配置中的 `impactTides` 标记实际所用模型。配置标记只读，不能经普通 `setScene` 注入来源。

`simulation.impact.tidalPotentialJ` 是当前帧的外部潮汐势能；`trackedEnergyJ` 为动能、材料内能、软化自引力势能及潮汐势能之和。它不含弹性应变能，不是完整材料能量，更不是整个父世界的能量。普通结构数组里的势能仍只表示自引力；不能把外部项悄悄混入其原有语义。

`sourceTimeSeconds` 是接触事件时刻，`elapsedSeconds` 是当前局部帧秒数，`eventEpochPlusElapsedSeconds` 仅将两者相加作为时间对应标记；回看时跟随所选帧，不代表父世界已演化到该时刻。绝对时刻很大时相加会损失浮点精度，局部时间仍以独立的 `elapsedSeconds` 为准。上游步长会略越过请求终点，60 秒实验的最后帧可能为 60.02 秒。

## 回放兼容

- v18 轨道：沿用 v16 布局，在每帧入射扩展之后增加 uint32 世界天体数（0 或 2–8），然后每个天体 8 个 double，顺序为质量、半径、位置 3 维、速度 3 维。无来源的旧帧数为 0；读入不会补造来源。
- v19 潮汐 SPH：沿用 v17 入射头，在 292 字节之后增加相同世界扩展，每帧材料响应之后增加一个 double 潮汐势能。读取时重新核对世界与入射一致性、模型筛选及数值有效性。v19 明确意味着启用潮汐，不允许无外部来源的 v19。
- 隔离 SPH 继续写 v17，仅保留双方入射记录；重新加载不具有外部快照，也不开放潮汐入口。v14、v16、v17 继续可读。

SPH 回放仍是观察记录，没有完整求解器检查点和持久父会话。来源快照也不是已完成的世界回滚协议。

## 验证与下一阶段

验证包括解析拉伸／压缩、势梯度、独立精确点源差分对照、独立积分的静态势能预算、实际 SPH 开关对照、轨道 v18 与局部 v19 往返、损坏拒绝和应用返回。结果与边界见 [0.55.0 记录](../releases/RELEASE-0.55.0.md)。

下一阶段仍需随时间演化且带反作用的外部天体、接触时刻世界分支、持久事件协议、束缚团块判定、残骸质量与动量回注。此版本没有完成这些环节，也没有完成行星分层、辐射加热、相变和月球形成。
