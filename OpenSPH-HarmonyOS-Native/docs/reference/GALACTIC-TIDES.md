# 星系潮汐实验

> 类型：当前模型与操作参考；适用版本：0.46.0；更新日期：2026-09-08（Asia/Shanghai）。

实验库新增“两条潮汐尾”和“反转一片星系”，参数页也可选择“星系潮汐”。它们以两个移动的扩展引力势驱动恒星示踪盘，观察相遇后的拉伸与物质桥。此处的“恒星群”是无质量示踪粒子，没有粒子间引力、实体碰撞、气体、动力摩擦或自洽星系合并。

## 盘内天空

观察面板新增太空／地表入口，跟随主盘初始约 8 kpc 处的固定示踪点，用实际历史重绘天空；支持纬度、恒星时、环顾、视场与同一时间轴。这是太阳位置类比，未标定真实银河系／仙女座，也未嵌入太阳系。见 [盘内天空的实现与边界](GALAXY-OBSERVER.md)。

## 操作

选择主题后在初始时刻暂停。点击开始，计算至设置时长；可以暂停、回看、拖动视角或跟随主／次星系中心。镜头与回放操作不重新计算。参数修改进入草稿，点击“应用参数 · 重新生成”才从零重建；参数页可进入“在星图调整相遇”，在受约束预览中调整横向偏移；尚不支持任意空间放置星系或从历史帧续算。

| 参数 | 范围与含义 |
| --- | --- |
| 恒星示踪点 | 200–2400，两盘各约一半；点数不改变引力质量 |
| 主星系质量 | 固定为 1000 亿太阳质量；不是中央黑洞质量 |
| 次／主质量比 | 0.2–1.0 |
| 接近速度 | `speed` 为 0.75–1.25 倍基准速度；基准约 156.45 km/s |
| 初始横向偏移 | 0–30 kpc，初始两中心沿 X 相距 60 kpc；不是近心距 |
| 次盘倾角 | `angle` 为 0–70°，主盘在 XY 平面 |
| 次盘旋转 | 顺行／逆行；相对于非零偏移时中心轨道角动量定义，零偏移时仅表示自转符号 |
| 模拟时长 | 50–800 Myr；1 Myr 为一百万年 |
| 随机种子 | 配方和 CLI 保留 1–1000000 的确定性种子 |

两组主题使用 1600 点、质量比 0.6、偏移 12 kpc、倾角 25°、600 Myr 和相同种子，只改变次盘旋转方向。新封面由此模型在 400 Myr 的实际示踪点投影生成，金色／蓝色记录所属星系，不代表恒星温度或观测光谱。

## 在星图调整相遇

参数页点击“在星图调整相遇”，界面暂时显示草稿参数生成的初始双盘。上下轻点／拖动改变次星系横向偏移，双指可缩放，也可以使用预览滑条。蓝色竖线是允许位置范围，箭头只表示相对接近方向，不是预测轨迹。两中心在质心系内同步调整，主星系不会被固定为绝对不动的原点。

此模式保留现有模型的约束：初始 X 方向间距固定 60 kpc，偏移为 0–30 kpc，越过预览端点会停在端点。它不是任意方向／距离／速度的自由放置，也不代表设置最近距离。进入时暂停正在进行的计算或回放；取消恢复原镜头、面板、参数草稿及播放状态，原历史保持。确认才用当前草稿与新偏移重建初态并暂停，旧历史随之替换。折叠和旋转保留预览草稿。

## 演化曲线与导出

观察面板有间距、主／次盘均方根尺度、主／次盘外延比例五条曲线。时间为 Myr，外延曲线显示百分比；“记录最小／最大”定位已有采样并暂停，曲线来源过期时拒绝定位，避免跳到新场景的同编号帧。极值只代表 4 Myr 记录节奏中的采样，不代表精确近心时刻或瞬时最大值。

`getGalaxyObservation` 返回同一次锁定读取的历史、已应用参数、场景身份和当前曲线；`getGalaxyTable` 返回 CSV、行数、参数及说明。最多 201 行常规星系记录，包含 model、种子、点数、质量比、速度倍率、倾角、初始偏移、旋转方向、时长、帧号、时间、五项诊断与两中心归一化能量／角动量偏差，共 18 列。CSV 中外延比例为 0–1，曲线显示为 0–100%；不插值、不只截取当前帧，不混入未应用草稿。当前导出通过 CLI 获取，尚未增加系统文件选择器或逐恒星轨迹导出。

v12 已保存这些记录，旧版星系回放可直接生成曲线和 CSV，不更换回放格式。实际测试与截图见 [0.44.0 记录](../releases/RELEASE-0.44.0.md)。

## 两次星系实验对照

在观察面板点击“保存本次作参照”，保留当前实验的全部已记录数据及计算实际使用的参数；至少需要两帧。修改参数并重新计算，或使用实验库“切换对照实验”，即可在同一坐标轴叠加青色当前曲线和金色参照。参照只有一个本地槽，再次保存会替换；跨场景、回放载入和应用重启保留，与命名实验、SPH／轨道参照分开。

五个指标统一按各自实验开始后的 Myr 对齐，纵轴覆盖两组记录。“当前 − 参照”只在参照时间范围内计算；参照在当前时刻没有恰好采样时做线性插值，不向范围外推算。外延曲线仍显示百分比，两个比例的差显示“个百分点”。极值按钮始终定位当前实验的原始采样，参照的极值不改变当前历史索引。

参数差异使用两组已应用初值，包括示踪点数、随机种子、接近速度倍率、倾角、时长、质量比、偏移和次盘顺逆行；未应用草稿不混入。点数改变采样预算，不改变引力质量；多项参数一起变化时，不能仅凭曲线认定单一原因。顺逆行对照说明形态响应，不等于科学收敛或真实星系拟合。

“隐藏参照”只隐藏叠加与差值，仍保留文件和导出；“移除参照”只清理这个参照槽，不改变当前实验。损坏文件显示错误并保留原文件供恢复，可以重试读取或明确移除。写入先校验完整临时文件再替换，写入失败保留旧参照。

新增动作 `galaxy.reference.capture`、`galaxy.reference.toggle`、`galaxy.reference.clear`、`galaxy.reference.reload`；`getGalaxyReference` 返回保存内容，`getGalaxyComparison` 返回当前原始记录、参照、差异、共享曲线和差值。原有 `getGalaxyObservation` 仍返回单次实验曲线；`getGalaxyComparisonTable` 导出 19 列 CSV，在原 18 列前增加 `series`（current/reference）。每行保留各自的参数、采样时间、五指标和两个中心误差；无重采样，外延比例仍为 0–1。最多两组各 201 行常规记录；显示隐藏不影响导出，非星系场景只有参照数据时明确返回 `currentAvailable:false`。

参照存储为本地 `galaxy-reference.json`，schemaVersion 1、模型 `galaxy-tidal-restricted-v1`；不修改 v12 回放格式。它包含诊断时间序列，不包含逐粒子轨迹、形态画面的同步叠加或求解器续算状态。

## 数值定义

模型身份为 `galaxy-tidal-restricted-v1`。C++ 求解使用 kpc、Myr 和太阳质量，独立于现有 AU／年行星轨道；以太阳引力参数换算本模型引力常数。主势的 Plummer 尺度为 5 kpc，次势尺度乘以质量比的立方根。示踪点的势为 `Phi = -G M / sqrt(r² + a²)`，初始速度取各自孤立球对称势下的圆轨道速度。

初始盘是截断的冷示踪盘，半径为 0.5–12 kpc，次盘按质量比立方根缩放。径向采样使用固定 xorshift32 序列，不是拟合观测的指数盘或自洽平衡星系。两个势中心以质心系初值积分；两中心相互作用采用对称软化势，软化长度平方为两尺度平方之和。这是明确的近似规则，不等于两个 Plummer 密度分布的精确引力卷积。

积分采用 kick–drift–kick，最大步长 0.0625 Myr；每 4 Myr 及最终时刻记录一次，共最多 201 帧。计算每个子步检查取消身份；渲染使用相对实验质心的坐标，1 显示单位为 10 kpc。每个示踪点直接来自积分位置，以柔和光点显示；当前尚无完整宇宙目录、层级参考系或连续空间 LOD。

## 诊断的含义

观察页和 `getGalaxyDiagnostics` 提供中心间距、各来源粒子相对于所属中心的均方根半径，以及超过各自初始盘外缘 1.5 倍的点数比例。外延比例不是逃逸质量或引力束缚判定。

能量与角动量偏差只计算两个软化中心；能量分母为初始能量绝对值加两倍初始动能，避免近抛物线初态下分母过小。角动量指标是当前与初始两中心总角动量模长之差，分母为初始两中心各自 `m |r| |v|` 的和（最小取 1），不是各分量的误差范数。中心能量归一化偏差超过 0.001 时停止并报告错误。恒星示踪点受时变外场做功且无反作用，不能以其总能量恒定作为封闭系统守恒条件。

主机、ASAN/UBSAN 检查、ARM64 核心测试以及模型限制见 [0.43.0 记录](../releases/RELEASE-0.43.0.md)。单模型误差检查不等于真实星系科学验证，也没有完成恒星数／初态／分辨率的科学收敛研究。

## 保存与 CLI

命名实验保存模型、质量比、偏移、旋转方向、其他初值以及现有镜头／显示配方。回放使用 v12，保存每帧实际示踪点、中心位置与诊断，仍兼容旧回放；回放只供观察，不能恢复完整求解器继续积分。以下与 ArkUI 使用同一动作：

```sh
node scripts/opensph-cli.mjs --device 127.0.0.1:5555 --command uiAction --payload-json '{"action":"theme.galaxy-tails"}' --wait-state paused
node scripts/opensph-cli.mjs --device 127.0.0.1:5555 --command setUiValue --payload-json '{"field":"galaxy.offset","value":18}'
node scripts/opensph-cli.mjs --device 127.0.0.1:5555 --command uiAction --payload-json '{"action":"simulation.apply"}' --wait-state paused
node scripts/opensph-cli.mjs --device 127.0.0.1:5555 --command start --wait-state completed
node scripts/opensph-cli.mjs --device 127.0.0.1:5555 --command getGalaxyDiagnostics
```

`setScene` 使用 `preset:6`，接受 `galaxyMassRatio`、`galaxyOffsetKpc`、`galaxyRetrograde`，省略分别取 0.6、12、false。`count/speed/angle/duration/seed` 按本模型含义；为兼容配置结构，岩体字段仍需通过已有范围验证，但不参与此模型。其他预设拒绝星系字段。不能为该模型开启岩体自引力或预松弛，也不接受行星列表。

新增预览动作 `galaxy.place`／`galaxy.place.cancel`／`galaxy.place.confirm`，字段 `galaxy.placement.offset`，以及 `getGalaxyPlacement`／`setGalaxyPlacementPoint`；后者接收视口归一化 x、y，并投影到当前允许的偏移范围。曲线动作为 `galaxy.metric.0`–`galaxy.metric.4`、`galaxy.minimum`／`galaxy.maximum`。

字段为 `galaxy.ratio`、`galaxy.offset`、`scene.angle`、`scene.count`、`scene.speed`、`scene.duration`；动作 `galaxy.retrograde` 切换次盘方向，`focus.0`／`focus.1` 跟随两个中心。已有保存、载入、暂停、取消和回放动作通用；行星表面、材料损伤和行星曲线动作在星系实验中禁用。
