# SPH 跨实验参照

> 类型：当前交互与数据约定；适用版本：0.38.0；验证日期：2026-09-08（Asia/Shanghai）。

## 从预研到实现

[博客与论坛预研](../research/UNIVERSE-SANDBOX-BLOG-FORUM-2026-09-07.md) 第 04 项要求保留 A/B 两次结果并显示参数差异。0.27.0 已为轨道实验实现参照；此前 SPH 主题的“切换对照实验”只切换初态，不能在同图中保留上一条曲线。本版补齐 SPH 的保存、对照、持久化与导出。

在观察面板点击“保存本次作参照”，再切换对照主题并运行。青色为当前、金色为参照；压力、比内能、损伤、总动能、总内能、引力势能、相对动能、分布尺度及平均径向速度共九项都可比较。保存会替换单个 SPH 参照槽，切换实验不自动覆盖它。轨道参照仍使用自己的槽。

## 数据语义

保存的是已应用的配置、模型身份、实际粒子数、名称、保存时刻和最多 240 帧原始诊断，深拷贝后不随当前求解更新。未应用参数不进入参照配置。参照不是完整求解器检查点；不能从其某帧继续计算。

两条曲线按各自模拟开始后的秒数对齐，使用共同的时间和数值范围。窗口首帧可能不是零秒，不把它平移为零。准备阶段不在正式碰撞／释放计时内。当前曲线的极值定位仍只操作当前历史；参照既不驱动镜头，也不覆盖当前帧。

游标差值为当前值减参照在同一时刻的线性插值；只在参照记录范围内计算。区间不重叠、游标越界或旧回放缺少结构指标时，明确说明原因，不外推或补零。共用数值范围溢出时保留单条当前曲线并报告不能合并。所有原始导出都不包含插值点。

参数差异按“参照 → 当前”显示实验类型、预算、速度系数、偏移角、时长、两体半径／密度、附加自转、种子、自引力及预松弛。零／缺省准备、关闭／缺省自引力按相同含义比较。记录参数相同不证明求解器逐位可复现；修改多个变量也不能从曲线差异自动判定因果。

## 保存与导出

应用私有目录 `sph-reference.json` 使用 schemaVersion 1，限制 131072 字节，保存前核对配置、模型、帧顺序、有限值和结构字段。临时文件写入、同步、完整读取校验后才原子替换；失败保留原文件。读取损坏文件会显示错误并允许重读或移除，不静默覆盖用户数据。

`getSphComparison` 提供图和来源摘要，`getSphReference` 提供全部参照原始诊断；`getSphComparisonTable` 提供当前指标最多 480 行原始采样和元数据。隐藏参照只影响图，不影响导出；缺少该指标的系列不导出，并设置对应 available 字段。单位保存在 JSON 元数据中，CSV 列为 `series,frame,time_s,value`。

使用 `scripts/export-sph-comparison.mjs` 同时保存 CSV 和来源 JSON，校验单位、行数、采样顺序与有限值，已有路径拒绝覆盖。完整操作见 [CLI 指南](../CLI.md#sph-两次实验对照)。

## 验证与边界

[主机检查](../evidence/comparison-0.38.0-host-tests.txt) 包括共用坐标、独立插值、旧字段缺失、数据溢出、参数差异、文件写入失败保护与导出。实际设备 [功能验收](../evidence/comparison-0.38.0-ui.json) 比较直接／预松弛岩球，逐项核对九指标、432 行原始数据、冷启动保留、损坏恢复、替换与轨道参照隔离。[布局检查](../evidence/comparison-0.38.0-layout.json) 核对展开、折叠和横屏的保存／隐藏按钮命中与双曲线显示。

本版没有修改 SPH 求解器，没有增加静水平衡、碎片再聚合、行星层状结构或环颗粒互撞。固定种子重复误差与力项残差仍需独立物理验证；这套对照工具让差异可检查，不替代验证本身。
