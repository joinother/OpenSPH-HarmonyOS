# 连续时间与当前时刻加入天体

> 类型：当前模型与操作说明；实现版本：0.53.0；验证日期：2026-09-08（Asia/Shanghai）。

## 使用方式

轨道预设 3、4、5 都提供“加入天体”，暂停与运行中均可使用。进入放置会冻结当前可见的完整状态；选圆轨道、直接投放、掠过或瞄准目标，再确认。确认后保留原有天体的位置、速度、时间和保留历史，之前在运行则恢复运行；取消恢复原视角、播放状态和草稿。预览沿用独立渲染帧，不重建 XComponent。

“直接投放”表示相对首颗恒星静止，继承该恒星速度，随后由引力加速。圆轨道速度为包含候选质量的二体估计，绕首颗恒星构造；多体扰动仍可能使其偏离圆轨道。瞄准指向目标当前位置，不预测拦截。选中天体后可用“添加卫星／向它发射／附近投放”围绕该母体构造候选，相对速度叠加母体当前完整速度。点质量场景确认时按现有估算规则补全半径、启用实体接触；原有时间、质量、位置和速度不变，取消不切换模型。局部放置默认使用 kg、中心距母体表面高度 km、相对速度 km/s 和直径 km；可切换到天文单位、中心距离或半径，换算保留候选物理状态。高度指新天体中心距母体表面的距离，必须避免实体重叠；改变候选半径不改变所填中心高度。实体半径估算不等同于真实行星结构；接触仍为弹性响应并自动暂停。

外观包括恒星、海洋、厚云、荒漠、带环、月面。天文输入模式中，恒星采用太阳质量，范围 0.1–2；其他天体采用地球质量，等价太阳质量范围为 1e-18–0.01。公斤模式使用同一物理范围。实体半径仍须至少 1 km，尚非米级陨石支持。新增恒星参与同一多体引力；材质按主导恒星照亮，尚未叠加多光源散射。当前保留最多 8 个实体天体的设备预算，不能无限添加。

“15 km 岩质小行星”按直径 15 km、均匀密度 2700 kg/m³ 生成约 4.77e15 kg 的岩体，保留当前距离与速度字段。质量和尺寸之后独立编辑，并未自动锁定密度。向小岩体添加卫星时，默认质量随母体缩小并受最低质量预算约束，半径估算下限为 1 km。

绝对速度模式改变距离或质量时保留 km/s；圆轨道倍数模式保留倍数，因此实际速度会随母体、质量和距离改变。快捷“圆轨道／投放／掠过”在当前单位中写入相应速度；输入相对速度上限 100 km/s，同时候选相对首颗恒星的完整速度也须通过 100 km/s 校验。换单位时不完整输入会被拒绝并保留草稿。局部中心距离下限仍为 0.000001 AU（约 149.6 km）。

低质量天体可保留带环外观，但现有固定尺度的动态示踪环仍只支持至少 1e-8 太阳质量；不满足时对应动作禁用，配方校验同样拒绝不支持的动态环。

## 时间与历史

主运行按钮启动持续积分，轨道系统不再以初态配方的 1–10 年作为自动结束时间。档位为 0.01、0.1、1、10、100 个模拟日／现实秒，底层接受 0.001–100。暂停会固定已发布的完整状态，舍弃尚未发布的在途计算。恢复不补算暂停期间的墙钟时间。

步长继续受积分精度和实体接触约束；每次推进设置计算预算。达到预算时减慢真实推进，不扩大步长冒充目标速度。界面同时显示目标档位与平滑测得的实际速度，刚启动时实际值需要采样。系统保留最近 240 帧，历史窗口滚动与模拟结束是两回事。

查看旧帧后继续时间，会从该帧建立新分支，丢弃它之后的未来历史；在旧帧确认加入天体同样建立分支。仅打开再取消放置不会丢弃未来历史。加入天体改变总质量、能量和角动量，所以守恒误差从该次加入后的状态重新计量；不是把外部加入的质量视为守恒误差。

初态编辑的应用、删除、重置仍会重新建立实验。加入天体清除这套初态编辑撤销记录，防止误用旧初态覆盖正在演化的世界；其他天体输入草稿保留。当前不提供插入事务的单独撤销按钮，可通过保留时间轴回到插入前继续。

## 保存与接口

新版轨道“保存回放”在没有入射快照时写 v14，有入射快照时写 v16（见 [撞击初值](IMPACT-INITIAL-CONDITIONS.md)）：逐帧保存双精度位置与完整速度、名称、质量、材质、半径、接触事件、守恒基准、轨迹和时间档位。加载后暂停在最新帧，可继续或选择历史帧分支。旧 v1–v13 继续按原格式读取；缺少完整速度的旧回放不能伪造为可继续的检查点。SPH 与星系回放仍是观察历史。

命名实验依旧保存配方与外观，不保存连续时钟。初态编辑有坐标与速度范围；演化越出初态编辑范围时，仍可查询状态、加入天体及保存 v14／v16，应使用“保存回放”保留当前演化，而不是将命名配方当成中途续算文件。v14／v16 不包含地表种子、全局外观和镜头配方。

| 接口 | 含义 |
| --- | --- |
| `uiAction: simulation.toggle`、`start`、`pause` | 同一运行／暂停路径，轨道启动持续时钟 |
| `uiAction: time.rate.0.01/0.1/1/10/100` | 切换时间档位；不自动解除暂停 |
| `uiAction: orbit.add` | 冻结当前帧、打开候选预览 |
| `selection.satellite/launch/drop` | 对当前选中的天体添加卫星、发射或附近投放；可在预设 3／4／5 使用 |
| `placement.circular/still/escape/target.N/reverse` | 圆轨道、直接投放、掠过、瞄准及反向 |
| `placement.surface.0..5` | 天体类别；天文模式下 0 使用太阳质量，公斤模式保持 kg |
| `placement.units.physical/astro` | 切换整组显示单位；物理模式需实体半径 |
| `placement.units.center/altitude/radius/diameter` | 距离基准与尺寸表达；不改变同一候选 |
| `placement.rock` | 15 km 岩质小行星快捷参数，需要实体放置 |
| `getState.placement.units/labels/fields` | 查询当前输入单位、标签和原始字符串草稿 |
| `placement.confirm/cancel` | 带场景修订校验的插入／取消事务 |
| `getState.simulation.orbitState` | 所选帧的双精度状态；旧回放为空数组 |
| `continuous/daysPerSecond/actualDaysPerSecond/orbitRevision` | 是否持续、目标与实测速度、当前事务修订 |
| `getPlacementPreview.sourceTime/sourceRevision` | 放置基准时间与修订 |

单位和小质量贯通的验证见 [0.51.0 记录](../releases/RELEASE-0.51.0.md)。完整命令用法见 [CLI 指南](../CLI.md)。

## 验证与剩余边界

真实模拟器运行检查覆盖超过原定三年、暂停、当前时刻增加恒星、原有双精度状态保留、240 帧滚动、保存／载入／续算、定向预览和取消。独立原生引擎测试还覆盖旧帧分支、取消保留未来历史、过期修订与损坏文件拒绝。主机界面测试使用受控平台适配器，不能代替触摸与动画验收，证据见 [版本记录](../releases/RELEASE-0.49.0.md)。

未指定实体半径仍按点质量计算，近距离遭遇会保护性停止；指定半径时采用恢复系数为 1 的理想弹性接触，并在接触后暂停。没有行星合并、破碎、熔融、气体演化或从轨道到局部 SPH 的转换。本次没有为 SPH／星系引入同样的动态插入，也没有实施全宇宙层级模拟。
