## 本轮选择

0.39.0 沿材料碰撞主线增加 [几何团块](SPH-FRAGMENTS.md)：从实际质量、位置、速度与光滑长度计算分组，连接画面、统计、CLI 与回放。该项把“损伤数值”推进到可逐团观察材料分布，尚未实现引力束缚判定、持久碎片身份或再聚合动力学。固定条件重复性、力项残差与完整能量问题仍需继续解决。

0.40.0 补 [材料团块连续跟随](FRAGMENT-FOLLOW.md)：逐团选择、最大团快捷入口、实时质心镜头以及倒放／折叠连续性。保留的是本场景材料粒子序号，尚非持久碎片谱系；物理主线继续保留。
