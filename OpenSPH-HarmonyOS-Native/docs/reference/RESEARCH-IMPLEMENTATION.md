## 当前交付与新增预研

0.42.0 接入 [球体接触模型](SPHERE-CONTACT.md)：实体半径、连续扫掠、理想弹性响应、自动暂停、带外观球体和近距回放。此前主星图放置、SPH 团块观察保留；没有完成行星流体破裂或轨道到局部 SPH 的转换。

随后补充的星系／星云研究不改变应用版本。Celestia 和 SpaceEngine 提供导航与显示参考；恒星群的无碰撞引力、气体流体和宇宙学积分须分别实现，不能沿用实体球反弹或岩石损伤模型代替。

## 接下来的顺序

1. 保留并扩展已完成的真实尺寸接触／基本响应回归；高密度和多体同时接触仍受步长及事件预算限制，不能取消保护。见 [具体接入验收](VIEWPORT-PLACEMENT.md)。
2. 在支持的小岩体尺度接入主轨道与局部 SPH 的事件转换、时钟和材料身份；保留已有数值问题的诊断，不能直接声称已完成整颗行星破裂。
3. 继续力项残差、固定条件重复差异、准备停止条件、完整能量与空间收敛，再扩展分层初态、引力束缚／再聚合及同源表面。
4. 环的摄动卫星、互撞与统一时钟单独验收；外观、导览、国内资源分发及真机性能按各自路线推进。
