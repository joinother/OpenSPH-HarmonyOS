# 行星独立外观

> 类型：当前实现指南；适用版本：0.32.0；更新日期：2026-09-07（Asia/Shanghai）。

## 能力与操作

自定义系统中的海洋、厚云、荒漠和带环行星拥有独立地表与云层种子。观察面板的“新地貌”和“换云层”分别修改其中一项；“撤销外观／重做外观”最多保存 20 次。外观编辑沿用当前物理状态、回放位置、相机和原生视口；后台完成后用 350 ms 过渡替换材质。静态截图只能验证最终画面，不证明动画帧率。

复制行星保留两个种子；删除前面的行星不会让后面的天体改变外观。天体编辑历史保存配方关联，恢复被删天体时同时恢复其外观。外观历史与质量／轨道历史分开，物理初值变更后清空外观历史，避免旧历史误作用到另一个天体。

新建自定义系统／主题为虚构行星分配非零种子，新放置行星获得新种子；它们随后作为配方值保存，不按排序实时计算。恒星保留原有表面，真实月面保留 NASA 观测底图。预设 3／4 的固定轨道演示不支持逐天体编辑，使用自定义系统或探索主题体验此功能。

## 配方与兼容

命名实验外观配方 v3 新增 `surfaces`，自定义系统一颗天体对应一条 `{version:1,seed,cloudSeed}`，其他模型为空数组。种子范围为 0–1000000 的整数，0 保留旧噪声规则；生成器版本仅接受 1。先验证整个文件再改变场景，未知版本、错误数量或非法种子会拒绝。

旧 v1／v2 或无配方文件沿用原有共享风格，不因打开旧文件而获得随机大陆。读取不改写旧文件；另存时写入 v3。回放文件仍只保证原有物理回放内容，不包含这套外观。

## 实现与资源

当前扩展自有 [球面噪声生成器](../../entry/src/main/cpp/planet_texture.cpp)，未引入 NPGS 或其他外部代码。种子进入整数哈希，地表与云层随机流分开。岩质陨坑仍是既有的颜色明暗示意；没有新增真实凹凸地形、流体云、大气散射或撞击求解。

[后台生成器](../../entry/src/main/cpp/surface_generator.cpp) 只有一个工作线程与八个槽位，输出 512×256 RGBA8 地表和 R8 云图。请求更改按行检查取消，只有当前请求可发布结果；旧有效纹理在生成期间保留，失败保留原结果并报告错误。恢复旧种子或切换不适用类别会释放该槽。渲染线程上传纹理，切换窗口后从当前配方重新生成必要资源。

每组 CPU 纹理约 0.625 MiB，八槽常驻约 5 MiB；GPU 完整 mipmap 约 0.833 MiB／组，八槽约 6.67 MiB。过渡期间可额外保留一代 GPU 纹理，上传和生成另有瞬时缓冲。以上只估算新增贴图，不包括既有共享地图、NASA 月面、银河、驱动和帧缓冲，不能当总进程实测内存。

原生提交种子和查询状态见 [CLI](../CLI.md)。当前 `surfaceGenerated` 表示当前配方已完成 CPU 生成，不应据此推断每一颗星球的 GPU 上传、动画完成或设备帧率。编辑不改变物理 seed、质量、轨道与时钟。
