# 连续碰撞玩法验收

> 类型：R01 固定验收协议；应用基线：0.56.0；实施开始日期：2026-09-08；跨日验证日期：2026-09-09（Asia/Shanghai）。应用功能未因新增验收脚本而升级。

## 固定输入与执行器

使用 [固定夹具](../../examples/acceptance/continuous-collision-v1.json)和 [设备执行器](../../scripts/test-continuous-collision-emulator.mjs)。执行器读取实际安装版本，必须符合夹具中的 0.56.0；之后的功能改变需要同步升级判据，不能继续沿用本版的缺失结论。

G1 从恒星和 100 km 岩体开始，通过选择目标、向它发射、预览取消、输入质量／中心距／速度／半径及确认加入，生成 60 km 撞击体。双方密度为 2700 kg/m³；入射初态中心距为 400 km、相对速度 8 km/s，粒子预算 600。源质量采用应用的太阳 GM／G 单位约定，不混用另一份近似太阳质量常数。实际应用后的完整配置和世界向量另写入报告，避免用文档手抄值代替。

G2 复制 G1 应用后的完整配置，只把撞击体的 x 位置增加 400 km；运行至少 90 个模拟秒，核对未接触、未启动 SPH、无材料热诊断。此场景是有限时间的近掠对照，不保证长期不碰撞。重新应用配置可能调整整体质心参考系；物理初值的唯一编辑仍是这个横向偏移。

G3 与 G1 使用同一套放置操作，把母体初始 x 距离改为 0.02 AU，实际接触后选择含冻结潮汐的局部撞击。其任务是暴露外部世界／局部时钟断点，不把冻结潮汐当成已实现双向演化。

每次执行连续跑两轮 G1、G2、G3。完成后由 [独立报告检查器](../../scripts/analyze-collision-acceptance.mjs)核对实际初值逐字段一致、G2 只改偏移、两轮分类相同及恢复成功。输入夹具摘要、实际初值、逐步结果、首个断点、墙钟耗时、局部回放重开及截图均保留。实验中的 60 秒指模拟时间，不是性能承诺。

## 成绩的含义

[判定器](../../scripts/collision-acceptance.mjs)始终保留八个步骤：放置、接触、材料演化、连续观察、世界演化、残骸提交、撞后再加入、重开续算。缺项自动记为 `not_tested`，不跳过之后报成功。

| 字段／状态 | 含义 |
| --- | --- |
| passed | 本步骤的具体断言得到支持；不能外推到下一步骤 |
| unsupported | 本版有明确功能限制及现场状态证据 |
| not_tested | 未执行或前置不存在；例如无接触对照不测试残骸提交 |
| failed | 执行／断言失败，需要保留证据和修复；不与预期的功能缺失混用 |
| collectionComplete | 两轮资料采集完成，不代表产品玩法通关 |
| workflowComplete | 八个必要步骤均实际通过；返回未改变的父世界和保存局部观察回放都不算完成 |
| repeatStatusesMatch | 同一夹具的两轮步骤分类一致，不代表数值轨迹逐字节相同或物理收敛 |

执行器退出码：0 表示完整玩法通过；2 表示采集完成但玩法尚未完成；1 表示采集、断言或恢复发生错误。G2 无接触对照中没有残骸步骤，保留未测状态，因此单凭这一控制实验不能证明撞击主线通关。报告中的异常详细写入 errors，不把一次脚本异常归纳成模型缺失。

## 运行与数据保护

```sh
node --test tests/collision_acceptance.test.mjs
node scripts/test-continuous-collision-emulator.mjs 127.0.0.1:5555 docs/evidence/r01-new-run build/r01-new-private-backup
# 退出 2 仍需检查报告；不可当成玩法通过。
node scripts/analyze-collision-acceptance.mjs docs/evidence/r01-new-run/report.json examples/acceptance/continuous-collision-v1.json
```

两个目录必须全新；只操作指定的 127.0.0.1:5555。先查询命令和界面，再检查场景和备份。本执行器当前只接受无草稿、无录像、无环时钟、未运行的 SPH 零秒初始帧；其他会话会在修改前拒绝，需要先采用适合该会话的完整保存／恢复流程，不能为跑测试直接重置用户场景。

私有备份放 build，包含原页面状态和全部持久文件，不进入公开证据或 Git。finally 恢复初始配置、暂停状态、相机、外观和原始文件；递归核对文件数量、名称与 SHA-256，公开报告只输出恢复结果和数量。执行失败仍尝试恢复，恢复失败将退出 1 并保留私有备份。模拟器断电等进程级中断仍需从该备份人工恢复，不能视为 finally 一定执行。

0.56.0 的局部运行使用 `uiAction simulation.toggle`；通用 `start` 不在局部分支允许的命令集合内。真实月面外观不接受程序化种子编辑；基线保留原月面，不为了固定截图改变物理或加载规则。

## R02 必须处理的已观测断点

入射事件和显示父世界不是同一积分阶段：第一次 G1 的入射约为 29.9994 秒，而保存供返回的显示父世界约为 30.0264 秒。局部又演化至 60.02 秒后，返回仍恢复 30.0264 秒及原始轨道向量。应先建立可选择、可取消和可恢复的事件检查点，再处理连续镜头和残骸后果提交。

冷启动载入局部回放后，界面主按钮显示“仅回放”，原生 canReturn 为 false；底部说明仍可能写“原轨道暂时保留”。这个说明与当前加载状态不一致，纳入 R02 的状态文案核对，不把它解释为父会话已持久保存。
