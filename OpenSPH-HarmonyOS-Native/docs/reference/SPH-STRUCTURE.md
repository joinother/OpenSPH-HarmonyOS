# 材料结构与能量检查

> 类型：当前物理诊断；适用版本：0.35.0；验证日期：2026-09-08（Asia/Shanghai）。

## 四项读数

引力势能来自当前 Storage 的质量、位置和平滑长度，通过与求解一致的上游 Factory／BruteForceGravity 软化核计算，每帧重新建立视图。该对象在实验内复用，避免逐帧重新构建查找表；自引力关闭时势能记为零。上游 evalEnergy 的 1/2 系数避免每对粒子重复计能。核与球壳积分对照沿用 [自引力基线](SPH-GRAVITY.md)。

其余三项来自同一帧双精度 SI 状态，先计算总质量、质心位置和质心速度，再逐粒子统计：

| 读数 | 定义 | 能说明什么 |
| --- | --- | --- |
| 相对动能 J | Σ mᵢ × \|vᵢ−v质心\|² / 2 | 排除整团材料的平移，保留内部运动、自转与撞击相对运动 |
| 分布尺度 km | sqrt(Σ mᵢ × \|rᵢ−r质心\|² / M) / 1000 | 全部材料的空间分散程度；不是等效球体或表面半径 |
| 平均径向速度 m/s | Σ mᵢ × (rᵢ−r质心)·(vᵢ−v质心) / \|rᵢ−r质心\| / M | 负值表示平均向内运动；位于质心的粒子计零径向分量 |

相对动能通过先减速度再平方计算，避免两个巨大总能量相减导致有效数字丢失。所有质量必须为正，全部输入与结果必须有限，非法值会停止生成该物理帧。未用显示层 float 位置反推物理统计。

## 验证范围

- [解析测试](../evidence/structure-0.35.0-structure-tests.txt)：不同质量双粒子，已知质心与相对动能；平移、统一速度偏移及旋转后的不变性；对称收缩；单粒子；非法质量、坐标与势能。以 ASan/UBSan 编译运行。
- [原生引擎测试](../evidence/structure-0.35.0-native-emulator.txt)：真实岩体初始相对动能对照约化质量公式；有符号势能、尺度与径向速度；v8 精确往返；结构字段非有限、符号错误、截断均拒绝且保留原场景；旧 v6 明确缺失。原有 SPH、轨道、回放、取消、准备与有界历史检查继续通过。
- [主机检查](../evidence/structure-0.35.0-host-tests.txt) 与 [最终曲线／CLI 回归](../evidence/structure-0.35.0-final-regression.txt)：新曲线单位、极值、16 列导出、旧 12 列、结构缺失／混合／损坏输入处理。
- [应用数据](../evidence/structure-0.35.0-ui.json)：关闭与开启自引力的 16 秒碰撞，每条新曲线逐样本与 CSV 一致；极值定位保留相机与场景；v7/v8 回放精确恢复；1200 预算（实际 1276 粒子）自引力短算例完成。

上述开启／关闭应用算例使用不同粒子预算，分别用于功能覆盖，不能拿两者差值当作自引力效应的受控对照。已有 0.34.0 的同预算、同初值物理对照仍有效。应用 stepMs 是快照之间的墙钟间隔，包含求解及等待，不代表单独势能开销或渲染帧率。

## 保存与后续

原十项诊断数组保持不变，额外结构数组可选；新回放 v7/v8 追加四个 double，旧版缺失保持缺失。界面、原生接口与导出顺序见 [CLI](../CLI.md#sph-结构与能量)。

本轮补的是检查能力，没有生成静力平衡球体或分层行星。尚缺弹性应变能、耗散与损伤的完整能量处理、软化／步长收敛及长时稳定性。负势能和平均向内速度都不足以识别束缚碎片或证明再聚合；下一步继续松弛初态、完整能量账本，再做碎片团辨识。
