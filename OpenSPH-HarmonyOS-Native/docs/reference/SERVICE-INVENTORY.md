# 资源、服务与构建依赖台账

> 类型：当前依赖参考；源码版本：0.24.0；核验日期：2026-09-07（Asia/Shanghai）。本表中的候选不代表已经接入。

## 已有依赖

| 对象 | 当前来源与实际用途 | 运行时外发 | 国内运营处理 |
| --- | --- | --- | --- |
| 月面地图 | NASA SVS JPEG 随 rawfile 打包，ImageKit 按需解码 | 此路径无请求，URL 只作出处 | 保留离线包；未来国内镜像仍保留 NASA 署名；国产数据另行授权 |
| 银河全景 | ESO/S. Brunier JPEG 随包，CC BY 4.0 | 此路径无请求，URL 只作出处 | 可在授权范围内国内托管；换国产摄影需完整全景与再分发许可 |
| 云、海洋、环、星点及封面 | 自有程序生成；主题概念封面为项目资源；月面封面单独归因 | 未见联网路径 | 可继续离线维护；新增素材逐件登记授权 |
| 天体初态、实验库、轨道与 SPH | 本地参数、独立 C++ 引力及 vendored OpenSPH | 本地计算 | 没有待替换的外国计算 API；OpenSPH 仍是海外来源开源代码 |
| OpenSPH / sse2neon | 固定提交及 MIT 许可随源码保留 | 已导入源码，无运行时下载 | 国内 Git 备份与源码归档；不因换托管而改称国产引擎 |
| ArkTS / ArkUI / ImageKit / GLES | 本机 DevEco SDK、系统 API 与 native 库 | 本次资源读取未接第三方云 | 保留支持矩阵；系统实现及工具链不是本次完整审计范围 |
| 命名实验、配方、回放 | 应用沙箱内文件 | 无云同步 | 未来先做本地导入导出与格式迁移，再考虑账号同步 |
| CLI | HDC、Want、HiLog；由开发机发起 | 有显式开发设备连接，不是应用 HTTP 服务 | 保持开发专用；如做 LAN 控制需另建权限、认证和暴露边界 |
| GitHub | 当前源码检查点与同行研发参考 | 应用不查询 GitHub | 候选 CodeArts Repo / Gitee 单向备份，校验提交与附件完整性 |
| OHPM / Hvigor | `build.sh` 调用 ohpm install；项目根远程依赖为空，entry 只有本地 so 类型依赖 | 构建侧可能联网 | 官方中心仓与内部审核缓存；未验证清空缓存后断网构建 |
| Node、Python、编译器、ffmpeg | 开发、构建和图像验收工具，部分来自 DevEco / Homebrew | 仅开发安装更新涉及外部源 | 工具版本与二进制哈希登记；固定 CI 环境，不能只切 npm 镜像 |
| 华为开发者知识 MCP | 开发时检索官方文档 | 开发机发送检索词 | 当前工具，不是 HAP 依赖；服务失败可回退已缓存文档及本地 SDK 声明 |
| 同行网站与其他开发插件 | 调研、编程或账号连接工具 | 取决于开发工具，不由应用触发 | 与产品 SDK 分开管理，不把开发插件打包或代理到终端用户 |

资源原字节、参考文件哈希和扫描范围见 [本次清单](../evidence/localization-inventory-2026-09-07.json)。模块未声明 INTERNET；在本次一方 ArkTS／native 包装层关键词扫描中未发现所检索的网络调用，已人工检查两条图片读取链路。此结论不等于全 SDK 无通信、全部 vendored 源码逐行审计或真机抓包证明。研发浏览器访问、SDK 安装和系统应用市场通信另计。

## 尚未接入的服务与扩展

| 类别 | 候选处理 | 接入前应形成的验收结果 |
| --- | --- | --- |
| 资源 CDN、对象存储、域名、DNS、证书 | 境内 OBS+CDN 为首轮验证候选；OSS、COS 为备选 | 授权文件、地域、ICP备案适用性、断点续传、缓存、计费、故障回退 |
| 实验／素材数据包 | 有限格式的 JSON 和图像清单，本地导入优先 | 大小／维度限制、SHA-256、可信签名、路径约束、版本兼容和撤回 |
| 可执行插件、求解器、shader 扩展 | 随签名应用发布；评估官方增强模块按需分发 | 模块与 ABI/API 兼容、手机／平板／PC、升级回退；不当作图片热更新 |
| 账号、云存档、数据库 | 先保持本地；需要时评估 HarmonyOS 原生服务或国内自建后端 | 数据处理位置、字段最小化、冲突解决、导出、删除与离线使用 |
| 支付／订阅 | 数字权益候选 IAP Kit | 账号地区能力、服务端验单、幂等发货、退款与离线权益 |
| 分析、崩溃、性能日志、客服 | 本地诊断及用户主动导出优先；国内 SDK 另评估 | SDK 版本、实际外发字段、初始化时机、保留期限、权限与敏感信息去除 |
| 推送、邮件、短信 | 尚无必要；按通知场景单独选择 | 退订、重复发送防护、地域与每条费用，不自动引入推广 SDK |
| 地图、定位、授时 | 当前实验不需要地图或定位服务 | 未来观测模式先用手动位置／系统能力；地图另核资质与坐标基准 |
| 云模拟、AI 导览、翻译 | 先保留离线求解与人工文案；国内模型可列独立实验候选 | 结果可验证、上传字段、计费上限、许可、地域、失败离线回退 |
| 工坊、社区、内容搜索 | 原创实验包先本地交换，公共服务另立项 | 作者授权、审核举报、版本撤回、恶意文件控制、账号与运维职责 |
| 实时天文目录／巡天瓦片 | 与静态图片分开；国产源逐项确定 | 时间历元、单位、坐标、覆盖、时效、服务协议；不伪称国内等价 API |
| 局域网／本地设备控制 | 与公网服务、数据镜像分开 | 用户主动连接、认证、监听地址、断开与操作权限 |

每次新增 URL、SDK、数据上传、资源更新、远程监听或可执行扩展时更新此表，区分已实现、待验证和不适用。详细选型、费用模型与分期计划见 [国产替代与国内运营预研](../research/CHINA-LOCALIZATION-OPERATIONS-2026-09-07.md)。
