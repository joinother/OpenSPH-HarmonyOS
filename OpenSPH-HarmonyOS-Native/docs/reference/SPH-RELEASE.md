# 静止岩球的自由演化

> 类型：当前物理实验与数值基线；适用版本：0.37.0；验证日期：2026-09-08（Asia/Shanghai）。

## 应用中的实验

单体岩球 preset 2 支持 speed=0；其他碰撞仍要求 speed≥0.5，轨道保持原有约束。实际初始角速度为 `targetSpin + speed × 0.003` rad/s，参数面板改为显示总初始角速度。“设为静止初态”同时清除这两个草稿值，应用后生成新岩球，不改变正在回看的历史帧。

实验库增加“静止岩球，会一直静止吗？”和“撤去阻尼之后”，均为半径 100 km、密度 2700 kg/m³、预算 200 的静止玄武岩单体，开启自引力，自由演化 32 秒；后者先运行 64 秒预松弛。准备后使用普通 SPH／自引力求解，不再施加准备阻尼，也不在每步重置损伤。沿用既有 v8／v9 回放，零速度参数可随命名实验保存。

这让用户能观察初态释放后的压力、损伤、尺度和运动，而不是只看阻尼期间的表现。[预松弛本身的操作](SPH-RELAXATION.md) 包括耗散和残余速度清零，仍不能视作守恒演化或平衡判定。

## 固定步长对照

独立程序 `tests/sph_release.cpp` 运行相同材料和初态：预算 200／600，分别直接生成、预松弛 16 秒或 64 秒，再自由演化 32 秒；释放阶段步长分别为 0.0625／0.03125 秒，共十二组。预松弛自身步长固定为 0.0625 秒，因此本轮减半步长只检查释放阶段。

每步检查质量、质心及动量，记录尺度最大偏离、平均质心系动能、平均径向速度的绝对峰值及总加速度的质量加权 RMS。总加速度包含各求解项，未拆成单独压力／引力残差。

以下取较细释放步长，尺度偏离相对各自释放时的初态：

| 预算 | 预松弛 s | 尺度最大偏离 % | 平均径向速度绝对峰值 m/s | 平均相对动能 J |
| --- | --- | --- | --- | --- |
| 200 | 0 | 0.01307 | 0.4508 | 6.568×10¹⁷ |
| 200 | 16 | 0.008672 | 0.2972 | 2.898×10¹⁷ |
| 200 | 64 | 0.0006762 | 0.02171 | 2.615×10¹⁵ |
| 600 | 0 | 0.01253 | 0.4696 | 6.475×10¹⁷ |
| 600 | 16 | 0.007544 | 0.2823 | 2.348×10¹⁷ |
| 600 | 64 | 0.00004612 | 0.002030 | 2.221×10¹⁴ |

64 秒准备在这些算例中显著降低后续运动，但不同预算的残余运动仍差异明显。所统计指标的粗细步长相对差最大约 1.60%，出现在一个末帧动能值；完整各项差异保留在 [分析](../evidence/release-0.37.0-analysis.json)。不能用两组步长、两个低预算或 32 秒观察宣称空间收敛、长期稳定、静水平衡或真实行星精度。

[桌面](../evidence/release-0.37.0-desktop.jsonl) 和 [鸿蒙](../evidence/release-0.37.0-emulator.jsonl) 十二组结果完成同模型跨平台核对。桌面按 [兼容副本流程](SPH-DIAGNOSTICS.md) 编译本轮测试，额外包含应用 C++ 头文件路径；模拟器执行 `scripts/test-sph-release-emulator.sh 127.0.0.1:5555`。

## 记录窗口统计

观察面板和 `getSphWindowSummary` 使用同一个函数，统计全部保留的 SPH 记录，不按当前回放游标截短。平均相对动能按实际采样时间用梯形积分加权，避免自适应小步被重复高估；尺度偏离相对记录窗口第一帧。径向指标是质量加权平均径向速度的绝对峰值，不是某个粒子的最高速度。

240 帧上限导致初始帧被淘汰时，明确返回 `includesInitial:false` 并显示“相对窗口首帧”；不能把窗口统计冒充完整过程。少于两帧、缺少旧回放结构字段或数据非法时，返回不可用，数值字段缺省，不捏造零值。统计不会给出 stable／equilibrium 结论。

满 240 帧的 16 列 CSV 曾超过 CLI 原 64000 字符上限。本轮将有界回复增加到 128000 个 UTF-16 编码单元、最多 256 片，保留按 UTF-8 字节计费的发送节奏；配套 CLI 解析同一上限。超限仍拒绝，完整导出应使用同版本 CLI。
