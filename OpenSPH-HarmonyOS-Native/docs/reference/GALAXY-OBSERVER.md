# 从星系内部观察天空

> 类型：当前模型与操作参考；适用版本：0.47.0；更新日期：2026-09-08（Asia/Shanghai）。

在星系潮汐实验的“观察”面板，进入“太空”或“地表”。这两个视角跟随主盘内太阳半径附近的一颗示踪点，用当前模拟帧绘制天空；不是把银河摄影贴到背景，也不是现实银河系／仙女座的未来预测。进入、退出、环顾和回放不重新计算实验。

## 已实现的观察方式

- 太空：从盘内向四周看，支持拖动环顾、双指改变视场、看主星系中心及看来访星系。太阳位置只是类比，没有在这个 kpc 模型里放入太阳、地球或其他太阳系天体。
- 地表：在相同位置加上地平线遮挡与示意地面；镜头按当地水平坐标环顾，保持地平线水平。观察面板可调纬度 −90–90°、当地恒星时 0–24 h；恒星时独立于数亿年的实验时钟。中心在地平线下时，指向它会看到地面，可调整恒星时或切到太空。
- 回放：沿用已有时间轴和播放按钮，0、240、480 Myr 等记录对应同一个示踪点的不同位置。返回外部保留原外部镜头和当前模拟时刻；切换实验、重新计算或载入回放会退出观察模式，需要再次选择进入。
- 折叠与旋转：视场按屏幕短边定义，35–120°；窗口变化保留观察身份、角度、纬度、恒星时和记录。此处没有镜头飞入动画、跨尺度太阳系模型或任意观察点编辑。

## 坐标与数据来源

引擎在同一把锁下返回当前帧、历史首帧、选择索引和场景代号。首帧必须为 0 Myr，当前与首帧粒子数相同，并含星系诊断。观察身份是主盘中最接近初始主中心加 `(8, 0, 0) kpc` 的粒子索引；之后一直追踪这个索引，不逐帧重新选择最近粒子。实际初始半径通过 CLI 返回，1600 点、种子 1234 的当前主题为约 8.061 kpc，不声称恰好是太阳轨道。

天空方向为每个示踪点相对观察点的位置差。绘制等权角度平滑光斑和细点，隐藏观察点自身，使用所属星系的金色／蓝色区分来源；没有虚增物理粒子、改变质量、补造引力轨道或插入照片。光斑由实例化四边形绘制，避免依赖设备点精灵的最大尺寸。它是示踪密度示意，没有恒星光度、距离消光、物理盘厚度、核球、尘埃带、颜色测光或光行时校正；主盘初始为薄盘，盘内看到的主银河带仍偏薄。

地平线方向采用固定 FK5 J2000 → 银道系的旋转角定义，再把银道坐标轴映射到模型 `(-X, -Y, +Z)`。给定纬度和当地恒星时计算天顶、东和北方向，天空镜头使用方位角／高度角；在极点也保持有限。角常数与轴定义核对自 [Astropy 的 Galactic 定义](https://github.com/astropy/astropy/blob/main/astropy/coordinates/builtin_frames/galactic.py) 和 [坐标变换](https://github.com/astropy/astropy/blob/main/astropy/coordinates/builtin_frames/galactic_transforms.py)。未引入 Astropy 运行时或复制其程序文件。这里固定现代坐标方向只是观察类比，没有推演未来地球自转轴、岁差、章动、太阳演化或适居性。

## CLI

先查询 `listCommands` 和 `getUiState`，使用 `uiAction` 与 `setUiValue`。所有按钮共用 ArkUI 动作，字段可用状态由运行时目录返回。

| 动作／字段 | 含义 |
| --- | --- |
| `galaxy.observer.space` / `.ground` | 进入盘内太空／地表模式，并指向来访中心；需要含初始帧的星系记录 |
| `galaxy.observer.primary` / `.secondary` | 指向当前帧主／次中心 |
| `galaxy.observer.exit` / `ui.back` | 返回外部镜头，保留时间 |
| `galaxy.observer.yaw` | −100–100 rad；太空中为模型 XY 平面角，地表中为由北向东的方位角 |
| `galaxy.observer.pitch` | −1.5–1.5 rad；太空中为盘面上仰角，地表中为地平高度角 |
| `galaxy.observer.fov` | 短边视场 35–120° |
| `galaxy.observer.latitude` | 纬度 −90–90° |
| `galaxy.observer.sidereal` | 独立当地恒星时 0–24 h，不推进 Myr 时钟 |

`getGalaxyObserver` 返回 available、mode（0 外部／1 太空／2 地表）、sceneRevision、selected、time（Myr）、anchor、initialRadiusKpc、positionKpc、两中心相对方向、指向角、当前角度、纬度和恒星时。`getState.galaxyObserver` 提供同一接口；`rendering.galaxyObserverMode` 和 `galaxyObserverTime` 表示最近完成提交的渲染帧。非星系场景 available 为 false；新场景不会继承旧场景的活动模式。

观察模式内禁用外部镜头、外部着色和静态天空设置的普通动作。它们退出后恢复；原外部镜头保存。观察设置当前只存于会话，未加入配方或回放。v12 限制性轨迹与 v13 双向引力轨迹均可重开盘内观察，也不新增求解器续算。

## 真实银河系／仙女座情景的后续路线

用户提出的真实全天空变化仍需专门情景：不能把当前 60 kpc 初始间距、最多 800 Myr 的受限模型直接改名成现实的银河系／仙女座。NASA 在 2025-06-02 介绍的新研究不再支持“必然碰撞”，需把不同未来轨道作为假设情景。[NASA 研究说明](https://science.nasa.gov/missions/hubble/apocalypse-when-hubble-casts-doubt-on-certainty-of-galactic-collision/)

1. 建立有来源及不确定性的银河系、仙女座、三角座与大麦哲伦云初值，区分接近、擦肩、晚期合并等情景；时间扩展须同时验证积分步长和存储预算。
2. 接入并验证有质量恒星盘、核球、暗晕及动力摩擦，先做孤立盘稳定和直接求和对照；当前两个解析势不产生自洽合并。
3. 在统一参考系下嵌入太阳位置与 AU 尺度的太阳系；地球站点接入真实历元、地形、日月、昼夜与大气模型，远期地球情景明确使用哪些固定假设。
4. 用恒星族、盘厚度与尘埃消光构建天空亮度，再加入光行时与观测方向标注；手机采用分级预算。历史 [NASA SVS 碰撞可视化](https://svs.gsfc.nasa.gov/30955) 可参考多时刻天空的叙事方式，但不能把其中旧预测当作现有科学定论。

观察原型的历史具体证据见 [0.46.0 验证记录](../releases/RELEASE-0.46.0.md)。

## 双向引力轨迹

0.47.0 的 [带质量恒星群](GALAXY-RESPONSE.md) 使用相同的固定来源索引、中心和时间序列进入天空通道。此时锚点代表一个带质量恒星群中的太阳位置类比，仍不是单颗太阳的实测轨道；天空继续等权示意，不按群质量测光。
