# 从轨道撞击进入局部 SPH

> 类型：当前模型与操作说明；源码版本：0.56.0；实现与验证日期：2026-09-08（Asia/Shanghai）。

0.56.0 新计算的 SPH 回放使用 [v20 来源质量扩展](FRAGMENT-PROVENANCE.md)，保留下述 v17／v19 基础布局和模型语义；旧回放仍可读，缺失粒子质量时不补造来源比例。

## 操作与完成范围

在自定义系统的最新暂停接触帧，打开观察页，选择“隔离撞击”或“含外部潮汐”。仅当 0.53.0 的入射范围检查通过且没有未保存的编辑／撤销历史、独立环时钟时开放入口。按钮分别与 `uiAction impact.simulate`、`impact.simulateTides` 共用代码；入射数据仍可通过 `getImpactPlan` 查询。

应用使用记录的双方三维位置、速度和质量生成真实 OpenSPH 粒子，初态暂停在局部 0 秒；点击开始后计算 60 秒岩质碰撞。可以查看损伤、热软化、剩余强度、材料团块和时间曲线，保存结果回放。顶部“返回轨道”（`impact.return`）恢复进入前的原轨道时刻、全部天体和历史。原来的镜头、地表种子和外观一并恢复。

这是可返回的局部实验分支。外部轨道在本批计算中暂停；返回的是用户进入前已显示的弹性接触后世界，没有把局部碎片合并回世界。局部计时与轨道计时分开，来源时刻记录在 `simulation.impact.sourceTimeSeconds`。进入时调整局部镜头，并非已完成跨尺度一镜到底或实时双向耦合。

## 粒子初始化

`Experiment::setUp` 检测内部入射上下文后，直接使用局部质心三维向量，不沿用独立实验的固定 X 方向速度、横向偏移或额外初始间距。

- 双方体积、密度和质量来自真实事件；不会缩小行星或替换密度。每颗岩体使用原 OpenSPH 球形采样器，分别分配 3/4 与 1/4 的粒子预算。界面当前固定 600 预算，实际数量由采样器决定。
- 上游按球体体积与密度分配粒子质量。本地检查总质量偏差不超过 1e-6 后，只修正数值归一化误差；再把每颗采样云的质量加权中心平移到记录的局部中心，逐粒子施加对应三维平移速度。采样云是离散近似，未做表面分辨率收敛验证。
- 本版明确采用冷态、无初始损伤、无自转的均匀玄武岩模型，开启现有粒子自引力，不预松弛。材质贴图不定义物理成分；源轨道没有材料或自转状态可继承。
- 隔离模型没有外部引力；含潮汐模型把同一时刻外部快照的冻结线性场加入粒子加速度，仍没有外部反作用，见 [模型与筛选](IMPACT-TIDES.md)。两体接触瞬间的入射半步速度来自轨道积分，不能称为连续精确解。

材料采用现有 Tillotson、von Mises 和 Grady–Kipp 路径。本批没有改动材料方程，热软化含义仍遵循 [材料响应](SPH-MATERIAL-RESPONSE.md)，不等于温度、液相比例或连续熔岩表面。

## 事务与返回

native 启动校验场景修订号、接触序号、最新暂停状态和尺寸／密度／撞速预算，过期或重复请求拒绝。初始化期间保留原世界帧；第一份有效 SPH 帧发布时才替换显示历史。准备失败会恢复原轨道；准备中取消和运行中返回都释放局部分支并恢复原轨道。运行后的数值失败保留可返回入口，便于查看错误后返回。

分支期间禁止载入其他实验、普通配方保存和修改初始条件，避免把实际入射向量丢成普通预设。可以保存局部回放；返回轨道后再加载。该限制在共享动作目录、字段目录和 CLI 入口一致。加载独立局部回放时没有父世界，返回按钮不出现，但可以正常切换到其他实验。

原生返回保存的是整个进入前的轨道会话，不是接触瞬间的全世界回滚。每次分支只有一个父会话，不能嵌套；返回后再次分析同一接触属于主动重做局部实验，不是已实现的物理事件消费与残骸回注协议。应用进程退出后内存中的父会话不会随局部回放自动恢复，重要世界应先保存轨道回放。

## v17 基础回放布局

隔离的局部 SPH 使用 v17 基础；含外部潮汐使用 v19 基础，当前均通过 v20 扩展保存，布局见 [潮汐回放](IMPACT-TIDES.md)。逐帧布局沿用 v15；在原 136 字节配置部分之后增加 156 字节入射记录：uint32 接触次数、两个 int32 索引、double 时间与法向速度，随后两个天体各 8 个 double（质量、半径、三维位置、三维速度）。逐帧保留粒子、材料标量、结构、团块与响应。

读入核对上下文与局部配置一致、入射几何、有效数值和版本。v17 不能降级成缺失入射记录的普通回放；它是观察回放，不含完整求解器状态，也不包含父轨道。旧 v14／v16 轨道与 v15 SPH 路径继续兼容。

## 验证与后续

原生测试独立汇总真实采样粒子的质量、三维质心、动量、动能与角动量；随后执行含斜向和垂向速度的局部碰撞，检查热量增长、质量保持、来源回读、损坏拒绝、准备取消及父世界恢复。应用验收另覆盖 60 秒演化、语义按钮和镜头／外观返回。详见 [0.54.0 记录](../releases/RELEASE-0.54.0.md)。

0.55.0 已加入可选冻结潮汐；下一步是时变外部场、反作用与世界时间耦合、连续局部镜头、可恢复的事件协议、碎片束缚判定和回注。行星尺度、分层材料、真正相变、冷却和月球形成仍未完成。
