# 碰撞前的岩体预松弛

> 类型：当前物理准备流程；适用版本：0.36.0；验证日期：2026-09-08（Asia/Shanghai）。

## 接入方式

当前导入的 OpenSPH 提供 `StabilizationSolver`，包装普通求解器并衰减速度、恢复材料初始损伤；上游说明与模型背景见 [项目说明](https://github.com/pavelsevecek/OpenSPH)。本次选读本地固定版本 `core/sph/solvers/StabilizationSolver.h`、`core/run/jobs/SimulationJobs.cpp`、`core/run/IRun.cpp`、`core/quantities/Storage.cpp` 和初态生成器；不修改第三方内核。

预松弛只适用于开启材料自引力的岩质实验，选项为关闭、16 秒、64 秒，预算仍不超过 1200。每个岩体在原点单独生成、以静止状态运行准备求解器；准备时两个岩体不相互施力。固定步长 0.0625 秒，阻尼系数从 0.5/s 线性衰减到零。每步执行真实压力、固体应力和软化自引力，再由上游包装器衰减速度并重置损伤。

定时结束后清零剩余准备速度和最高阶导数，保留演化后的粒子位置、平滑长度、密度、内能和应力；再给主天体加入请求的自转，给撞击体平移位置并加入请求的撞击速度。两个 Storage 按原身份合并，交给普通碰撞求解器，第一帧为 0 秒。旋转岩球只准备一个静止球体，之后才加入自转，因此并不是旋转平衡初态。

准备阶段分别显示 `relax-target`、`relax-impactor`，支持逐步检查取消。取消后不能继续提交旧帧或把旧材料混入新请求。阻尼、损伤恢复和最后的速度清零是耗散的初值操作，不计入碰撞时间或其能量曲线。

## 对照结果

四组单体实验以相同预算、种子、100 km 半径和默认玄武岩材料运行；仅改变阻尼系数 0／0.5，均采用同一个上游损伤恢复流程。对每步的质心系动能取时间平均，另外保留结束瞬间数值。

| 预算 | 准备时长 s | 平均动能：阻尼／对照 | 末帧动能：阻尼／对照 |
| --- | --- | --- | --- |
| 200 | 16 | 0.1946 | 0.3052 |
| 200 | 64 | 0.1027 | 0.2287 |
| 600 | 16 | 0.1914 | 0.3060 |
| 600 | 64 | 0.0831 | 1.4602 |

最后一组末帧动能更高，说明不能把单一终点当作收敛指标。上述结果只说明这些算例全过程的运动受到抑制，不能证明达到静力平衡，也不能证明移除阻尼后长期稳定。测试同时检查质量逐粒子不变、有限状态、尺度没有异常塌缩、演化密度保留、速度重置及取消。

## 使用与保存

实验库新增“直接生成，相同撞击”和“先准备，再相撞”对照：都开启自引力、预算 200、速度 5 km/s、偏移参数 30°、正式计算 16 秒，仅预松弛配置不同。两组复用岩体概念封面，参数与实际求解相连。

界面、CLI 和模型身份见 [CLI](../CLI.md#sph-预松弛)。预松弛新模型为 `sph-rock-prepared-v1`；v9 回放在配置头后附加准备时长，帧数据继续保存原十项和四项结构诊断。旧回放不启用准备，不会把已有历史重新计算。

## 后续通过条件

仍需步长／空间分辨率敏感性、完整材料能量与耗散记录、解除阻尼后的自由演化、压力与重力残差和收敛判据，再讨论更长准备、自动收敛或分层天体。当前固定 16／64 秒结束不能显示“平衡完成”。手机与真机性能没有验证；1200 预算仅覆盖准备取消，不声称最大预算长时准备已验收。
