# 材料团块的连续跟随

> 类型：当前交互与实现参考；适用版本：0.40.0；验证与更新日期：2026-09-08（Asia/Shanghai）。

## 选择与运动

从 [几何团块](SPH-FRAGMENTS.md) 列表选择一团，或快捷选择当前最大团块。原生渲染使用该团实际质量加权质心作为镜头目标，保留旋转、缩放、着色和全部材料绘制。选择、停止与镜头操作不重新计算材料，也不移动回放时间。

选择保存本场景中的一个粒子序号 seed。每帧用 labels[seed] 找当前团块，再读取其质心。因此排名改变不会改选其他团；分裂时跟随 seed 所在分支，连接时跟随其所在合并团。最大团块按钮只在点击时选最大，不持续追逐质量排名第一名。

当前 SPH 路径没有接入动态增删、合并粒子或存储重排，序号仅在同一场景内有效。新增这类求解操作前必须改用显式材料身份映射。这里没有建立持久碎片 ID、全部后代谱系、引力束缚或再聚合。

镜头按 `1-exp(-dt/0.12s)` 的响应系数趋近实时质心，误差小于 1e-5 显示单位时贴合目标；100 km 为一个显示单位。静止目标的响应不依赖渲染帧率。运动中可能存在跟随滞后，不把 moving=false 当成物理停止条件。停止跟随也平滑回到常规观察中心。

## 生命周期与界面

| 操作 | 结果 |
| --- | --- |
| 回放前进／倒退 | 保持 seed，从目标帧重新解析其团块 |
| 旋转／缩放／换色／翻页 | 保持 seed、场景和时间 |
| 折叠／展开／横竖屏 | 保持 seed，视口构图随布局调整 |
| 停止跟随 | 返回常规观察中心，保持镜头朝向和缩放 |
| 返回全景／选择原天体／复位 | 结束团块跟随，执行已有镜头动作 |
| 返回键 | 先关面板，再结束团块跟随 |
| 显式 setCamera／载入回放／换实验 | 结束跟随，旧场景序号失效 |

跟随为会话内观察状态，不保存到配方或回放。v10 分组格式保持不变；旧 v1–v9 缺失分组时入口禁用。HUD 和观察列表显示当前质量排名及粒子数，列表着色与画面对应。

渲染从同一个受锁保护的快照读取场景修订与所选帧。新请求到达后，旧帧不得清除它；状态读取也屏蔽已过期场景的跟随信息。显式命令校验场景和粒子范围，失败不改变目标。

## 验证

`./scripts/test-fragment-follow.sh` 以 AddressSanitizer／UndefinedBehaviorSanitizer 检查过渡、停止、分裂／连接、排名变化、倒放、帧率、场景失效与迟到旧帧。共享动作检查覆盖 CLI 与按钮处理、旧场景拒绝、颜色／缩放保留和返回操作。

实际应用测试独立解码保存的 v10 文件，使用其标签和双精度质心核对回放首／中／末帧的跟随目标及实际显示中心；验收脚本为 `scripts/test-fragment-follow-emulator.mjs`。三布局命中测试为 `scripts/test-fragment-follow-layout-emulator.mjs`。两者都会更换当前实验，执行前必须备份用户会话及保存槽。

原始证据、截图和限制见 [0.40.0 记录](../releases/RELEASE-0.40.0.md)。这是观察操作升级，没有修改材料求解方程或证明行星撞击精度。
