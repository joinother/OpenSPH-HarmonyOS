# 星图视频录制与导出

> 类型：当前功能说明；引入版本：0.48.0；更新日期：2026-09-08（Asia/Shanghai）。状态：实现与模拟器不支持提示已验证，实际录制与导出待真机验收。

## 操作

顶部「视频」打开录制窗口。选择标准（长边最高 1280）或高清（长边最高 1920），点击「开始录制」，可继续移动镜头、播放回放或运行实验。悬浮计时按钮用于停止；停止成功的视频进入本机视频列表，可预览并通过系统文件选择器「导出 MP4」。取消导出保留本机副本。

视频只接收原生星图画面，不包含 ArkUI 菜单、状态栏或其他应用，不采集麦克风，输出无声 H.264/MP4。显示摄影银河时，视频画面保留 ESO/S. Brunier、CC BY 4.0、来源和改编说明；文件元数据另记录资源来源。

录制按现实时间进行，目标最高 30 帧/秒，不保证每秒都有 30 个渲染帧。它不是固定步长离线渲染，也不改变求解步长。暂停实验仍可录制镜头和外观变化；回放速度沿用现有回放控制。

开始时按设备编码能力选择实际尺寸，保持原视口比例且不超过所选上限。录制画幅随后固定，旋转或展开时完整画面按比例装入固定画幅，必要时留黑边。每段最多 3 分钟；进入后台或页面销毁时请求结束录制。锁屏、来电、折叠过程中的系统资源行为还需真机验证。

## 保存与异常

- 本机目录为应用私有 `files/videos/`，完成的文件独立保存，不覆盖先前视频；卸载应用会删除这些私有文件，需要留存的视频应导出。
- 编码时使用 `.mp4.part` 临时文件。停止、释放编码器并通过视频时长和尺寸检查后才改名为 `.mp4`；中断或失败文件不会列为成功视频。未完成文件可能留在私有目录，当前没有自动恢复或删除入口。
- 导出使用 `DocumentViewPicker.save` 提供的目标 URI，以文件描述符复制并同步落盘。取消或失败保留来源；目标选择、读写拒绝及真实播放须在设备上验收。
- 不支持所需 H.264 编码的设备明确提示使用支持录制的真机，不启用软件编码。当前模拟器能力查询只返回 AAC 音频编码器，因此不能验证实际录制。
- 本版未增加系统录屏、音轨、剪辑、离线逐帧导出、自动上传或云端服务。

## CLI

按钮通过 `uiAction` 共用 ArkUI 实现。

| 命令或动作 | 含义 |
| --- | --- |
| `getVideoCapabilities` | 查询系统编码器列表；录制或导出操作中不可调用 |
| `getVideoState` | 状态、实际尺寸、现实秒数、提交帧数、本机视频、预览就绪或错误 |
| `video.open` / `video.close` | 打开或关闭视频窗口，不停止正在录制的星图 |
| `video.quality.1280` / `video.quality.1920` | 选择尺寸上限；实际尺寸服从设备能力 |
| `video.start` / `video.stop` | 准备并开始／停止并完成 MP4 |
| `video.reload` | 刷新本机视频列表 |
| `video.select.<id>` | 选择列表内的视频；不存在的 ID 不可用 |
| `video.preview` / `video.preview.close` | 打开／关闭内置视频预览；播放控件由系统 Video 组件提供 |
| `video.export` | 打开系统保存位置选择器；CLI 等待人工选择后返回 |

首次使用先查询 `listCommands` 和 `getUiState`。涉及文件选择器时需给 CLI 留出选择时间，例如 `--timeout 120000`；CLI 超时不会自动取消已显示的系统窗口。

## 真机验收

本轮按用户要求不为模拟器增加软件编码。以下项目尚未获得真机通过证据，不能据构建或模拟测试宣称已录制成功：

1. 查询到 H.264 编码器；分别录制行星近看、SPH 碰撞、星系演化及地面观察，每段至少 10 秒。核对颜色、上下方向、画幅、镜头运动、素材署名及无菜单遮挡。
2. 测试两种尺寸、录制中旋转／折叠、后台／锁屏、立即停止、3 分钟上限和连续多段录制。停止后应恢复原星图且旧视频仍在。
3. 预览、暂停与拖动系统播放进度；导出到用户选定位置，用系统播放器播放，检查时长和画面；取消与拒绝写入不得删除本机副本。
4. 检查录制时渲染帧率、能耗和编码资源释放；遇到失败保留 `getVideoState`、`getVideoCapabilities` 和应用日志。

## 依据与实现

按照华为 [视频录制指南](https://developer.huawei.com/consumer/cn/doc/doccenter-capabilities/video-recording) 的 AVRecorder / InputSurface 流程，实现 ArkTS 管理编码生命周期、原生渲染线程向 Surface 提交星图画面；使用本地 SDK 的 MediaKit、NativeWindow 和 CoreFileKit 声明核对接口。元数据检查使用 AVMetadataExtractor。

源码入口：[SceneVideo.ets](../../entry/src/main/ets/common/SceneVideo.ets)、[video_output.cpp](../../entry/src/main/cpp/video_output.cpp)。没有新增第三方编码库。
