# 0.5.0：浮在宇宙上的工具

> 类型：历史归档（不作为当前操作指南）；适用范围：历史版本。
> 整理日期：2026-09-06（Asia/Shanghai）。

本文保留当时的判断、限制和操作记录，可能已被后续版本替代。请先阅读[当前文档目录](../README.md)。

这一版移除上下整条深色衬底，让原生模拟视口保持连续。顶端是独立工具胶囊，底部是限宽的时间胶囊与三个悬浮操作，四周留出能看到宇宙的空隙。深空背景配冷白文字，用少量淡紫色标记当前工具和主要操作；天体原有的青色、橙色仍表达对象身份。

圆角分为两档：按钮与时间轴为胶囊，编辑面板为 28 vp 圆角。面板使用细描边、局部阴影和背景模糊材质；表单保持可读，不把整个页面做成模糊层。新增图标是本项目自行绘制的 SVG，没有引入外部素材包。

## 已查阅的华为依据

通过华为开发者知识 MCP 的 searchDocuments 搜索，并通过 getDocumentsById 读取了动态模糊、组件内转场、组件动画全文；同时核对本地 API 24 SDK 并编译验证。

- [组件内转场](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-transition-animation-component)：使用 TransitionEffect 组合透明度、平移和缩放；进入与离开分别设置参数，稳定的组件 ID 支持动画打断时复用节点。
- [组件动画](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-component-animation)：借助组件自身反馈与弹簧曲线增强操作反馈。此项目只对交互元素添加动效。
- [动态模糊](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-blur-effect)：对局部浮层设置背景材质，控制覆盖面积，保留文字对比度。
- [沉浸光感](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-immersive-light-sense)：MCP 返回的新通用接口从 API 26 开始，当前构建使用 API 24，因此本版没有调用该新接口。HDS 指定组件的较早能力也不能等同于任意自定义浮层都支持。

当前实际采用 backgroundBlurStyle、TransitionEffect、curves.springMotion 与 UIContext.animateTo。原生 Surface 背景采样和材质表现需继续在真机核验；本版没有承诺 API 26 的光学材质效果或全设备恒定帧率。

## 动作设计

| 操作 | 实现与目的 |
| --- | --- |
| 打开面板 | 透明度、32/42 vp 位移与 0.97 缩放组合；springMotion(0.36, 0.88)，帮助理解浮层来自哪个方向 |
| 收起面板 | 170 ms 淡出并轻移，退出时禁用操作，保留画面连续性 |
| 切换面板内容 | 90 ms 淡出/轻移，180 ms 淡入；序号丢弃过期回调 |
| 按压按钮 | 缩至 0.94/0.95，再以弹簧曲线回弹，取消触摸时恢复 |
| 专注与恢复 | 顶部轻移淡出、底部弹簧位移，原生视口始终保留 |
| 缩放和复位视角 | 320 ms 缓动；新的手势、CLI 相机设置或重建实验取消未完成的镜头运动 |

弹簧的实际收敛时间由曲线决定，不能把 response 直接当成固定时长。物理时间、求解状态和时间轴定位不添加插值来伪造计算进度。

## 接下来真正需要补的物理能力

当前引擎仍是有限规模的岩质 SPH 实验。要走向可编辑的宇宙沙盒，优先顺序应是：

1. 多体引力和轨道：独立的 N-body 场景、位置/速度编辑、添加删除对象，配套两体轨道、能量和角动量误差测试。
2. 宇宙浏览：星表、历元与坐标系、按层级加载、远近尺度切换和纹理分级；与本地活动的动力学对象分开管理。
3. 轨道与碰撞衔接：在局部事件中转入高细节 SPH，并验证转换前后的质量、动量与能量处理。
4. 设备与发布：真机计算预算、发热与内存分档，平板/电脑输入和自由窗口，签名与分发。

这需要分阶段推进；浏览到的所有星体不应同时采用同一种高细节碰撞求解。Celestia 与其他项目的复用范围仍按此前的评估逐项确认。
