## 预研核对与行为变化

重新核对本地 Universe Sandbox、Celestia、程序化生成和国内运营预研的实施章节，补充 [预研实施对照](../reference/RESEARCH-IMPLEMENTATION.md)。本轮选择博客／论坛第 04 项的 A/B 缺口：此前 SPH 主题切换会重算，无法在同图中保留两次结果；现在可保存独立 SPH 参照，跨实验与应用重启保留。

九种 SPH 指标使用青色当前／金色参照和共同坐标轴，显示已应用参数差异及范围内游标差值。原始采样导出最多 480 行，附模型、单位与配置；插值只用于显示差值。旧结构指标缺失、采样时间不重叠和坏文件都明确处理，不补零或外推。参照可替换、隐藏、移除，与轨道参照分开保存，操作和 CLI 共用实现。详见 [SPH 对照说明](../reference/SPH-COMPARISON.md) 与 [CLI](../CLI.md#sph-两次实验对照)。

- [三布局验收](../evidence/comparison-0.38.0-layout.json) 实际点击保存和隐藏／显示，验证应用参数来源及历史保持；展开、折叠竖屏和横屏截图已逐张目视检查。未测动画帧率或真机性能。
