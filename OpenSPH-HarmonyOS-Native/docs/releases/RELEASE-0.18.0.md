# 0.18.0 · 环影之间

> 类型：版本记录；适用版本：0.18.0；实现与验收日期：2026-09-06（Asia/Shanghai）。

新增带环气态行星和第七个主题“环影之间”。进入实验后从暂停的近看视角开始，旋转镜头观察条纹、环面分缝和影子，也能返回全景继续轨道计算。

## 行为与实现

- 新材质 `surface:4` 使用原创程序条纹及云纹，保留 1 海洋、2 厚云、3 荒漠。编辑和放置均可选择“带环”，沿用草稿、确认、撤销／重做及命名实验保存流程。
- 三维薄环通过视线与倾斜环面的解析相交绘制。球体与环带在同一着色器内按交点深度合成，包含径向透明度、分缝、正反面光照、行星投向环面的影子及环面对球面的遮光。细条纹按投影尺寸过滤；严格侧视时环面投影面积为零。
- 近看过渡为环带外包范围预留空间；开关环带保持球体大小和镜头不变。近看、返回全景、折叠和旋转复用既有连续镜头，不重新加载场景。
- `appearance.rings` 与 `setAppearance {rings:boolean}` 复用界面动作；错误类型在修改任何外观参数之前拒绝。CLI 目录与状态包含新选项，见 [操作指南](../CLI.md#外观与相机)。
- 材质 4 随初始条件及 v4 回放保存。验收发现回放读取仍限制旧材质编号，已修正并补充回归；非法编号 5 仍拒绝且保持原状态。

## 模型边界与下一步

“环岚”是虚构天体：太阳质量恒星、约 0.0002857 太阳质量的行星、约 1 AU 初始距离、1 年计算时长，不是真实土星轨道。环面内外边缘为显示球半径的 1.24–2.26 倍，外观轴相对场景 +Y 固定偏转约 27°，这些固定美术参数不用于轨道计算。

本版没有环粒子动力学、环碰撞、自引力、潮汐破碎或月球形成。尺寸仍放大；不同天体的材质整体按中心深度排序，尚非任意相交天体的精确透明排序。阴影采用单恒星、平行光与球体／零厚度环近似，未加入多光源、半影与体积散射。环面不单独响应点选。

环带开关、主题身份和镜头仍属于会话状态；材质编号随天体保存。包含材质 4 的文件需 0.18.0 或更新版本读取，旧版本会拒绝；本版保留旧文件读取。没有声称验证真机触摸、传感器旋转、持续帧率或科学收敛。

本轮沿用 [已收集的 SpaceEngine 资料](../research/SPACEENGINE-2026-09-06.md) 中环带光照与连续镜头的功能思路，代码、纹理和封面均为本项目实现，未导入闭源程序或素材。下一步优先建立行星中心的局部轨道与环粒子数值基线，再增加可量化的实验曲线；SPH 压力／内能／损伤、自引力和完整检查点仍按既有路线推进。
