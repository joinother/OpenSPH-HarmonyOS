# 0.32.0 — 每颗行星独立的地貌与云层

> 类型：版本记录；版本：0.32.0；实现与验证日期：2026-09-07（Asia/Shanghai）。

## 变化

以前同类行星共享同一地貌。现在自定义系统的虚构行星分别保存地表与云层种子，观察面板顶部提供“新地貌”“换云层”“撤销外观”“重做外观”。只换云层时大陆保留；这些操作不重新提交物理初值，也不重置相机、原生视口、模拟时刻或回放选帧。

原生端增加单线程后台生成，最多八个槽位，按行检查已被新请求替代的任务。保持上一张有效纹理，完成后用 350 ms 材质过渡更新。ArkUI 和语义 CLI 共用修改入口，提供待完成数量与错误状态。

复制行星保留地貌；删除前面的行星后，其余天体保留原配方。外观历史独立保存最近 20 次操作；天体初值历史连同外观关联一起恢复。命名实验新增 v3 外观配方，旧存档读取不随机改换大陆，恒星与 NASA 月面保留原素材规则。详见 [当前指南](../reference/SURFACE-GENERATION.md)。

## 边界与下一步

本轮扩展项目自有程序化纹理，没有引入 NPGS 或 GPL 候选实现。种子决定外观，不改变内部材料、碰撞半径或物理 seed。当前陨坑仍是明暗示意，没有高度网格、法线起伏、大气流体、物理散射或新的 SPH／自引力能力。

新增纹理为固定 512×256，尚未接入按投影大小分辨率分档。生成状态中的完成数量指 CPU 结果；没有逐天体 GPU 回执、真机功耗／帧时间或跨 GPU 逐位一致性保证。回放文件不保存新增外观，使用命名实验保存配方。后续沿程序化路线继续海平面／大陆尺度、地形细节与大气，同时独立推进 SPH 验证。
