# 0.26.0 · 看见轨道中的变化

> 类型：版本记录；版本：0.26.0；验证日期：2026-09-07（Asia/Shanghai）。本版为模拟器未签名交付。

## 行为变化

观察面板新增距离与速度曲线。选择某颗行星后，可以观察它到恒星的距离、系统质心系中的速率随时间变化；全景或选中恒星时默认观察第一颗行星。显示实际采样时间范围、纵轴单位、当前读数和保留记录中的最小／最大值。

“记录最小”“记录最大”暂停演算并跳到对应历史帧，保留镜头、参数、编辑草稿和同一渲染视口。原时间轴也会同步曲线游标。打开曲线和切换指标只读取数据；不触发积分或场景重建。ArkUI 按钮与 CLI 共用动作，接口见 [CLI 指南](../CLI.md)。

新增原生只读历史接口与带修订号／时间校验的定位接口。历史达到 240 帧后会滚动，场景替换也会改变索引含义；定位在同一锁中校验并拒绝过期引用。轨道回放沿用既有快照格式，可重新生成曲线；没有新存档版本。

## 数据边界

曲线只覆盖最近最多 240 个显示／回放快照，横轴按实际时间绘制，不保证包含完整轨道或初始时刻。距离为三维中心距（AU），速率为质心参考系中的 km/s，均来自既有单精度快照。采样极值不能等同于连续轨道近远点；视觉曲线不是新的科学精度保证。

无记录时显示等待提示，单帧可读取但尚不能形成变化曲线；近乎平坦的数据保留有界纵轴，避免除零。SPH 不显示轨道曲线。指标选择不写入实验配方，尚无跨实验曲线叠加、完整历史、CSV 导出、卫星摄动或新增碰撞物理。
