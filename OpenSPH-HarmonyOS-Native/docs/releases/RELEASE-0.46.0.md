# 0.46.0 · 盘内天空与地表观察

> 类型：版本变更与验证；版本：0.46.0（1000047）；调研、验证与记录日期：2026-09-08（Asia/Shanghai）。

星系实验现在可以从主盘太阳半径附近观察天空：同一示踪点随当前记录运动，来访星系的方向和形态随时间改变。太空与地表视角共用回放，不重算；地表可调纬度及独立恒星时，使用水平镜头和地平线遮挡。外部镜头保留，专注模式隐藏新增工具；所有按钮和五项观察输入接入语义 CLI。

## 实现与范围

- 原生引擎原子返回当前帧、首帧和场景身份；以首帧约 8 kpc 位置选定固定粒子索引。重建或载入场景后退出旧观察模式，v12 星系回放可以重新进入。
- 新天空通道用实际相对方向绘制等权示踪光斑与细点，隐藏自身及旧摄影银河；实例化四边形不依赖设备点大小上限，柔和叠加降低密集区过曝。
- 太空采用盘面角度，地表采用当地北／东／天顶方向；短边视场 35–120°，纬度 ±90°，当地恒星时 0–24 h。固定 J2000 朝向只作类比，不将 Myr 时间换成未来地球日期。
- 新增 `getGalaxyObserver`、五个 `galaxy.observer.*` 动作和五个输入；`getState` 包含观察位置与已提交渲染帧的模式／时间。外部镜头、着色和背景的普通动作在盘内模式禁用，返回后恢复。

这仍是 [限制性潮汐模型](../reference/GALACTIC-TIDES.md) 的观察原型。未校准真实银河系／仙女座初值，未实现自洽合并、气体、尘埃消光、真实恒星亮度、光行时或 AU 层级太阳系。薄盘和等权采样仍限制天空真实感；地面色带不是物理大气模型。详细坐标、文献及下一阶段条件见 [盘内天空指南](../reference/GALAXY-OBSERVER.md)。

## 复现与截图

先备份活动实验和回放槽，再执行 `scripts/test-galaxy-observer-emulator.mjs 127.0.0.1:5555`。专注补验脚本要求保存槽内有星系回放；所有验收会切换当前场景，调用者负责恢复。普通操作可使用 [批处理示例](../../examples/galaxy-observer-batch.json)。
