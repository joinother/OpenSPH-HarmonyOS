# 0.33.0 — 环带与粒子共同运动

> 类型：版本记录；版本：0.33.0；实现与验证日期：2026-09-07（Asia/Shanghai）。

## 变化

此前固定环面与 192 个示踪点各自显示，点离开初始环形时，两者分离。本版使用 8192 个实际运动粒子生成浓度图，环面、环影和可选颗粒共用位置数据；没有额外不随运动变化的环面叠加。静态普通环使用同一模型的初始图。

新增局部径向速度扰动，峰值可调 0–0.35 倍圆轨道速度。给环一小块区域注入速度后，各粒子在中心引力下演化，整条环的浓度和形状随之改变。强度改变时归零并暂停，单独开关颗粒则保留时间和播放状态。环控制移到观察面板顶部，按钮、滑块和语义 CLI 共用动作；配方保存扰动、颗粒显示和环模型版本。

修复切换场景时旧渲染帧误关掉新实验环模式的竞态。微小扰动的初始偏近点角计算避免消减误差；初始方位改用确定性散列，去除规则黄金角采样在差分转动下形成的人工螺旋队列。

## 边界与后续主线

本版解决环面与运动分离，**没有完成整颗行星碰撞**。环粒子仍无质量、只有中心引力；扰动是受控初始速度注入，没有撞击体、互撞、自引力或卫星摄动。缝隙为初始设置；浓度映射不是物理光学厚度。局部环仍使用独立时钟，查看其他天体会退出局部模式。有限采样和平滑核仍会产生可见颗粒起伏，不能解读为真实环的密度波。

当前 SPH 材料碰撞仍是小岩体初值，缺少分层行星、静水平衡、自引力与再聚合。下一阶段优先推进这些基础及同一材料分布的连续表面，再连接主轨道与局部材料模拟；验收条件见 [物理主线](../reference/RING-AND-COLLISION.md)。新增纹理和外观控件不作为这些功能完成的替代。
