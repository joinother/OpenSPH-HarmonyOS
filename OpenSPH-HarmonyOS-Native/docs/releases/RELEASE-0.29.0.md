# 0.29.0 · 追踪碰撞如何变化

> 类型：版本记录；版本：0.29.0；实现／验证日期：2026-09-07（Asia/Shanghai）。

## 本轮功能

SPH 观察面板新增五种随时间变化的曲线：峰值压力、质量加权平均比内能、质量加权平均损伤、总动能与总内能。横轴使用保留快照的实际秒数，纵轴按真实记录范围缩放；当前时间轴位置以游标标出。选择“记录最小／最大”可以回到对应采样帧，保留相机、场景与原生视口。

压力／内能／损伤着色与对应曲线联动；单独切换曲线不会改变着色或重算。峰值压力表示每帧所有粒子中最大的压力；它和面板中质量加权平均压力含义不同。平值多次出现时定位最早保留样本。最小／最大仅属于最近 240 帧，不称为连续物理极值、接触判定或碎片生成事件。

CLI 现在既能读曲线，也能导出全部十项双精度诊断的原始 CSV 与来源配置 JSON；导出不插值，已有文件拒绝覆盖。曲线接口只返回所选指标，避免把十项历史和绘图路径一起塞入单次 CLI 返回。使用方式见 [CLI 指南](../CLI.md#sph-曲线与原始数据导出)。

## 与 SPH 内核的连接

[原生 Engine](../../entry/src/main/cpp/engine.cpp) 在互斥锁内复制保留帧的十项诊断汇总，不从屏幕或单精度粒子反算。跳帧同时核对场景修订、帧索引与实际时间，防止重算、模型切换或历史滚动淘汰后定位错误帧。v5 回放沿用上一版格式，载入后自动得到曲线；旧回放缺失诊断时不造数据。

[曲线模型](../../entry/src/main/ets/common/SphObservationModel.ets) 处理真实间隔、单位、负压力、单帧／平值、游标和极值；[导出工具](../../scripts/export-sph.mjs) 保存 CSV 及元数据。新按钮与 CLI 共用处理，并保留原按钮／输入覆盖检查。

本批继续 [SPH 路线](../reference/SPH-DIAGNOSTICS.md#后续顺序与验收门槛) 的可观察性阶段。没有改动上游物理方程、材料参数、时间步或回放格式。动能和内能曲线尚不包括弹性应变能与引力势能，不能宣称完整能量守恒监控。
