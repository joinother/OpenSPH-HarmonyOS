# 0.48.0 · 星图视频录制与 MP4 导出

> 类型：开发断点；实现与模拟器验证日期：2026-09-08（Asia/Shanghai）；真机验收日期：尚未进行。

新增顶部「视频」入口、实际尺寸选择、录制计时与停止、本机视频列表、内置预览和系统文件选择器导出。视频源直接来自星图渲染，不包括界面菜单，采用鸿蒙系统 H.264/MP4 编码，无声音。录制中固定画幅并按比例适配新视口，后台请求结束；已完成的视频独立保留。按钮具有同源语义 CLI，见 [录制指南与真机验收](../reference/VIDEO.md)。

文件先写临时路径；停止、关闭资源及校验视频时长／尺寸后才加入列表。取消导出保留来源，导出失败有状态提示。摄影银河视频带素材署名和来源，元数据也记录授权信息。

## 已验证

- 97 项主机检查通过：既有 88 项 CLI/页面动作检查与 9 项录制生命周期检查。后者使用受控系统接口替身，覆盖重复开始／停止、后台取消、时长上限、句柄释放、导出取消／失败、编码能力边界和不支持设备；不是实际编码或导出文件的证据。
- 鸿蒙 HAP 构建与模拟器安装通过。当前模拟器只返回 AAC 音频编码能力，不具备 H.264 视频编码器；开始录制明确报不支持，没有生成成功视频，也没有改变实验历史。
- 根据用户要求撤掉试作的软件编码路径和依赖，当前源码及应用只保留系统录制路径。

证据：[主机检查](../evidence/video-0.48.0-host.txt)、[模拟器不支持路径](../evidence/video-0.48.0-device.json)、[构建](../evidence/video-0.48.0-build.txt)、[安装](../evidence/video-0.48.0-install.txt)。

恢复与补充检查：[原场景及保存槽恢复](../evidence/video-0.48.0-restoration.json)、[最终生命周期复查](../evidence/video-0.48.0-lifecycle.txt)。

## 尚待验证

尚未在真机实际录制、播放或完成系统选择器导出；系统编码 Surface 的画面、方向、色彩、时间戳、持续录制性能、后台／旋转／折叠的 MP4 完整性均待真机验收。本版是实现完成但尚未通过真机录制验收的开发断点。

未实现音轨、视频剪辑或离线逐帧渲染，不改变物理求解器及回放格式。失败时留下的临时文件当前没有恢复／清理界面。
