# 0.8.0 · 自定义行星系统

> 类型：版本记录（仅描述该版本）；适用范围：0.8.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

新增“自定义系统”：一个中心恒星与最多七颗行星共同参与双精度牛顿引力计算。可以增加／删除行星，编辑每颗天体的名称、质量、三维初始位置与速度，分别选择海洋、厚云或荒漠表面。初始条件、名称和表面类型会随命名实验保存，也会写入 v4 回放。

## 操作

参数 → 自定义系统 → 选择天体。行星质量以地球质量显示，恒星质量以太阳质量显示；位置是 AU，速度是 km/s。输入完成后点击“应用天体 · 重新生成”，系统会清空旧轨迹、重建并暂停。非法输入不会替换已有系统。切换天体会放弃尚未应用的输入；另存实验保存的是已应用天体与当前时长。

“添加行星”按中心恒星质量给出一个圆轨道初速和不重叠的候选位置，仍然需要运行观察稳定性。更改质量或位置不会自动修改已输入速度。恒星不能删除，至少保留一颗行星。近看时使用“上一颗／下一颗”循环观察全部对象，表面切换不改变物理质量。

自定义面板默认折叠预设列表，点击“切换实验”展开。轨道视口、悬浮按钮、近看过渡、云层／大气开关与现有安全区布局继续共用。

## 模型范围

| 项目 | 范围／行为 |
| --- | --- |
| 天体数 | 2–8；首个为恒星，其余为行星 |
| 恒星质量 | 0.1–2 太阳质量 |
| 行星质量 | 1e-8–0.01 太阳质量，界面换算为约 0.00333–3329.46 地球质量 |
| 初始位置 | 各轴 −10…10 AU；任意两颗间距至少 0.05 AU |
| 初始速度 | 三维速度模长 ≤100 km/s |
| 时长 | 1–10 儒略年 |
| 外观 | 0 恒星；1 海洋；2 厚云；3 荒漠。行星不能使用恒星类型 |
| 参考系 | 对整个系统统一减去初始质心位置和速度；保存的是用户原始输入 |
| 求解 | kick-drift-kick leapfrog，固定步长 1/32768 年，每 128 步发布预览 |
| 精度／遭遇 | 间距低于 0.02 AU 或能量归一化偏差超过 1% 时停止，不发布失败积分段 |

两种轨道预设继续使用原有 1/4096 年步长。自定义模式使用更细步长，仍然不适用于任意近距离轨道、卫星、双星、强散射或碰撞计算。恒星同样受其他天体引力影响，“中心”不是固定不动的锚点。停止时保留上一次有效预览帧。

能量诊断通常除以初始能量绝对值；当它小于初始动能与势能绝对值之和的百万分之一时，改用该和归一化，避免近抛物线轨道的零分母。角动量通常除以初始模长；初始角动量接近零时，使用由初始位置、速度与引力常数构造的尺度归一化。界面将自定义模式标为“归一化偏差”，这些指标不是轨道位置误差的严格上界。

行星仍是点质量，表面与放大的显示尺寸不参与碰撞、潮汐、海洋或大气计算。本版没有完成 N-body 与 OpenSPH 的碰撞耦合，也不是包含全宇宙目录的模拟器。

## 保存与实现

`SimulationConfig.orbitBodies` 保存各天体初始参数，场景模型为 `nbody-custom-v1`。ArkTS 与 native 均检查范围、名称、数量和初始间距；原生层同时拒绝非法 UTF-8 名称。配置完整通过校验后才替换系统。

v4 在原有配置块后保存有上限的天体列表、UTF-8 名称与外观编号，帧数据继续包含粒子、轨迹和诊断。读取过程中验证全部配置与帧后才切换状态，损坏文件不会破坏当前实验。v1／v2／v3 继续支持；回放是可视化历史，不是可续算检查点。外观开关和镜头状态仍属于当前会话。

渲染将对象编号与外观编号分开：最多八个对象共享四套纹理，轨迹颜色也按对应表面类型显示，不会为新增行星重复生成纹理。

## 参考与验证

本轮通过华为开发者 MCP 查阅 [TextInput 与键盘避让](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-common-components-text-input)、[UITest 输入指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/uitest-guidelines)。使用本地 API 24 SDK 严格编译检查接口。

复验入口：

```bash
node --test tests/cli_transport.test.mjs
./scripts/test-orbit-core.sh
./scripts/test-emulator.sh 127.0.0.1:5555
node scripts/test-custom-emulator.mjs 127.0.0.1:5555
node scripts/test-custom-ui-emulator.mjs 127.0.0.1:5555
```

设备脚本会替换当前实验和单槽回放。自定义 CLI 脚本最多创建一个“自定义八天体 · 验证”命名实验，复跑时复用该记录。验证结果以同目录的 `custom-*.txt/json` 为准，模拟器结果不代替真机性能与热稳定性验证。

本版验证结果：

- 12 项宿主测试通过，包括非法天体列表的原子拒绝、未配对 Unicode 代理项、空输入、增删边界、相机索引与配置复制。
- 数值基线通过：二阶收敛、十年预设守恒、三维圆轨道、质心转换、可逆性和近距离停止。
- ARM64 引擎回归通过：三个 SPH 预设、旧版回放、八天体三维积分、确定性、v4 全量往返、损坏／非法 UTF-8 回放拒绝、零角动量与径向下落停止。
- 设备 CLI 验证通过：八天体状态、第五颗之后的表面绘制、三维演化、实验库保存／载入与 v4 回放恢复。
- 展开 707.2 vp 与折叠 345.6 vp 的实际 UI 操作通过：新增、文本输入、两倍地球质量、荒漠表面、应用、近看、上一颗／下一颗循环、删除与边界检查。
- 云层、大气、外观自转的像素差异及后台暂停回归通过，四种材质与 SPH 显示未出现 GL 错误。

验收脚本对文本框使用普通字符输入，避开模拟器组合键注入的焦点异常；表单输入与 native 结果均实际核对。截图脚本改用每次唯一的远端路径，避免模拟器重复写同一 PNG 时残留旧文件尾部；没有修改截图像素来通过测试。

`examples/custom-system.json` 提供五天体示例，其中“远洋”具有倾斜轨道与两倍地球质量。模拟器实验库保存了“我的第一片星系”，可直接载入体验。
