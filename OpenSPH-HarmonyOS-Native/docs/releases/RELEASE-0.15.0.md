# 0.15.0 · 天体编辑撤销与重做

> 类型：版本记录；适用版本：0.15.0；实现与验收日期：2026-09-06（Asia/Shanghai）。

此前修改或增删一颗天体，会清除整个系统的编辑草稿；误删后也无法回退。本版为自定义天体初始条件提供最近 20 步撤销／重做，并保留未受当前操作影响的其他天体草稿。

## 行为

- 参数面板顶部增加撤销／重做，展示最近可撤销的操作；修改、添加、删除各作为一次事务。
- 应用只清除当前天体草稿；删除时其他天体草稿随索引移动，撤销删除可恢复被删除天体的参数和草稿。
- 新增“还原当前输入”，只撤掉当前天体未应用的输入，保持其他草稿和模拟进度。天体标签显示“草稿”。
- 无效输入不改写历史；撤销后的新提交创建新分支，旧重做分支失效。当前窗口缩放、折叠和旋转不影响编辑历史。
- 输入框回显已恢复的值时不再误标为新草稿；重复选择当前表面同样不产生草稿。
- UI 与 CLI 使用同一动作实现：`orbit.undo`、`orbit.redo`、`orbit.discard`；全部草稿及历史计数、操作说明通过 `editor.drafts/history` 可查，见 [CLI 指南](../CLI.md#天体编辑撤销与重做)。

## 范围

撤销／重做恢复的是天体初始条件、编辑对象及草稿，会清空旧轨迹，重建暂停的初始帧并回到全景。实验时长、名称等全局参数保持当前设置；它不提供任意历史物理状态的恢复，也没有增加碰撞合并或破碎模型。

历史和草稿保留在本次会话内，尚不持久化、不随另存实验或回放保存。切换预设、设置新场景、载入实验或成功载入回放会清除历史。放置期间和回放 I/O 期间不可撤销／重做。同步拒绝天体事务时，配置、草稿和历史保持原样；提交后发生的异步求解错误仍由现有模拟状态报告。

## 验收

- [29 项主机测试](../evidence/edit-history-host-tests.txt)：既有共用动作回归，以及编辑／增删回退、草稿索引恢复、20 步上限、分支、非法输入、原生接口同步拒绝和输入回显。
- [既有 UI／CLI 回归](../evidence/edit-history-ui-regression.json)：共用按钮、输入、放置、近看、面板、回放和批次失败处理。
- [构建](../evidence/edit-history-build.txt) 与 [安装](../evidence/edit-history-install.txt)。
- [模拟器事务与布局检查](../evidence/edit-history-device-tests.json)：使用真实 CLI 和 native 求解状态，覆盖回退到初始帧、草稿保留、删除、放置、还原输入及切换实验；检查展开竖屏、折叠竖屏和横屏面板内的撤销／重做按钮边界。

截图：[展开编辑](../../../OpenSPH-0.15.0-history-wide.png)、[折叠竖屏](../../../OpenSPH-0.15.0-history-phone.png)、[折叠横屏](../../../OpenSPH-0.15.0-history-landscape.png)。这些检查不代表真实触摸命中、动画帧率或真机传感器验收。

首次设备测试被脚本外的行星放置操作打断，随后将当前六天体初始条件另存到模拟器实验库，并保留 [当时的状态](../evidence/edit-history-interrupted-state.json)。后续检查发现并修复了输入回显产生伪草稿的问题；最终结果以本版验收文件为准。

验收后恢复原五天体演示、3 年计算结果和自动旋转，见 [最终状态](../evidence/edit-history-final-state.json)。验收期间保存的六天体实验仍在模拟器实验库中。

## 后续

继续完成草稿持久化与其余实验参数的撤销，再推进独立轨道数值对照和完整物理检查点。只有具备可靠的速度、积分状态与检查点，才适合实现当前时刻插入／发射天体和分支模拟。
