# 0.25.0 · 复制行星并放置

> 类型：版本记录；版本：0.25.0；验证日期：2026-09-07（Asia/Shanghai）。本版为模拟器未签名交付。

## 行为变化

自定义系统的天体编辑新增“复制并放置”。选择行星后沿用它已应用的质量与外观，生成独立的新行星草稿；月面和带环等五种表面均可复用。入口位于对象选择下方，来源与复制范围在预览中可见；未应用的编辑草稿不会被悄悄提交。

新轨道从相对恒星的 XY 平面圆轨道开始，优先参考原始相对距离并错开位置，再尝试有界的备选位置；候选仍执行质量、速度、坐标和最小间距校验。名称自动避重并限制在 48 字符内，不截断 Unicode 代理对。找不到有效候选时保留无效预览供修改，不允许确认。

可继续调整质量、距离、方位、倾角、速度和表面。取消保留原场景、镜头、回放帧与编辑草稿；确认会重建暂停的初始场景，作为一步可撤销操作，并支持重做和命名实验保存。修正放置帮助中“确认清空其他草稿”的过时文字。

界面与 CLI 共用 `orbit.copy`。`getState.placement` 提供来源索引和名称，普通添加或退出放置后为空来源；不引入新的存档格式。完整操作见 [CLI 指南](../CLI.md)。

## 模型与体验边界

这是质量／表面模板复用，不是运行中天体的完整克隆。不复制原位置、原速度、当前模拟时刻或局部环时钟；新圆轨道只使用二体解析初值，并不保证在多体扰动下保持圆形或长期稳定。已运行的主系统在预览期间按原规则继续，进入放置退出局部示踪模式。确认会清空旧轨迹，从零重算，不支持在当前时刻注入行星。

只接受自定义系统中的行星，恒星、满 8 个天体、放置中和 I/O 忙碌时不可复制。本轮没有引入新的物理求解、碰撞合并、卫星摄动或月球形成能力，也没有增加网络服务或外部资源。
