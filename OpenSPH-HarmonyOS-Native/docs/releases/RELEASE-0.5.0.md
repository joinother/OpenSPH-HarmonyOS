# 0.5.0 · 悬浮界面与过渡动画

> 类型：版本记录（仅描述该版本）；适用范围：0.5.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

根据“界面偏旧、按钮依附整块衬底”的反馈，重新设计了工具层：独立悬浮胶囊、限宽时间轴、淡紫强调色、统一圆角、矢量图标及局部背景材质。编辑菜单在窄屏四周保留留白，在宽屏浮在右侧；主画面仍保留完整原生视口。

新增面板弹簧进入、淡出退场、内容轻移切换、按钮按压回弹、专注模式过渡，以及平滑缩放和视角复位。连续切换时丢弃过期回调；新的镜头操作可打断旧动画。详细 API 依据、参数和后续物理路线见 [设计记录](../archive/DESIGN-0.5.0.md)。

已进行 ArkTS 构建与模拟器安装，并保留以下验收记录：

- [floating-host-test-results.txt](../evidence/floating-host-test-results.txt)：7 项宿主测试，包括关闭/重开时过期动画回调不会改变新面板。
- [floating-wide-device-results.json](../evidence/floating-wide-device-results.json)、[floating-narrow-device-results.json](../evidence/floating-narrow-device-results.json)：展开和折叠状态下的实际 UI 点击、面板边界、相机拖动、平滑缩放/复位、专注恢复和返回键；菜单切换保留原生配置及编辑参数。
- [floating-cli-device-results.json](../evidence/floating-cli-device-results.json)：命令传输、冷启动、参数验证、实际求解和回放回归。
- [floating-build-result.txt](../evidence/floating-build-result.txt)：最终构建日志。

已保存展开、折叠和面板的实际截图。HDC 连续截图只能达到约 2.5 次/秒，无法可靠呈现短动画；本机窗口录制也遇到停止时间异常，已终止录制。因此本版没有交付动效视频，不用低频截图合成来证明流畅性。动画已编入安装包，需在模拟器直接体验；真机帧率与功耗仍待专项测量。

刚从折叠切回展开时，首次冷启动 CLI 测试曾在 20 秒内收不到响应；随后状态查询恢复，稳定形态下重新冷启动并完成整个测试通过。当前记录不能确定这次超时的根因，后续应在真机和重复折叠/冷启动压力测试中继续跟踪。

测试只操作 `127.0.0.1:5555`，结束后恢复模拟器原来的展开形态，停在菜单收起的主画面。物理核心没有新增宇宙尺度的引力或轨道模型；本轮交付集中在交互和视觉。真机材质表现、功耗、系统减少动态效果偏好联动、键盘避让及鸿蒙电脑自由窗口仍需继续验证。
