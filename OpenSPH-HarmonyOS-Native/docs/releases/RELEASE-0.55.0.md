# 0.55.0 · 局部岩体撞击接入外部潮汐

> 类型：开发断点记录；实现与验证日期：2026-09-08（Asia/Shanghai）。

## 本批实现

接触点现在记录全部天体同一瞬间的状态，避免把弹性响应后的显示帧当成入射环境。新增“近恒星岩体撞击”初态，观察页可以选择隔离 SPH 或含外部潮汐的 SPH。潮汐项实际参与粒子加速度，保存逐帧潮汐势能；v18 轨道和 v19 局部回放保留对应来源。UI 与 CLI 共用新增动作，旧隔离入口继续保留。

外部场采用冻结线性近似，有时间、空间及变化速度筛选；外部天体不受反作用，父世界继续暂停，碎片尚不回注。局部时刻与源事件时刻分别公开，二者之和仅作时间对应标记。材料仍是冷态、均匀、零自转玄武岩，没有辐射加热、真正相变或连续熔融表面。详见 [模型、接口与回放](../reference/IMPACT-TIDES.md)。

## 已执行验证

- [主机检查](../evidence/impact-tides-0.55.0/host-tests.txt)：114 项通过，含新预设、动作可用条件、原生潮汐参数传递及实际模型身份；保留按钮／输入绑定覆盖。
- [原生潮汐验证](../evidence/impact-tides-0.55.0/native.txt)：解析拉伸／压缩、原点零差异引力、势梯度、独立精确点源对照、空间／时间筛选、独立 60 秒静态势积分能量检查。
- 同一原生记录含 641 粒子、8.12 秒 SPH 开关对照：动能相对差约 1.67e-6，说明外力进入实际求解；所记录能量项相对漂移约 2.19e-6，不包含弹性应变能，不能称为全系统守恒误差。v19 来源、势能、四种损坏拒绝和原世界返回通过。
- [轨道来源回归](../evidence/impact-tides-0.55.0/incoming-regression.txt)：v18 同时刻世界状态往返、定位、九种损坏拒绝、继续演化后来源不变、v14／v16 兼容。
- [隔离 SPH 原生回归](../evidence/impact-tides-0.55.0/isolated-native.txt)、[连续轨道回归](../evidence/impact-tides-0.55.0/orbit-regression.txt)、[SPH 专项回归](../evidence/impact-tides-0.55.0/sph-regression.txt)。SPH 专项使用 `--sph-only`；没有把旧全域轨道格式断言计作通过。
- [构建](../evidence/impact-tides-0.55.0/build.txt)与[指定模拟器安装](../evidence/impact-tides-0.55.0/install.txt)通过。
- [实际应用完整流程](../evidence/impact-tides-0.55.0/device.json)：641 粒子演化至 60.02 秒、材料内能增长、质量保持、潮汐势能和时间对应、v19 回放来源与诊断一致；返回后原轨道向量、时间、历史、镜头、外观及地表种子一致。已查看[模拟器页面截图](../evidence/impact-tides-0.55.0/local-tides.jpeg)，来源说明和返回入口正常显示。
- [隔离模式应用回归](../evidence/impact-tides-0.55.0/isolated-device.json)：既有 60 秒撞击、v17 来源／诊断、返回和独立回放退出通过；明确验证 v17 重载后不补造外部场。回归脚本截图改存构建目录，避免覆盖 0.54.0 历史证据。
- 最终构建把实验入口改为可换行布局；[通用 UI／CLI 回归](../evidence/impact-tides-0.55.0/cli-regression.json)通过，覆盖天体编辑／加入、镜头、面板、外观、播放、失败批次与新场景加载。
- [用户测试前场景恢复](../evidence/impact-tides-0.55.0/restoration.json)：原 6 天体系统、28.583309297356237 年、240 帧、暂停状态及镜头／外观一致；[13 个持久文件逐字节一致](../evidence/impact-tides-0.55.0/files-restored.json)，无额外或缺失文件。

首次应用验收在已完成约 60 秒演化后，因时间相加的不同计算路径相差约 1.4e-14 秒而触发严格相等断言，见 [原始失败](../evidence/impact-tides-0.55.0/ui-first-error.txt)。测试改为 1e-12 秒容差，不修改应用物理结果。主机新增测试的初次模拟对象未更新准备状态，修正模拟对象后全套 114 项重跑通过；[首次主机记录](../evidence/impact-tides-0.55.0/host-first.txt)保留。

未完成时变外部轨道、双向反作用、碎片回注和持久父会话。没有新增材料收敛、真机性能、触摸命中或动画帧率验收，也不把冻结场的适用性筛选当成误差证明。
