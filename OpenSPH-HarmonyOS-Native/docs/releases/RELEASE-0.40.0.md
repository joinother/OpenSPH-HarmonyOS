> 类型：版本记录；验证与整理日期：2026-09-08（Asia/Shanghai）；源码版本：0.40.0；设备：模拟器 127.0.0.1:5555。

团块列表新增“跟随”“跟随最大团块”和“停止跟随”。镜头平滑追踪所选材料所在团块的实际质心，旋转、缩放、颜色、回放前进／倒退和折叠旋转均保留目标。返回键、全景、换实验与载入回放有明确退出逻辑；全部入口接入共享 CLI。

选择以本场景材料粒子序号保持，按每帧标签解析当前团块，不按质量排名反复换目标。保持全部材料显示；不重新计算实验。v10 回放格式不变。完整语义见 [跟随参考](../reference/FRAGMENT-FOLLOW.md)。

## 边界与后续

本版保存材料点的选择连续性，未实现全部碎片谱系、物理束缚、引力再聚合或表面重建。镜头可能滞后于快速运动的质心；帧率不变性仅针对固定目标的响应测试，不是动画性能验收。本轮没有重跑数值物理矩阵或完成真机验证。

首次构建的新导出函数误放于匿名命名空间，已修复并重新构建。回放载入默认第一帧的行为已在验收脚本中正确处理。首轮应用检查出现一次完整状态响应第 0 块缺失，记录保留于工作区；后续等待改用短的跟随状态查询，完整验收重新执行，不对修改状态的命令自动重试。该现象未被认定为已修复的通用传输问题。

继续按 [碰撞主线](../reference/RING-AND-COLLISION.md) 处理力项残差、完整能量、重复性、空间收敛及持久材料／碎片身份。
