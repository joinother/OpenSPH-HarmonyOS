# 0.37.0：静止岩球释放后会怎样

> 类型：版本记录；验证日期：2026-09-08（Asia/Shanghai）；适用设备：开发模拟器 127.0.0.1:5555。

## 行为变化

单体岩球允许零速度系数，并增加“设为静止初态”，同时清除基础自转与附加自转草稿；总初始角速度显示也包含两项。碰撞场景的速度约束保持原值。按钮与 CLI 共用动作，编辑不改变当前历史或镜头。

实验库增加“静止岩球，会一直静止吗？”和“撤去阻尼之后”，可在同一组初始参数下比较直接生成与 64 秒预松弛后的 32 秒自由演化。正式计算使用普通 SPH 与自引力求解器，准备阻尼不带入正式演化。两组均支持命名保存和回放。

观察面板新增记录窗口的尺度最大偏离、平均相对动能、平均径向速度绝对峰值；动能按实际采样时间加权，回放游标不改变窗口统计。初始帧被淘汰后明确标记只相对窗口首帧，旧回放缺少结构记录时不显示该统计，CLI 返回不可用。CLI 新增 `getSphWindowSummary`。

实际验收发现满 240 帧、16 列 CSV 超过原 CLI 回复上限，已将应用与配套 CLI 的有界容量同步增加至 128000 个 UTF-16 编码单元、最多 256 片，保持原有 UTF-8 字节发送节奏。旧版 CLI 不保证接收较大的回复。操作见 [CLI](../CLI.md)，计算定义及完整数值见 [自由演化基线](../reference/SPH-RELEASE.md)。

## 验证

- [111 项主机检查](../evidence/release-0.37.0-host-tests.txt) 通过，包括不等间隔采样积分、窗口缺失初帧、零自转参数、草稿与按钮绑定，以及跨 128 片的 Unicode 回复和超限拒绝。
- [原生引擎回归](../evidence/release-0.37.0-native-emulator.txt) 通过：零初速、释放后运动、v9 回放、碰撞零速度拒绝及既有准备、引力、结构、轨道和取消检查。
- 十二组固定步长实验在 [桌面](../evidence/release-0.37.0-desktop.jsonl) 与 [鸿蒙](../evidence/release-0.37.0-emulator.jsonl) 完成，覆盖 200／600 预算、0／16／64 秒准备和两组释放步长。[分析](../evidence/release-0.37.0-analysis.json) 保留质量、质心、动量、残余运动及步长差异。减半步长只作用于释放阶段，所统计指标最大相对差约 1.60%；不能据此宣称数值收敛。
- [应用验收](../evidence/release-0.37.0-ui.json) 验证两个实验的零初速、32 秒计算、窗口统计与独立 CSV 积分一致、回放及命名实验往返，以及超过 240 帧后完整导出和首帧淘汰标记。应用使用自适应步长，固定步长实验是另一路数值检查。
- [三布局验收](../evidence/release-0.37.0-layout.json) 在展开、折叠手机竖屏和横屏实际点击静止初态按钮，核对两个草稿值、当前历史、镜头与窗口统计；截图已逐张目视检查。没有测量动画帧率或真机性能。
- [恢复记录](../evidence/release-0.37.0-restoration.json) 核对原有 240 帧 v6 回放、配置、全部十项旧诊断、视角和窗口，保留 10 个用户项目；原单槽回放按字节恢复。

## 边界与下一步

这轮补上了“撤去阻尼再观察”的验证环节。64 秒准备在本轮算例中降低了后续残余运动，但两个预算仍有明显差异，32 秒不能证明长期稳定。当前仍没有静水平衡或旋转平衡判定、多层行星、完整能量账本、碎片再聚合及环粒子碰撞。下一步继续拆分力项残差、延长释放观察、检查空间预算和准备停止条件，再推进碰撞后的碎片识别。
