# 0.28.0 · 看见碰撞内部的数据

> 类型：开发检查点记录；最终模拟器验收待继续；版本：0.28.0；实现／验证日期：2026-09-07（Asia/Shanghai）。

## 这次可以做什么

运行岩质正碰、掠碰或旋转实验，打开“观察”，切换“压力”“比内能”“材料损伤”，查看粒子之间的差异、范围、质量加权均值以及动能／内能总量。拖动时间轴，读数与颜色一起回到对应帧；新保存的回放也保留这些诊断。旧回放显示数据缺失，不把没有保存的信息当成零。

例如预算 600 粒子的正面碰撞运行到约 20.12 秒时，压力范围约 0.0235–76.83 GPa，质量加权均值约 5.41 GPa；压力模式可看见碰撞区域较高的读数。固定色标超过 +10 GPa 会显示饱和红色，具体数值仍保留在统计中。这是当前粗分辨率材料模型的数值结果，不代表已验证某个真实天体事件。

SPH 画面现在会平滑避让观察面板，折叠、展开与旋转保持原生视口、相机姿态和模拟帧。诊断选择随命名实验配方保存，UI 和 CLI 共用处理。当前应用仍由 ArkTS/ArkUI 负责交互，原生 OpenSPH 负责材料计算，GLES 负责显示。

## 调研落地与实现

落实 [上游覆盖审计](../reference/UPSTREAM-AUDIT.md) 的第 2 步，以及 [宇宙沙盒博客与论坛路线](../research/UNIVERSE-SANDBOX-BLOG-FORUM-2026-09-07.md) 的可测量实验方向。具体字段、公式、精度、回放 v5 格式和桌面对照复现见 [SPH 诊断说明](../reference/SPH-DIAGNOSTICS.md)。

读取固定版本 OpenSPH 的 PRESSURE、ENERGY 和 DAMAGE。损伤必须将上游存储的立方根立方，不能直接显示原始根值；压力保留正负号，内能用比内能单位。统计来自原始双精度数据，逐粒子着色使用独立 float 缓冲，不修改求解输入或物理方程。没有新资源下载、外部服务接入或同行私有代码。

桌面对照只在临时副本加了现代 libc++ 需要的迭代器访问兼容补丁，应用导入核心未改。独立提取没有复用应用统计实现，但物理模型与初值相同，因此不能替代标准算例或收敛验证。

只操作开发模拟器 `127.0.0.1:5555`；本轮没有真机、鸿蒙 PC 性能或连续动画帧率结论。原生回放测试使用独立临时目录，未覆盖用户的应用回放槽。

## 仍需推进

当前没有 SPH 自引力、碎片再聚集、完整能量预算、温度换算、多材料或月球形成。回放不是积分检查点，诊断仍限最近 240 帧。新 v5 回放需 0.28.0 及更新版，轨道回放保持 v3/v4；旧版配方读入正常，新诊断色号需新版读取。

下一步优先补 SPH 诊断曲线和标准冲击／弹性算例，再建立自引力稳定性、势能和树近似误差基线；具备这些证据后，才连接轨道近接触与局部 SPH 碰撞。完整顺序和每步门槛已写回 [接入路线](../reference/SPH-DIAGNOSTICS.md#后续顺序与验收门槛)。
