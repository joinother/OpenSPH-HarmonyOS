# 0.17.0 · 从参数列表到主题实验

> 类型：版本记录；适用版本：0.17.0；实现与验收日期：2026-09-06（Asia/Shanghai）。

此前实验入口按求解器类型组织，没有主题封面和明确的观察目标。本版接入首批六个主题，保留基础预设和自定义参数入口，让用户先进入场景，再调整和比较。

## 可以做什么

| 主题 | 玩法与初始条件 |
| --- | --- |
| 碎岩风暴 · 慢撞 | 100 km 与 60 km 岩质天体，2 km/s，90 s |
| 碎岩风暴 · 快撞 | 与慢撞仅速度不同：8 km/s；质量、种子、粒子预算和时长相同 |
| 错位相撞 | 5 km/s，非零横向偏移，90 s；偏移参数不是实际撞击角 |
| 旋转的岩石 | 单个岩质天体的旋转与形变，60 s |
| 蔚蓝世界 | 从带云层与海洋的行星近看开始，可返回双体轨道，3 年 |
| 三种世界，同一片星空 | 恒星与三种表面的行星；点选、近看、连续切换，3 年 |

- 实验库分“碰撞／探索／我的实验”，六张原创概念 SVG 封面可直接点击进入；主按钮放在封面上，小屏无需先滚过全部说明。矮窗口省略分类引导文字，保留主要入口。
- 进入后暂停并关闭面板，不自动消耗整段计算。参数和观察面板提供观察目标、“恢复主题”和慢撞／快撞对照。
- 恢复和对照会重新创建初始场景，清空旧轨迹和天体编辑草稿；可先使用既有另存功能保存变体。更改物理初始条件会标记“已改参数”。
- 全部入口复用语义 CLI：`listExperiments`、`theme.*`、`library.*`，见 [当前操作指南](../CLI.md#主题实验库)。

## 岩质显示与初始化修复

原色使用灰岩与赭岩区分物质来源，按稳定粒子索引生成明暗，并增大颗粒覆盖范围。颗粒随求解结果移动与分离，没有套用始终完整的球壳。速度和密度模式保留较小粒子显示及原有数值色标。

这仍是颗粒代理显示，不是连续表面重建；不代表真实撞击坑、温度、熔融或损伤。SPH 未启用自引力，粒子预算 600 的实际采样数量由上游分布决定。主题封面是原创概念插画，不是模拟结果或同行素材。Image 填充与圆角裁切参考华为开发者 MCP 中的 [Image 接口](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-image) 和 [裁切属性](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-universal-attributes-sharp-clipping)。

验收发现原先“启动求解，再调用暂停”存在时序窗口，轨道场景偶尔已经走过一步。原生 `Engine::start` 现在可在同一锁内设置初始暂停状态；ArkUI 的主题载入、场景预览与天体编辑重建传入该状态。旧原生立即运行入口保留原行为。

## 验收

- [36 项主机测试](../evidence/themes-host-tests.txt)：共用动作、完整条件恢复、仅速度对照、目录隔离、失败事务、分类导航和原生初始暂停标志。
- [主题与设备验证](../evidence/themes-device-tests.json)：六个主题全部完成真实求解；20 次重复轨道主题载入严格停在时间零点；展开、折叠竖屏和横屏核对实验库、相机保留及全窗口沉浸布局。
- [既有 UI／CLI 回归](../evidence/themes-ui-regression.json)：天体编辑、增删、放置、近看、输入草稿、回放与批次失败处理。
- [构建](../evidence/themes-build.txt) 与 [安装](../evidence/themes-install.txt) 成功。

SPH 的终止帧可能超过设定时长一个时间步，本轮记录为 90.02 s 或 60.02 s；设备检查要求偏差不超过当前 0.15 s 最大步长。轨道终止帧为 3 年。这些验证证明默认预设能完成，不证明科学收敛、真机触摸或动画帧率。

首轮更新后的模拟器出现一次 EGL swap 错误；冷启动后继续验收。另一次发现上述初始暂停竞争，修复后重新验证；最终通过证据以本版文件为准，未把显示故障的自动恢复列为已完成功能。

## 下一步

主题 ID、默认镜头和观察说明尚未随另存实验持久化。接下来推进土星风格三维薄环外观，再配合局部行星中心轨道与环粒子模型；SPH 侧接通压力、内能和损伤输出，再做自引力基线与表面重建。月球形成、物理成环、恒星吸收仍未实现，按 [主题调研路线](../research/THEMED-EXPERIMENTS-2026-09-06.md) 逐项增加。
