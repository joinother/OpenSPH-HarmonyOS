# 0.4.0 · 让宇宙视口成为主画面

> 类型：版本记录（仅描述该版本）；适用范围：0.4.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

旧版在当前宽度把视口固定为 320 vp 高，大标题、预设卡片和长菜单占据了主要空间。此版本把 XComponent 放在常驻的全尺寸底层，参数、观察和实验库改为按需打开的面板。主页面不再滚动，只有面板内部滚动。

默认保留 56 vp 顶栏与 110 vp 播放/时间轴栏，菜单关闭。实验预设移入参数面板，着色、缩放、跟踪及回放文件操作移入观察面板。点击“专注”隐藏工具栏和状态文字，只保留“显示工具”；系统返回键先关闭面板或退出专注。载入实验、应用参数以及点击开始后收起菜单，方便立即看结果。

窗口宽度达到 600 vp 时，右侧面板宽 300 vp；窄屏使用最多 430 vp、通常占安全区一半高度的底部面板。面板会覆盖部分宇宙画面，但不重建渲染视口或重置求解状态。进入面板使用淡入，标签切换延续原有淡出/淡入及过期回调取消机制。

渲染投影改为以短边维持视野，粒子屏幕尺寸使用相同投影比例，避免折叠后默认天体被横向裁切。物理求解模型没有改变；这也不意味着扩展碎片云永远自动适配屏幕，用户仍可缩放和跟踪。

## 验证

环境为 `127.0.0.1:5555`，ARM64、API 24。同一折叠屏模拟器实际切换展开/折叠形态，完成后恢复原来的展开状态。未操作其他已连接设备。

| 测量项 | 展开 | 折叠 |
| --- | ---: | ---: |
| 根窗口 | 707.2 × 773.12 vp | 345.6 × 782.08 vp |
| 常驻视口 | 707.2 × 706.56 vp | 345.6 × 715.52 vp |
| 上下工具栏之间的画面高度 / 安全区高度 | 76.53% | 76.82% |
| 打开的菜单形式 | 300 vp 右侧栏 | 半高底部面板 |

面积比例按 UITest 的实际边界计算，不包含系统状态栏与手势区。主画面左上还叠加少量实验状态文字；专注模式隐藏这些文字与上下工具栏。相比原来的 320 vp 固定视口，展开后的完整渲染高度约为 2.2 倍。

- 两种形态通过设备 UI 脚本：只有一个 XComponent、视口充满安全区、工具栏不重叠、面板边界、求解配置及进度不因菜单切换重置、专注/恢复、真实手势改变相机、返回键关闭面板。
- 窄屏实际拖动半径滑块从 100 km 改为 160 km：CLI 显示 dirty=true、原生仍为 100 km；点击“应用并开始”后原生配置变成 160 km、dirty=false，面板自动收起。拖动滑块没有同时转动相机。
- CLI 冷启动、命令目录、非法参数事务、相机、面板、真实求解、seek 和回放往返通过。
- 6 项宿主逻辑/传输测试通过；ArkTS 编译、原生渲染编译、打包及安装通过。
- 检查了展开主画面、侧栏、折叠主画面、底部面板与专注模式的实际截图。默认两颗天体在窄屏完整可见。
