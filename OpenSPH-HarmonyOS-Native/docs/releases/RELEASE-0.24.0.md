# 0.24.0 · 月海与高地

> 类型：版本记录；版本：0.24.0；验证日期：2026-09-07（Asia/Shanghai）。本版为模拟器未签名交付。

## 行为变化

实验库新增第十个主题“月海与高地”：可以绕到背面、观察两极，在同一场景中近看和返回全景。采用 [NASA SVS 月面颜色底图](https://svs.gsfc.nasa.gov/4720/)，封面也使用真实地图，应用内及随包文件保留署名。新增“月面”外观，天体编辑与放置均可使用；五种行星外观按钮改为可换行排列。

三维月面纹理从包内按需解码并上传，成功后约 250 ms 从灰色球体淡入，同一上下文中的查看切换复用纹理。加载失败时保留灰色回退，提供可重试入口。单张 RGBA 数据预算 8 MiB，含 mip 的 GPU 容量估算约 10.67 MiB；这不代表总内存实测。来源、处理和加载边界见 [月面资源说明](../reference/MOON-ASSETS.md)。

月面禁用云、大气、海洋反光与环带，保留曝光和现有日照。选择、近看、旋转和返回全景保留物理场景与时间；应用天体编辑、确认放置或载入实验仍按原规则重新生成初始场景。新增 `getSurfaceInfo`、`moon.retry`、`orbit.surface.5`、`placement.surface.5`，界面和 CLI 共用入口。

## 保存与模型边界

月面编号为 `surface:5`，命名实验及 v4 回放均可往返保存；本轮修复了回放读取器的表面编号上限。含月面的文件要求 0.24.0 或更新版本，旧版会拒绝；外观配方仍为 v2，旧 v1 配方读取规则不变。

“月海与高地”保留地球质量、1 AU 轨道作为材质观察体，主题说明明确这一点。没有真实地月轨道、当天月相、高度地形、月球形成或碰撞产生新坑；表面选择不改变质量。原有 SPH 与点质量引力模型的边界不变。
