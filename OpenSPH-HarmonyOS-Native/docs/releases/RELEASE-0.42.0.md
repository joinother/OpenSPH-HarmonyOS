# 0.42.0 实体半径与理想弹性接触

> 类型：版本记录；验证与发布日期：2026-09-08（Asia/Shanghai）；版本：0.42.0 / 1000043；开发模拟器：127.0.0.1:5555。

## 行为变化

自定义系统现在可为每颗天体设置实体半径。启用后，接触按半径和检测；球体碰到表面会改变速度，以理想弹性响应分离，并自动暂停供查看。旧点质量模式仍保留近距保护，旧存档不被静默改成新物理模型。

参数页提供“启用接触”和“球体接触实验”。演示含两颗带程序表面的球体，局部近看按实体尺寸绘制；临近时增加回放采样，时间轴显示秒。碰撞暂停后显示“继续实验”，继续推进分离过程。放置候选与编辑界面增加半径，共用 CLI、校验、取消及撤销；启用模型时已有草稿保留。

命名实验保存 `nbody-hard-sphere-v1` 和半径，v11 回放保存半径、累计接触次数与最近事件。新回放不包含 SPH 材料诊断。读取旧格式沿用原语义，损坏数据在替换历史前拒绝。具体算法、格式和限制见 [接触模型](../reference/SPHERE-CONTACT.md)，操作见 [CLI](../CLI.md)。

## 实际验证

- [125 项主机检查](../evidence/contact-0.42.0-host-tests.txt)：原行为回归及半径／模型身份、复制放置、命名实验保存和非法输入原子性。
- [主机内存／未定义行为检查](../evidence/contact-0.42.0-contact-sanitized.txt) 和 [ARM64 接触测试](../evidence/contact-0.42.0-contact-arm64.txt)：高速扫掠、切线、分离、等／不等质量正碰和斜碰、能量／动量／角动量、同时接触、失败回滚。引力示例以 0.5／0.25／0.125 秒步长对照，能量相对误差约 1.51e-5／6.76e-6／2.59e-6，接触时刻收敛；这不是所有输入的误差保证。
- [原轨道回归](../evidence/contact-0.42.0-orbit-arm64.txt)：十年轨道、解析圆轨道、近距保护和可逆性。
- [引擎回归](../evidence/contact-0.42.0-engine.txt)：实际接触自动暂停，v11 逐字节往返、独立结构解码、九类损坏文件拒绝；旧轨道／SPH／材料／回放检查继续通过。
- [模拟器接触验收](../evidence/contact-0.42.0-device.json)：半径编辑、启用时草稿保留、非法编辑不改变初值、放置确认和撤销／重做、演示及 v11 读取／定位。实际接触约 2268.4765 秒，法向接近速度约 13.0279 km/s，包含 174 帧接近过程。
- [画面与继续运行](../evidence/contact-0.42.0-visual.json)：接触帧能量相对误差约 −2.94e-5；继续后球心间距增大。展开竖屏、折叠竖屏及横屏保留接触记录，渲染无报错、沉浸式状态有效，四张截图人工检查。
- [原 UI／CLI 回归](../evidence/contact-0.42.0-ui.json)、[构建](../evidence/contact-0.42.0-build.txt)、[安装](../evidence/contact-0.42.0-install.txt) 与 [用户会话恢复](../evidence/contact-0.42.0-restoration.json)。原 v10 历史与保存槽逐字节保留，恢复原 240 帧、1276 粒子、120.0200000000017 秒的回放和 10 个命名项目。

会话恢复时一次屏幕方向操作的状态回包发生 [缺片超时](../evidence/contact-0.42.0-transport-interruption.txt)。随后只读查询确认方向、场景与相机已恢复，从核对步骤继续完成字节检查；没有自动重复不确定的操作，也没有声称修复通用 CLI 传输。

新增验证使用语义 CLI 与原生数值测试；本轮未重新做所有触摸手势、真机性能或帧率测试。编译通过仍有工程已有 ArkTS 可抛异常警告，没有声称全工程无警告。

## 边界与后续

这是恢复系数 1、无摩擦的理想完整球体响应。接触子步有数值误差与预算保护，多体同时接触按逐对顺序处理。没有把真实行星当作弹力球的物理结论，也没有完成流体变形、熔融、合并、破裂或有质量残骸。环带仍不参与接触。

主星图确认放置仍修改初始条件并重算；概览仍用放大标记，局部实体比例视图不等于全尺度连续 LOD。下一项为支持的小岩体尺度下的轨道事件→局部 SPH 坐标、时钟、质量／动量与材料身份映射，再建立残骸返回，见 [主线状态](../reference/VIEWPORT-PLACEMENT.md)。
