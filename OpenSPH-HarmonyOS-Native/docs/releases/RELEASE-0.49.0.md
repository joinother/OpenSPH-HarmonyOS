# 0.49.0 连续时间与当前时刻加入天体

> 类型：开发断点记录；实现与验证日期：2026-09-08（Asia/Shanghai）。

## 本次行为

轨道系统从固定时长实验扩展为持续演化：暂停、恢复、0.01–100 模拟日／现实秒档位，以及目标与实际速度显示。加入天体使用当前完整状态，支持恒星和五种行星外观、圆轨道、相对静止投放、掠过与瞄准发射；原有天体的时间、位置和速度保持，历史保留最近 240 帧。

逐帧保存双精度速度与位置，v14 支持加载后继续及旧帧分支；保留旧 v1–v13 读取。插入会重新建立守恒统计基准，过期事务拒绝；取消预览不截断未来历史。编辑器的初态应用／删除依旧重建，动态加入会清除初态撤销记录。

完整定义和操作边界见 [连续沙盒](../reference/ORBIT-SANDBOX.md)，CLI 见 [当前指南](../CLI.md)。

## 尚未完成
