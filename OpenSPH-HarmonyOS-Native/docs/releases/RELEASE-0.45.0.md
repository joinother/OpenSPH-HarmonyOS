# 0.45.0 星系实验对照

> 类型：版本记录；验证与发布日期：2026-09-08（Asia/Shanghai）；版本：0.45.0 / 1000046；开发模拟器：127.0.0.1:5555。

## 行为变化

观察面板新增“保存本次作参照”：至少两帧，将原生一次读取的已应用参数与完整记录保存到独立本地槽。切换顺逆行主题、调整参数重新计算或重启应用，仍能叠加青色当前与金色参照的五条诊断曲线；隐藏只改变显示，移除只清理参照，当前实验保持。

共享横轴按各自实验开始后的 Myr 对齐，纵轴覆盖两组记录。光标差值只在参照记录范围内插值，超时明确说明不外推；外延比例的差显示为百分点。最小／最大按钮始终定位当前历史，不把参照帧号用于当前实验。对照列出八项实际初值差异，未确认草稿不进入参照或比较。

新增三个查询 `getGalaxyReference`、`getGalaxyComparison`、`getGalaxyComparisonTable`，以及四个 `galaxy.reference.*` 共享动作。双实验 CSV 为 19 列：series 加原有模型／参数、帧／时间、五项诊断和两中心误差，每行保留自己的数据来源与原始时间；外延比例仍为 0–1，不进行重采样。原有单次实验查询保留原含义，v12 回放及 C++ 求解器没有更改。

参照文件使用独立版本和模型标识，检查身份、参数范围、数组、单调时间及数值；先写入并校验临时文件，再替换旧文件。读取错误保留原文件并显示重试／移除入口。极端数值不能生成含非有限坐标的曲线。

## 验证与证据

- [144 项主机测试](../evidence/galaxy-0.45.0-host-tests.txt)：共享时间轴、非均匀采样插值、百分比／百分点、范围外不外推、极值归属、所有初值差异、最多 402 行双记录 CSV、坏数据／溢出、冷读、原子替换和写入／刷新／重命名失败保留旧文件；原 UI 与新动作事务回归。
- [模拟器完整对照](../evidence/galaxy-0.45.0-device.json)：1600 点、600 Myr 顺行参照对照 800 Myr 逆行当前实验，151＋201 帧、352 行 19 列逐项等于原生采样及各自参数。五条曲线在 400 Myr 的差值和采样极值逐项核对；800 Myr 光标超出参照范围时不外推。共同时间段两中心间距逐帧相同，次盘分布尺度不同，符合当前无质量示踪模型中旋转不反作用于中心的定义。
- [三种布局](../evidence/galaxy-0.45.0-visual.json)：展开竖屏、折叠手机和折叠横屏可见完整曲线、图例与参照控件；真实滚动找到短面板中的按钮和百分点差值，隐藏／显示通过语义动作测试，时间、镜头与历史保持。每种布局再次切换次盘尺度和主／次盘外延指标，核对两组原始记录不变、400 Myr 差值一致。截图验收改为比较完整原始边界和裁剪边界，继续滚动直到差值与旋转差异全文可见；六张新截图人工检查，沉浸式状态正常。未宣称全部按钮实际触摸或真机帧率验证。
- [原 UI／CLI 回归](../evidence/galaxy-0.45.0-ui.json)、[构建](../evidence/galaxy-0.45.0-build.txt)、[安装](../evidence/galaxy-0.45.0-install.txt) 完成。原生求解器未改，本轮未重跑或重新声明旧科学收敛基线；工程已有编译警告保留。
- [会话恢复](../evidence/galaxy-0.45.0-restoration.json)：恢复进入本轮时的慢撞初态，641 粒子、0 秒、暂停可运行；初态回放与原保存槽逐字节核对。主题、镜头、外观、面板、展开方向和原命名实验保留，测试参照槽恢复为空。

本轮保留 [首次文件恢复失败](../evidence/galaxy-0.45.0-initial-transfer-failure.txt)、[一次差值核对失败](../evidence/galaxy-0.45.0-initial-delta-failure.txt) 和 [随后五指标现场核对](../evidence/galaxy-0.45.0-delta-probe.jsonl)，失败过程不覆盖成通过记录。差值失败未能稳定复现，现有失败日志没有记录该次的实际双方数值，不能据此宣称定位或修复了物理错误；随后现场五指标、完整重跑及三布局重复切换均逐项一致。最终验收增加文件传输成功检查、恢复前通过应用创建参照文件，以及包含实际指标／时间／双方记录的失败诊断；最终完整结果以上述模拟器证据为准。

## 数据与边界

[双实验原始 CSV](../evidence/galaxy-0.45.0-comparison.csv) 保留顺逆行的实际运行结果。参照在 600 Myr 截止，当前实验延伸到 800 Myr，共同时间段仅改变次盘旋转方向；延长记录不改变先前已采样的状态。400 Myr 的次盘外延差为 −9.125 个百分点，次盘均方根尺度差约 −2.391744 kpc。这是当前简化模型的一次实验结果，不是普适星系结论或分辨率收敛证明。

本轮完善诊断对照，没有加入任意位置／速度放置、逐恒星轨迹／形态叠加、系统文件选择器、多参照管理、求解器续算、自洽盘／暗晕、气体或宇宙学积分。星系仍由两个软化解析势驱动无质量示踪盘。下一步继续任意初态、形态／分辨率对照与质量盘基准，同时保留主轨道到局部 SPH 的碰撞接入主线；见 [模型指南](../reference/GALACTIC-TIDES.md) 与 [实施顺序](../reference/RESEARCH-IMPLEMENTATION.md)。
