# 0.33.1 — 近看行星时保留周围天体

> 类型：修复记录；版本：0.33.1；实现与验证日期：2026-09-07（Asia/Shanghai）。

## 原因与修复

此前投影函数在近看完成时将所有非目标天体透明度降为零，所以无论怎样旋转都看不到太阳和其他模拟天体。旧测试也错误地要求这个隐藏行为。

本版让近看保留同一星系中的其他天体，按相对于目标的方向投影到视野中。目标仍居中放大；视野背面和屏幕外的天体不可见，前方天体可被目标遮挡。绘制排序和点选使用相同投影深度，太阳在目标背后时不会覆盖目标或抢占点选。普通全景仍使用原投影；通过已有相机过渡连续切换，不重启物理或原生窗口。

太阳和其他行星采用便于识别的标记尺寸，并非按真实角直径显示。当前仍是环绕目标观察，未增加自由飞行或自由转头模式。

## 验证

- [原生投影与相机测试](../evidence/closeup-0.33.1-native-tests.txt)：三种窗口、近看过渡、远处天体投影、前后遮挡、旋转可见性、同方向不同距离、点选，以及相机取消／切换／帧率独立性。
- [构建记录](../evidence/closeup-0.33.1-build.txt)：鸿蒙构建成功并安装到指定模拟器。
- [模拟器验证](../evidence/closeup-0.33.1-emulator.json)：三种窗口中太阳可见并可语义点选；旋转显示其他行星；太阳被目标遮住时点选落在目标；返回全景保留时间和场景。
- [相机回归](../evidence/closeup-0.33.1-camera-tests.json)：取消冻结、连续切换、过期请求、无效参数及全景返回。
- [恢复记录](../evidence/closeup-0.33.1-restoration.json)：恢复原来的暂停椭圆环实验、局部时刻、镜头、面板、展开竖屏和十个用户实验。
