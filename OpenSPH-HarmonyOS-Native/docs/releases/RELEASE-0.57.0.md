# 0.57.0 · 接触入口与操作语义

> 类型：开发版本记录；版本：0.57.0（1000058）；实现与验证日期：2026-09-09（Asia/Shanghai）。

## 玩家可完成的操作

轨道接触暂停后，可明确选择“计算局部撞击”或“使用外部引力近似”。轨道继续演化后，保留的旧接触只用于查看，不能再拿它启动一份与当前世界不一致的局部实验。底层与 UI／CLI 共用可用性判据，缺少历史或完整事件世界时拒绝入口。

本段计算结束后，主按钮是“查看回放”，不再自动返回原轨道或从头重算。重新生成明确写“从头生成／从头重跑”；局部完成提示说明返回不会带入碎片。重启后载入局部回放，会说明仅供观看、不能继续计算，也不虚构可返回的父会话。

23 个主题标题按对象和变化重命名，例如“岩体撞击：预先受损”“星系相遇：次星系反向旋转”；原 ID、初始参数与保存兼容性保留。“保存设置与视角”说明保存的是配方，星系时间栏使用“百万年”，原始数据单位仍为 Myr。

## 工单边界

这是 [R02](../reference/PRODUCT-ROADMAP.md) 的第一片，工单仍在进行中。当前只允许新接触首次出现的最新响应帧启动局部实验；它仍是已施加弹性响应的父世界。没有修改积分器，没有新增反弹前待处理事件、唯一持久事件身份、积分阶段续接或原子会话存档。返回仍恢复旧父世界，SPH 碎片尚不回注。

v20 仍是观察回放，没有中途求解续算。冻结外部引力仍为短时近似，没有反作用或同步父世界时钟。未新增液相比例、潜热、冷却、连续熔岩表面或分辨率收敛结论。布局重组和整套新用户任务未完成；没有新增触摸、动画、折叠旋转、真机或视频验收。

下一片继续 R02：先固定事件状态转换与恢复边界，再实现反弹前世界和积分阶段的检查点，并测试重复处理、取消、重启与写入中断。R02 完成前不进入 R03。
