# 0.36.0：先准备岩体，再开始碰撞

> 类型：版本记录；验证日期：2026-09-08（Asia/Shanghai）；适用设备：开发模拟器 127.0.0.1:5555。

## 行为变化

岩质自引力实验增加“直接生成／预松弛 16 秒／预松弛 64 秒”。每个静止岩体分别运行 OpenSPH 阻尼准备求解器，再保留其演化后的材料状态、清除准备速度并施加请求的自转和撞击速度，合并成正式碰撞初态。第一帧仍为 0 秒，准备过程不混入碰撞历史；两个准备阶段可取消。

参数与 CLI 使用同一动作；草稿修改不改变当前求解，应用后生效。命名实验采用 `sph-rock-prepared-v1`，v9 回放保存准备时长及全部十四项诊断。旧配置默认关闭，旧回放按原物理身份读取。

实验库新增“直接生成，相同撞击”和“先准备，再相撞”：相同预算、速度、偏移和碰撞时长，通过对照按钮切换。详见 [准备流程和数值结果](../reference/SPH-RELAXATION.md) 与 [CLI](../CLI.md#sph-预松弛)。

## 边界与下一步

这是定时、耗散的岩体准备功能，尚无自动收敛判断、静力平衡行星、旋转平衡、分层结构、完整能量账本或再聚合。16／64 秒为模拟时间，不是承诺的等待时间；最高预算的长时准备和真机性能尚未验证。下一步优先检查解除阻尼后的自由演化、压力／引力残差及步长敏感性，再推进稳定初态与碎片识别。
