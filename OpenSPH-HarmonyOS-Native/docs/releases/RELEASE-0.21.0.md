# 0.21.0 · 把实验与观察设置一起保存

> 类型：版本记录；版本：0.21.0；验证日期：2026-09-07（Asia/Shanghai）。本版为模拟器未签名交付，尚未进行真机或应用市场发布。

## 行为变化

以前另存实验只保留初始参数、名称、表面编号与随机种子，重新打开会丢失主题身份、观察角度和局部环设置。现在“保存当前实验与视角”会一并记录主题、镜头、近看时返回全景的视角、云层／大气／轨迹／环带等外观开关、银河模式与亮度，以及局部环的目标、小时数、发射比例和播放倍率。

例如将带环行星调到 1.17 倍发射速度、0.3 小时/秒、4.75 小时，关掉云层并换一个观察角度，另存后退出应用再打开，能恢复这些设置及对应的示踪点位置。载入后主系统与局部环都暂停；主系统从初始条件重新生成，局部环回到所存时刻。保存本身不自动暂停正在运行的实验。

实验库区分“含外观与观察设置”和“旧版 · 初始参数”，有局部环的条目显示保存小时数。已有保存按钮和 CLI 共用逻辑，`listProjects` 新增 `hasRecipe`、`themeId`，无需坐标操作。当前规则见 [CLI 指南](../CLI.md)。

## 存档与兼容

- 保持原 `scene.schemaVersion=1`，添加可选的 `recipe`，配方与程序外观基底版本均为 1。旧存档没有配方时采用固定默认全景与外观，不沿用上一场景的设置。
- 保存沿用临时文件、同步写入、重命名；加载先校验场景和完整配方，再让原生层接受场景，随后更新界面。损坏配方、未知版本、越界参数、非带环目标或相机／目标不匹配会被拒绝；实验库隔离损坏条目。
- 内置主题说明由当前目录读取；未知主题 ID 不绑定主题。当前没有外部材质包导入，`appearanceVersion` 是现有程序外观的版本标记，不代表已实现资源依赖管理。

未提交的编辑／放置草稿、撤销历史、主系统运行时间、回放帧、面板和窗口方向不属于配方。程序外观动画的相位也未保存。恢复视角与设置不等于逐像素恢复历史画面；回放仍为独立单槽、最多 240 帧，不能从任意历史时刻恢复求解。

## 验证

- [48 项主机测试](../evidence/recipe-0.21.0-host-tests.txt)：原有 CLI／编辑／环参数回归，实际存档读写和旧格式，19 类损坏字段及错误目标，主题／镜头／局部环恢复，旧存档默认值与原生拒绝不改变界面。
- [模拟器配方验收](../evidence/recipe-0.21.0-device-tests.json)：冷启动恢复、全部 192 个示踪点位置对照、运行中保存后暂停恢复、坏文件隔离、旧文件载入、界面保存动作共用逻辑、展开／折叠竖屏／横屏保存控件边界与沉浸状态。
- [既有 UI／CLI 回归](../evidence/recipe-0.21.0-ui-regression.json)：天体编辑、放置、表面切换、面板、播放、批次失败停止、文件参数和等待求解状态。云层测试改为核对切换前后状态，支持先前保存为关闭的场景。
- [构建](../evidence/recipe-0.21.0-build.txt) 与 [安装](../evidence/recipe-0.21.0-install.txt)。测试兼容样本先经应用创建以保留权限与安全标签，再覆盖其内容；测试只清理自己创建的文件。

本轮没有修改 C++ 求解器或环模型，没有新增科学精度结论。截图与布局核对不代表真机触摸、折叠传感器、动画帧率或持续性能验收。
