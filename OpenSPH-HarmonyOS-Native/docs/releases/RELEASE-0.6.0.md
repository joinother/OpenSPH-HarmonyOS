# 0.6.0 · 从碰撞实验走向轨道实验

> 类型：版本记录（仅描述该版本）；适用范围：0.6.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

新增独立的牛顿多体引力模式；原有 OpenSPH 岩质碰撞继续使用原来的求解器。本版不是完整宇宙模拟器，也不是实时太阳系星历。

## 可以直接体验

打开“参数”，选择“双体轨道”或“行星系统”，收起面板并开始实验。默认运行 3 个儒略年；1.00 × 初速下观察近圆轨道，改变初速观察椭圆运动。这里的倍率改变物理初始条件，不是播放速度。

- 双体：一颗太阳质量恒星与一颗类地质量行星。
- 行星系统：恒星与三个不同质量的行星，全部成对相互施加引力；恒星也会运动。
- 轨道线由过去的积分位置绘制，最多保留每个对象最近 512 个采样点，约 2 年；未绘制尚未计算的未来轨道。
- 原生 OpenGL ES 球形点精灵，恒星金色、行星蓝／金／红；天体显示尺寸放大，位置采用 AU。
- 可在观察面板跟踪任意一颗预设行星，旋转／缩放仍使用原有可打断镜头动画。
- 观察面板显示能量、角动量相对误差以及各对象速度；CLI 还返回 AU 位置和太阳质量比。
- 保留暂停、恢复、240 帧历史、时间轴、实验库；v3 回放恢复轨迹、诊断量和引力预设，兼容原有 SPH v1/v2 回放。
- 五个预设自动换行；时间单位按模型切换为“年”或“s”；引力模式隐藏不适用的粒子预算、岩质半径／密度与自转控件。

## 数值模型与资料

自行实现 C++17 双精度 kick-drift-kick leapfrog，固定步长 1/4096 儒略年，16 个积分步发布一帧。直接成对求和，初始化后移入质心静止系。没有复制闭源实现，也没有新增 REBOUND 运行时依赖。ArkTS 负责界面、实验管理和控制，物理与轨迹留在原生线程，避免逐帧跨语言传输历史数组。

方法参考 [REBOUND leapfrog 文档](https://rebound.hanno-rein.de/integrators/leapfrog/)。AU、儒略年、太阳 GM、引力常数及行星 GM 取值依据 [JPL Astrodynamic Parameters](https://ssd.jpl.nasa.gov/astro_par.html)。轨道半径 0.72/1/1.52 AU 与相位为本项目教学设置，不是观测历元数据；蓝／金／红行星质量分别采用地球、金星、火星系统 GM 对太阳 GM 的比值。

相对误差定义为 `(E−E₀)/|E₀|` 与 `(|L|−|L₀|)/|L₀|`。误差基准来自本次实验初始状态；CLI 的位置、速度展示快照为 float，数值积分与误差计算保留 double。

间距小于 0.02 AU 时终止计算并给出中文原因。这是当前积分模型的适用范围保护，**不是物理碰撞半径**。没有引入引力软化、物体穿透后继续计算、随意合并、相对论或 SPH 碰撞耦合。低初速的多行星预设可能产生近距离遭遇；停止是预期行为。参考 [REBOUND 对近距离遭遇的说明](https://rebound.hanno-rein.de/ipython_examples/CloseEncounters/)，此类轨道后续需要专门积分器／局部碰撞处理。

## 验证

- 双体圆轨道解析解：1/4096 与 1/8192 年步长的四分之一年位置误差分别约 5.91×10⁻⁷、1.48×10⁻⁷ AU，收敛比约 4。
- 双体初速 0.75/1/1.25 倍、行星系统 1/1.25 倍，各运行 10 年。最大相对能量误差不超过 1.1×10⁻⁵，角动量误差不超过 4.9×10⁻¹⁴；线动量误差小于 6×10⁻¹⁹ 太阳质量·AU/年。
- 行星系统 0.75 倍初速触发近距离停止；积分时间反演和超限步长拒绝通过。
- ARM64 模拟器原生测试：两种轨道的暂停、2 年推进、缓存上限、v3 回放逐字节恢复、截断文件拒绝与状态原子性、取消后切换 SPH。
- 原有三个 SPH 预设、编辑天体质量、v1/v2 兼容、固定种子复现、60 秒碰撞回归通过。
- 8 项宿主 CLI／页面状态测试通过；设备 CLI 完成 3 年运动、暂停、保存实验／重建、回放恢复。

以上数值基线在 macOS 宿主与鸿蒙 ARM64 上均通过；可运行 `scripts/test-orbit-core.sh` 或带显式设备参数重现。

详细结果见同目录 [orbit-numerical-tests.txt](../evidence/orbit-numerical-tests.txt)、[orbit-native-tests.txt](../evidence/orbit-native-tests.txt)、[orbit-host-tests.txt](../evidence/orbit-host-tests.txt)、[orbit-device-tests.json](../evidence/orbit-device-tests.json)、[orbit-arm64-numerical-tests.txt](../evidence/orbit-arm64-numerical-tests.txt)。展开 707.2 vp、折叠 345.6 vp 下的实际预设点击、四颗天体镜头跟踪与常驻视口验证通过。设备 UI 布局与行星跟踪结果在 `orbit-*-ui-tests.json`、`orbit-*-layout-tests.json`。最终安装版本的 CLI 冷启动／SPH 回归通过（[orbit-cli-regression.json](../evidence/orbit-cli-regression.json)）；轨道密度着色拒绝与删除跟踪对象后的镜头状态恢复通过（[orbit-final-state.json](../evidence/orbit-final-state.json)）。

本版测试只使用 `127.0.0.1:5555` 模拟器。

5. 真机热稳定性、长时运行、鸿蒙 PC 窗口／键鼠、正式签名分发。

仍是低对象数的科学探索原型。记录帧的速度不等同于实时宇宙时间；图形天体尺寸不是等比例；回放只用于观察，不能从历史帧继续积分。
