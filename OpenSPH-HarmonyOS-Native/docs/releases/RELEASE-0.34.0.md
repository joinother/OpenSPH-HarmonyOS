# 0.34.0：材料粒子开始相互吸引

> 类型：版本记录；验证日期：2026-09-08（Asia/Shanghai）；适用设备：开发模拟器 127.0.0.1:5555。

## 行为变化

岩质实验增加“材料自引力”开关，应用参数后让 SPH 材料粒子相互吸引。采用固定上游的逐对软化引力，保留压力、固体应力及损伤路径；自引力预算上限为 1200，默认关闭，旧实验的物理设置保持原样。

界面与 CLI 共用动作，开关先改变草稿；实际求解设置在应用后更新。画面模型说明读取当前求解设置，观察面板说明动能／内能尚未包含引力势能及弹性应变能。主题修改标记包含自引力差异。

开启自引力的命名实验采用 `sph-rock-gravity-v1`，回放采用 v6；读写保留物理模型身份，旧模型和回放继续兼容。过大预算、轨道预设或非法布尔值会在改变当前场景前被拒绝。

## 验证

- 36 个条件的独立球壳积分对照，检查软化引力、势能与动量对称性。
- 三个粒子预算、每组关闭／开启／减半步长，共九个 4 秒岩球算例；桌面与鸿蒙结果对照通过。详见 [物理基线](../reference/SPH-GRAVITY.md) 和 [原始分析](../evidence/gravity-0.34.0-analysis.json)。
- [100 项主机检查](../evidence/gravity-0.34.0-host-tests.txt) 与 [两项新增证据校验检查](../evidence/gravity-0.34.0-evidence-tests.txt) 通过，包括草稿、非法输入、主题与命名实验兼容。
- [应用验收](../evidence/gravity-0.34.0-ui.json) 验证 16 秒碰撞完成、v6 回放模型与十项诊断恢复，以及重新计算继续使用自引力。
- 最终界面文本调整后，[69 项 CLI 主机回归](../evidence/gravity-0.34.0-ui-host-tests.txt) 和 [既有设备操作回归](../evidence/gravity-0.34.0-ui-regression.json) 通过。
- [布局与命名实验往返](../evidence/gravity-0.34.0-layout.json) 检查展开竖屏、手机竖屏和横屏的窗口、暂停时刻、沉浸状态及显示错误。截图检查为静态验收，不代表实体触摸命中或帧率测量。
- [恢复记录](../evidence/gravity-0.34.0-restoration.json) 核对原先完成的慢撞实验、时间、诊断、窗口和用户项目，并恢复用户原单槽回放的原始字节。
