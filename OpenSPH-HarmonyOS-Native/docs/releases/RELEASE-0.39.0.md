# 0.39.0：碰撞材料团块

> 类型：版本记录；验证与整理日期：2026-09-08（Asia/Shanghai）；源码版本：0.39.0；设备：模拟器 127.0.0.1:5555。

## 功能变化

碰撞材料可按当前几何连接分组着色，观察列表给出每团质量、质量占比、粒子数、质心位置／速度与均方根尺度，支持逐帧回放和分页 CLI。使用实际 SPH 粒子质量、位置、速度、光滑长度，统计和画面共享标签；切换颜色和翻页不会重建实验。

新回放 v10 保存逐帧标签和统计，同时记录自引力与预松弛身份。旧 v1–v9 继续读取，无团块记录时明确显示不可用，再次保存不伪造新数据。原生相机校验同步支持新色号 6；7 仍被拒绝。

定义、上游参考与二进制格式见 [材料团块](../reference/SPH-FRAGMENTS.md)。当前只识别几何连通，不等于引力束缚、永久碎片身份或再聚合；没有改变求解方程、加入行星表面重建或新的碰撞动画。

## 限制与后续

200 预算初态的两个材料球被光滑邻域连成 1 团，而 600 预算初态为 2 团。这是本轮明确记录的分辨率敏感性，不能把分组计数直接当成物理碎片数量。第一次构建的组件属性错误、设备色号校验错误和不成立的双团断言均已处理，过程见 [验证说明](../evidence/fragments-0.39.0-validation-notes.json)。

继续按 [碰撞主线](../reference/RING-AND-COLLISION.md) 完善力项残差、完整能量、重复性、静力平衡与空间收敛；再接入持久碎片身份和引力束缚／再聚合。该版本没有完成分层行星、环互撞、月球形成或真机性能验收。
