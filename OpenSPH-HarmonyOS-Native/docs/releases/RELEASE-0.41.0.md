# 0.41.0 主星图放置与定向发射

> 类型：版本记录；验证与发布日期：2026-09-08（Asia/Shanghai）；版本：0.41.0 / 1000042；开发模拟器：127.0.0.1:5555。

## 行为变化

此前只能在面板小图中放置新天体。本版在主星图显示已应用的初始天体和带外观的候选，支持点击／单指拖动、双指缩放、数值参数、倾斜轨道面和瞄准已有天体。候选速度箭头与最终提交速度来自同一初值。进入放置时收起无关工具栏与时间轴，取消／参数／确认保留在浮动入口。

原生显示使用独立预览帧，求解器历史保留；逆投影对应最近实际呈现的相机与尺寸。新命令 `setViewportPlacementPoint` 与触摸共用处理，辅助小图命令继续保留。候选程序外观种子随确认保存，复制沿用来源种子；月面候选按需加载原有地图。

进入放置暂停正在运行的实验及回放播放，取消恢复原运行状态、镜头和编辑草稿；确认仍重新生成初始条件并从零计算，可撤销。不是任意当前时刻插入。

## 碰撞仍未完成

瞄准只按目标初始位置定向，不能保证命中。轨道点质量模型仍在间距小于 0.02 AU 时停止，没有真实物理半径、接触响应或与 SPH 的事件转换；不能声称实现放置后行星破裂。下一项优先级已改为真实尺寸接触和基本响应，然后衔接支持尺度内的局部 SPH，见 [具体接入顺序](../reference/VIEWPORT-PLACEMENT.md)。本版没有更改物理求解方程。
