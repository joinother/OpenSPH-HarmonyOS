# 0.44.0 星图相遇预览与演化记录

> 类型：版本记录；验证与发布日期：2026-09-08（Asia/Shanghai）；版本：0.44.0 / 1000045；开发模拟器：127.0.0.1:5555。

## 行为变化

星系参数页新增“在星图调整相遇”。进入后显示初始双盘、偏移范围线和相对接近方向箭头；上下轻点／拖动或滑条可调整错身距离，双指缩放。预览只更新画面，原历史不被替换；取消恢复原视角、面板、草稿与运行／回放状态，确认才从当前草稿和新偏移生成初始暂停场景。横屏控件靠左放置，避免盖住蓝色星系，折叠和旋转保留预览。手机打开星系观察面板后隐藏重复的顶部说明，避免文字叠到星系画面。

此功能有明确约束：初始 X 方向间距仍固定 60 kpc，偏移仅 0–30 kpc，手势越界停在端点。两中心按质心系共同调整；箭头是方向辅助线，不是预测轨迹。尚无任意位置／速度的自由放置或历史时刻插入。

观察页新增间距、主盘尺度、次盘尺度、主盘外延、次盘外延五条曲线，显示当前时间和数值；“记录最小／最大”直接定位所显示采样并暂停，场景身份或采样已变化时拒绝旧定位。曲线操作不重算模型。

新增 `getGalaxyObservation`、`getGalaxyTable`、`getGalaxyPlacement` 与 `setGalaxyPlacementPoint`，预览与曲线控件共用语义动作。原生在一次锁定中复制参数与历史，CSV 包含完整保留记录的 18 列数据及已应用初值；不会把未应用参数草稿写成数据来源。800 Myr 例导出 201 行，外延比例为 0–1，界面显示百分比。v12 星系回放可直接恢复曲线和 CSV，格式及潮汐力学沿用 0.43.0。

- [实际手势和三布局](../evidence/galaxy-0.44.0-visual.json)：展开竖屏、折叠手机、折叠横屏均在预览中改变窗口后实际拖动，偏移改变、相机和 400 Myr 历史保持；取消后模型及 201 帧保留。曲线控件在布局树中可见；短横屏面板实际滚动后验证极值按钮，时间仍保持。六张截图逐一检查，沉浸式状态有效，渲染无报错。
- [原 UI／CLI 回归](../evidence/galaxy-0.44.0-ui.json)、[命名星系实验](../evidence/galaxy-0.44.0-projects.json)、[构建](../evidence/galaxy-0.44.0-build.txt) 与 [安装](../evidence/galaxy-0.44.0-install.txt) 完成。

首次横屏拖动在 [验收中失败](../evidence/galaxy-0.44.0-layout-failure.txt)，屏幕确认是居中面板覆盖次星系。改为横屏左侧控件，并为双指事件增加隔离，再重跑三布局。首次编译的两处 ArkTS 类型声明错误也已修复；本轮没有通用传输修复或物理模型改版。双指隔离有主机检查，尚未通过双指注入验证真实缩放手势；没有真机帧率、动画流畅度或全部按钮触摸命中结论。工程已有编译警告仍保留。

## 可复查数据与边界

[初始偏移 12 kpc](../evidence/galaxy-0.44.0-offset-12.csv) 与 [初始偏移 18 kpc](../evidence/galaxy-0.44.0-offset-18.csv) 为实际运行导出，其余初值相同；时间跨度均为 0–800 Myr。这些是无质量示踪盘和两个软化中心的诊断，外延比例不是逃逸质量，中心误差不是整个恒星群的封闭系统守恒量。离散极值不代表精确近心时刻。没有重新声称完成真实星系的科学验证或分辨率收敛。

CSV 当前通过 CLI 提取，没有系统文件选择器、逐恒星位置／速度导出或求解器续算。任意位置／速度初态、自洽带质量盘／暗晕、气体星云和宇宙层级坐标继续按 [实施顺序](../reference/RESEARCH-IMPLEMENTATION.md) 推进；行星事件到局部 SPH 的映射仍保留为另一条物理主线。操作和数据列定义见 [星系参考](../reference/GALACTIC-TIDES.md) 与 [CLI](../CLI.md)。
