# 0.7.0 · 行星表面与近看

> 类型：版本记录（仅描述该版本）；适用范围：0.7.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

从 0.6.0 的彩色球点升级为具有球面纹理、受光面、云层与大气边缘的行星显示。物理求解、实验参数和回放格式保持兼容。新增内容是视觉材质，不是气候、海洋流体、地质演化或真实自转周期模拟。

## 直接体验

选择“行星系统”，点击悬浮的“近看行星”。近看时可用“海洋／厚云／荒漠”切换对象，拖动改变视角，双指缩放；“返回轨道”回到系统视图。也可以在观察面板跟踪恒星，然后近看恒星。

- **海洋行星**：海陆分界、浅海、陆地颜色变化、冰帽、海面高光、云层遮蔽与蓝色大气边缘。
- **厚云行星**：暖色浓厚云层；关闭云层可见下方岩质表面。
- **荒漠行星**：红褐色地形、程序陨坑、极区冰帽、稀薄尘云与较弱的大气效果。
- **恒星**：自发光的颗粒纹理与柔和外晕。
- **独立外观控制**：“云层／大气／轨迹”可分别切换；速度着色暂时覆盖自然材质，避免把物理色标与表面颜色混在一起。
- **近看过渡**：约 360 ms 的球体放大与其他对象淡出；仍使用同一个原生视口。
- **外观自转演示**：近看入口默认启用，观察面板可停止。HUD 明确标为外观演示，不改变轨道、质量或能量诊断。回到轨道会关闭这项演示。

程序纹理是自行生成的教学美术，不对应真实地球大陆、某个观测历元或实时气象。未使用 SpaceSim、Universe Sandbox 等闭源素材，也未引入需要联网下载的贴图。

## 实现与参考

每种外观具有 1024×512 的 RGBA 表面图（alpha 为海洋遮罩）与 R8 云量图。所有取样来自球面上的确定性三维噪声，使用固定算法生成；海陆、云层分图，允许云层相对表面缓慢偏移。GPU 采用 mipmap 与线性过滤，并修正经度绕回处的纹理梯度，减少接缝。程序陨坑由固定球面位置生成。

近看使用双三角形包围解析球面的着色方法，绕过点精灵最大尺寸的限制；它不是地形网格或可登陆表面。着色包括方向光、简化云影、海洋高光、边缘散射与外晕，不是完整的大气散射／体积云求解。恒星方向由当前物理帧中的位置计算。显示半径特意放大，未改变 N-body 点质量参数。

纹理在首次进入轨道模式时由原生渲染线程准备，ArkTS 显示准备提示。CPU 图像在进程内缓存；每个 EGL 上下文独立上传、销毁纹理、VBO、VAO 和 shader program。四种外观的 CPU 基础图约 10 MiB，完整 GPU mip 链约 13.3 MiB，不含驱动、历史帧及窗口缓冲。

前后台状态控制渲染线程；后台停止提交新帧及外观计时，物理暂停沿用既有行为。Surface 销毁时先停止并 join 渲染线程，再完成 EGL 资源释放，避免子线程继续使用失效窗口。

本轮参考华为开发者 MCP 的 [XComponent 开发指导](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/napi-xcomponent-guidelines)、[XComponent 渲染问题分析](https://developer.huawei.com/consumer/cn/doc/best-practices/bpta-xcomponent-render-problem-guide)，以及 [Khronos OpenGL ES 规范与参考入口](https://registry.khronos.org/OpenGL/index_es.php)。没有引入高于现有 API 24 SDK 的组件接口。

## 验证与边界

- 运行 `scripts/test-planet-textures.sh` 可重现贴图生成宿主测试，启用 AddressSanitizer 与 UndefinedBehaviorSanitizer：尺寸边界、确定性、海陆／云层覆盖、经度接缝连续性通过。
- 10 项宿主测试：保留原有 CLI 验证，新增外观命令原子性、不重建物理场景、近看／返回、切换物理模型清理近看状态，以及从近看载入旧版 SPH 回放的界面恢复。
- ARM64 API 24 模拟器像素对比确认：关闭云层、关闭大气、启用外观自转均改变实际球面区域；这些动作保持暂停物理帧的位置和时间不变。
- 验证了四种材质的 shader 编译／链接和绘制，未记录 GL 错误；返回轨道后继续积分，再切换 SPH，实际粒子仍可见。
- 切到后台约 1.8 秒，外观计时没有按后台时长继续推进；返回后可继续显示。
- 展开／折叠尺寸检查近看入口、三类行星切换、云层／大气按钮、拖动视角、返回键层级与专注模式。展开 707.2 vp、折叠 345.6 vp 均通过，相关记录见 `material-*-ui-tests.json`。模拟器已恢复展开状态。

[material-device-tests.json](../evidence/material-device-tests.json) 保存像素差异及设备结果；[material-host-tests.txt](../evidence/material-host-tests.txt)、[material-texture-tests.txt](../evidence/material-texture-tests.txt) 保存宿主结果。`rendering.submitMs` 仅是 CPU 生成／提交绘制命令耗时，不等于 GPU 耗时或帧率；本版不作真机 FPS、功耗或热稳定性保证。首次生成贴图可能短暂停留在准备状态。

显示选项属于当前会话，不写入物理场景或 v3 回放文件。暂停外观演示后保留当前外观角度，物理时间轴和手势仍可改变可见表面。

## 后续路线

1. 自定义天体列表、质量、位置、速度，以及按对象保存表面类型。
2. 在真实星体目录、对象身份与历元明确后，接入有来源记录的真实行星地图。
3. 表面细节分档、法线／高度细节、体积云与更精细的大气模型，先做真机性能测试。
4. 近距离高精度引力积分与局部 SPH 撞击耦合；海洋／大气物理需要独立的材料与数值验证，不把纹理演示当作计算成果。
