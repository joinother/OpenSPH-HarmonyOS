# 0.30.0 · 用对照实验检查碰撞结果

> 类型：版本记录；版本：0.30.0；实现／验证日期：2026-09-07（Asia/Shanghai）。

## 功能

实验库增加“碰撞放大镜 · 速览”和“碰撞放大镜 · 细看”，仅将粒子预算由 200 改为 1200；两球半径、密度、速度、角度、种子和 16 秒时长相同。复用已有岩质碰撞概念封面，目录现在有十二个主题。进入和切换后都暂停在初始帧，默认岩质外观，运行后可查看同一组压力、内能和损伤曲线。

主题引导新增“查看碰撞曲线”，直接打开压力指标；保留原生场景、计算结果、时间选择、着色和相机。原“切换速度对照”改为通用的“切换对照实验”，兼容慢撞／快撞和速览／细看。所有新入口共用 ArkUI／CLI 动作，命令见 [CLI 指南](../CLI.md#主题实验库)。封面按主题提供的 `cover` 字段读取，支持复用而不会落入错误封面。

应用继续使用自适应 Courant 步长，预算 200／1200 实际为 212／1276 粒子，本轮两组均计算至约 16.07 秒。产品没有提供固定步长设置、自动 SPH 曲线叠加或“准确度已达标”提示。

## 数值工作

新增 30 项材料方程检查，以及桌面／鸿蒙各六次独立 IRun 研究：三组固定步长、三组粒子预算（复用一组）和一次重复运行，每次四个严格对应时刻。逐步核对质量、线动量、质心直线运动和数据有限性。跨平台对应样本最大归一差约 1.51×10⁻¹⁵。最终独立测试脚本也已 [重新执行并核对](../evidence/sph-0.30.0-baseline-recheck.json)。

缩小步长后压力／内能较稳定，但增加粒子后的差异仍明显，损伤差异不单调。因此本轮建立的是解析极限与敏感性基线，没有认定空间分辨率收敛，也没有宣称通过标准冲击管／弹性波验证。具体初值、容差、比较公式和复现步骤见 [SPH 基线说明](../reference/SPH-BASELINE.md)。

## 首次失败与边界

首次应用主题切换曾停在 preparing，之后一次卡片测试也超时。独立原生 Engine 切换通过；临时阶段标记、重新构建和重启后不再复现。临时标记已完全移除，原生运行代码与 0.29.0 相同。最终包另做完整主题和窗口复测，仍保留 [首次调查记录](../evidence/sph-0.30.0-transition-investigation.json)。原因未确定，不能将重试成功写成已修复某个源代码错误；后续需要更完整的准备阶段跟踪与卡顿复现。

横屏点击测试也曾在面板动画结束前读取旧页签，稍后截图和状态已处于目标页。验收脚本改为等待目标主题／面板状态后断言，只点击一次，不用重复点击掩盖失败。

未新增自引力、完整弹性能量预算、轨道到局部 SPH 的转换、碎片再聚集或月球形成。源码与模拟器包作为开发检查点保存，历史版本产物保持原字节；不代表应用市场发布或真机认证。

## 后续

优先增加准备阶段可观察性与超时诊断，同时建立独立参考解的冲击／弹性标准算例。继续分离时间误差、空间采样与损伤缺陷分配影响，再推进自引力稳定性与局部 SPH 接入。
