# 0.16.0 · 全窗口沉浸式

> 类型：版本记录；适用版本：0.16.0；实现与验收日期：2026-09-06（Asia/Shanghai）。

此前只把系统栏设置成透明，没有隐藏状态栏和底部手势指示条；页面根节点又按安全区添加内边距，导致宇宙视口没有铺满窗口。本版统一修复系统栏策略与画面尺寸。

## 行为

- 主窗口进入全屏布局，分别请求隐藏状态栏、传统导航栏和手势导航指示条。应用返回前台时重新应用策略。
- 原生宇宙视口覆盖整个窗口；工具栏、面板、时间轴和按钮单独避让安全区。安全区变化会重新计算布局，不重建场景。
- 横竖屏与折叠切换继续保留相机、编辑草稿、放置预览与回放位置。CLI 的原生投影尺寸对应完整窗口，`layout.safe` 表示控件使用的安全区域，见 [CLI 指南](../CLI.md)。
- `window.immersive` 表示应用成功执行沉浸策略，不是系统栏实时可见性的检测结果。

实现参考华为官方 [应用沉浸式效果](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/arkts-develop-apply-immersive-effects)，通过开发者 MCP 查阅。系统边缘手势仍可临时唤出系统导航；自由窗口模式的行为有平台限制，本轮未验收电脑自由窗口或真机。

## 验收

- [31 项主机测试](../evidence/immersive-host-tests.txt)：既有语义动作覆盖，以及全窗口视口、安全区布局和系统栏独立隐藏请求。
- [构建](../evidence/immersive-build.txt) 与 [安装](../evidence/immersive-install.txt) 成功。
- [9 个模拟器场景](../evidence/immersive-device-tests.json)：折叠竖屏、两个横屏方向、展开横竖屏、再次折叠、放置横屏、放置展开与全景横屏；核对完整窗口投影、控件边界和场景状态保留。
- 返回桌面再进入应用后，沉浸策略恢复，场景及编辑状态保持，见 [前台恢复状态](../evidence/immersive-foreground-state.json)。
- 已人工检查折叠竖屏、横屏和最终展开截图，未见顶部状态栏或底部白色手势条，银河背景延伸至窗口边缘。这些检查不代表真机触摸、动画帧率或传感器验收。

验收后恢复用户原有六天体初始条件、相机及外观设置，停在暂停的初始帧并恢复自动旋转，见 [最终状态](../evidence/immersive-final-state.json)。此前失败的求解结果没有恢复；实验库中的六天体备份保留。本版未修改物理模型。
