# 0.10.0 · 银河远景

> 类型：版本记录（仅描述该版本）；适用范围：0.10.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

背景从有限空间中的 230 个随机粒子改成独立天空层：6,500 个固定方向星点，以及带星云亮区和尘埃暗纹的银河示意带。可以选择纯净、星空、银河，并调节亮度；近看时背景自动变暗，让行星表面更清楚。

## 为什么这样做

从银河系内部看，其恒星盘形成横跨天空的亮带；完整的旋涡星系外观是另一种观察尺度。当前行星实验采用银河带作为背景更合适。[NASA 解释](https://imagine.gsfc.nasa.gov/science/objects/milkyway1.html)

“天区”也不等同于背景图片。现代星座是有边界的天空区域；接入真实天区需要星表、赤道坐标、历元和观测参考系。[IAU 定义](https://iauarchive.eso.org/public/themes/constellations/)

参考了 Celestia 将远处星系对象、方向变换和亮度分开处理的思路；其银河实现还按可见尺寸决定绘制细节。本轮没有复制它的实现或素材，新增 sky_data / sky_renderer 均为本项目原创。[Celestia 银河渲染源码](https://github.com/CelestiaProject/Celestia/blob/master/src/celrender/galaxyrenderer.cpp)、[许可证](https://github.com/CelestiaProject/Celestia/blob/master/COPYING)

## 当前实现与真实性

- **艺术化示意，不是真实星图。** 固定种子 24190906；星点位于单位球面，亮度和颜色分布用于显示，未对应已命名恒星、真实星等或星座。
- 银河纹理由连续三维噪声生成，经纬展开为 1024×512 RGB8，双线性与 mipmap 采样。采样导数处理经度接缝；尘埃暗纹和亮区均为视觉设计，没有使用摄影贴图。
- 天空采用固定短轴视场，方向跟随镜头 yaw/pitch，忽略实验的平移、跟踪位置与正交缩放。当前是局部实验背景，没有恒星距离视差，也不能飞出银河。近处行星仍沿用原有实验投影。
- 天空先绘制且不写深度，之后恢复深度状态绘制物理天体、轨道。背景星点不参与物理求解和天体点选。
- 亮度按每秒 2 个强度单位线性渐变，完整 0→1 最长 0.5 秒；近看完成后远景亮度为设定的 35%。后台停止绘制和渐变推进，返回后继续。
- 数据在 Surface 的 GL 上下文初始化时生成，静态顶点／纹理只上传一次；逐帧只更新方向和亮度。Surface 重建重新创建，销毁时由原渲染线程释放 GPU 对象。
- 银河纹理含 mipmap 约 2 MiB，星点顶点约 178 KiB，不含驱动分配。不是整个应用的显存／内存测量。未做真机温控和长期帧率保证。

默认银河、亮度 65%。设置在当前应用会话内跨场景保留，不写入物理场景／回放；应用重启恢复默认。亮度为 0 时与纯净模式一样没有星点和银河，但保留深色底色。

## UI 与 CLI

观察面板最上方新增“远方星空”，三种模式和亮度 Slider 与 CLI 共用处理。视口注明“银河背景 · 示意”。

- `setSky {mode?:0|1|2,brightness?:0..1}`：幂等修改，先完整验证再设置。省略字段保留原值。0 纯净、1 星空、2 银河。
- `getSkyInfo {}`：返回示意性质、种子、星点数、纹理尺寸、参考系和实际渲染状态。
- `uiAction {action:"sky.mode.0"}`，也支持 .1、.2。
- `setUiValue {field:"sky.brightness",value:0..100}`：与百分比 Slider 一致。
- `getState.sky` 表示目标配置；`rendering.skyReady`、skyStars、skyGalaxy 表示天空资源是否可用及渐变后的实际强度。CLI 返回设置成功不等于渐变已经完成。

## 下一步

真实星空应独立接入有明确授权的星表与银河观测数据，完成赤道／银道变换、历元和相机参考系约定后，再加星名、星座边界和天区检索。它不改变此前的物理路线：压力／内能／损伤观察、自引力基线、碰撞碎片连接仍是后续工作。

## 验证记录

- 18 项宿主 CLI／事务／按钮绑定测试通过，包含背景设置全量验证与物理配置不变。
- 天空数据在 AddressSanitizer、UndefinedBehaviorSanitizer 下通过：固定种子复现、6500 个单位方向、银河附近星点集中、有限色值与经度接缝连续。
- 展开窗口的像素对比：移除银河产生明显差异；移除星点可测；局部缩放与跟踪变更后，排除前景天体的背景像素差异为 0；旋转改变背景；近看强度降为设定的 35%。见 sky-device-tests.json。
- 原有语义 UI 与天体点选／真实拖动回归通过。背景未进入物理天体列表和命中列表。
- 折叠窗口同组像素／CLI 测试通过，额外验证旋转 2π 后星空恢复；见 sky-phone-tests.json。已检查手机观察面板的实际截图。
- 海洋／云层／大气／外观自转及前后台渲染回归通过，见 sky-material-regression.json。上述结果为模拟器验收，不代表全部真机性能。
