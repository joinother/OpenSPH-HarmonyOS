# 0.43.0 星系潮汐相遇

> 类型：版本记录；验证与发布日期：2026-09-08（Asia/Shanghai）；版本：0.43.0 / 1000044；开发模拟器：127.0.0.1:5555。

## 行为变化

实验库新增“两条潮汐尾”和“反转一片星系”。两个移动的扩展引力势驱动金色／蓝色示踪盘，演化中出现拉伸、物质桥与潮汐尾。两组初值只改变次盘旋转方向，可直接比较形态。新封面来自本模型 400 Myr 时刻的实际示踪点投影，由项目自行生成。

参数页新增星系潮汐，支持点数、质量比、接近速度、初始横向偏移、倾角、次盘旋转和模拟时长；默认 1600 点、600 Myr。修改先进入草稿，应用才从零重建。每 4 Myr 及最终时刻记录回放，暂停、回看、旋转和跟随中心保持同一条历史。金／蓝代表来源，柔和光点不使用岩体碰撞的粒子着色。背景切换为较暗星空，时间使用 Myr。

观察页显示中心间距、两盘均方根半径、外延示踪点比例和中心能量偏差。UI 与 CLI 共用参数和动作；新增 `getGalaxyDiagnostics`，命名实验保存星系初值，v12 回放保留实际轨迹与诊断，兼容旧版本。星系场景禁用行星表面与岩体材料控件，避免跨模型误用。完整定义、操作与近似范围见 [模型参考](../reference/GALACTIC-TIDES.md)。

- [127 项主机检查](../evidence/galaxy-0.43.0-host-tests.txt)：七种实验的时间单位、星系参数、配方、模型身份、共享动作及旧功能回归。

- [ARM64 引擎](../evidence/galaxy-0.43.0-engine.txt)：初始暂停、奇数点数、50 Myr 记录节奏、v12 字节一致往返、损坏／非法模型原子拒绝、定位／取消／替换及旧轨道回放；[旧引擎](../evidence/galaxy-0.43.0-legacy-engine.txt) 和 [实体接触](../evidence/galaxy-0.43.0-legacy-contact.txt) 回归继续通过。
- [实际应用](../evidence/galaxy-0.43.0-device.json)：初值草稿、非法输入、完整 600 Myr 演化、151 帧保存／载入、回看和跟随。1600 点例中，600 Myr 次星系外延点比例顺行为 47.875%，逆行为 22.625%；它是超过初始盘外缘 1.5 倍的点数比例，不是逃逸质量。
- [三布局与手势](../evidence/galaxy-0.43.0-visual.json)：展开竖屏、折叠手机和折叠横屏保留 400 Myr 与诊断；真实视口拖动改变镜头而不重算，观察面板不改变历史。五张截图已逐一查看，渲染无报错，沉浸式状态有效。CLI 控件验收不代表逐个验证了触摸命中或动画帧率。

## 模型边界与下一步

本版使用两个 Plummer 解析势和无质量恒星示踪点；中心间使用对称软化近似。没有恒星间自引力、气体激波、动力摩擦、自洽暗晕、恒星实体撞击或完整星系合并。误差与步长检查只验证这一受限模型，没有完成真实星系初态和分辨率的科学收敛研究。

独立 kpc／Myr 单位与实验局部显示已接入，完整宇宙目录、层级参考系和全尺度连续 LOD 尚未实现。下一步先补星系放置预览与数据导出，再评估带质量盘／暗晕和气体云基准；行星事件转入局部 SPH 的坐标、质量、动量与材料映射继续保留为物理主线，见 [实施顺序](../reference/RESEARCH-IMPLEMENTATION.md)。
