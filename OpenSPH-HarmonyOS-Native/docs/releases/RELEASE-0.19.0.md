# 0.19.0 · 环为什么会错位

> 类型：版本记录；适用版本：0.19.0；实现与验收日期：2026-09-06（Asia/Shanghai）。

新增第八个探索主题，以 192 个示踪点展示行星环的差速运动。12 条圆轨道上的点在零时刻排成径向队列，运行后内圈领先外圈，队列逐渐错开。底部使用独立小时轴，保留同一个宇宙视口、镜头与主系统场景。

## 模型与操作

原生模块 `ring_trace.h` 使用无质量试验粒子的解析圆轨道，速度为 `sqrt(mu/r)`，周期为 `2*pi*sqrt(r^3/mu)`，位置和速度来自相同轨道解。公式依据 [NASA 的圆轨道与开普勒第三定律说明](https://pwg.gsfc.nasa.gov/stargaze/Skepl3rd.htm)，量纲在模块中统一为 km、s。没有引入同行私有代码或纹理。

中心引力参数取所选行星的太阳质量比例乘项目既有太阳 GM；行星半径假定为 60000 km，12 条轨道的半径为其 1.28–2.22 倍。默认主题内圈周期约 6.03265 h、外圈约 13.77916 h。默认 192 点的初始位置与抽样固定；青色至金色标记由内圈到外圈，不表示温度或粒子物质。

- 通过“实验库 → 探索 → 环为什么会错位”进入；或选中带环行星，在观察面板打开“开普勒示踪粒子”。新主题有独立概念封面。
- 小时时间轴范围 0–24 h；运行、暂停、任意时刻定位和归零复用语义 CLI。到终点停住，不自动循环；再次运行从零开始。
- 局部模式启动时暂停主系统并停止外观自转；主系统的配置、轨迹与时间保留。每个显示步推进约 3600 倍时间，后台不推进，长卡顿不追赶墙钟时间。
- 开始主系统、历史回放操作、换天体、返回全景、重建场景或进入放置工具时退出局部模式。退出不自动恢复主系统运行。
- 粒子使用原生点绘制，背面的点受球体遮挡；位置共用行星环的倾斜平面与连续镜头。独立控制栏适配展开、折叠竖屏及矮横屏；横屏省略末尾状态提示，保留周期读数。
- `getRingTrace` 提供轻量状态或完整的 192 点位置、速度、半径与周期。单位及动作见 [CLI 指南](../CLI.md#局部示踪环)。

## 边界与下一步

示踪点不具有质量，没有点之间的引力、接触碰撞、破碎或黏结；也没有太阳／卫星摄动、行星扁率和自引力。装饰薄环仍是外观，示踪点不是重建实际土星环的组成，亮点采用便于观察的标记色。

这是行星中心局部圆轨道的解析基线，尚不能模拟投放任意速度的环粒子或卫星扰动。示踪状态只保留本次会话，不写入现有初始条件实验或 v4 回放；它不是完整求解检查点。下一步可在此基线上加入任意初速度与卫星摄动，并用轨道偏心率、能量和角动量曲线对照，再考虑粒子相互作用。
