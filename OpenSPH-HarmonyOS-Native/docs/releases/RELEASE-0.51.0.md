# 0.51.0 小岩体放置与物理单位

> 类型：开发断点记录；实现与验证日期：2026-09-08（Asia/Shanghai）；应用版本：0.51.0 / 1000052。

## 新行为

选中天体后使用“添加卫星／向它发射／附近投放”，参数默认显示公斤、中心距母体表面的高度、公里每秒和直径。可以换算到天文单位、中心距离和半径；切换保留同一候选的物理状态，不完整输入会被拒绝而保留草稿。数值输入移到辅助预览图之前。

高度指新天体中心距母体表面的距离，改变自身半径不自动改变中心高度。绝对速度模式改变距离或质量后保留 km/s；倍数模式保持圆轨道速度比例。完整初值仍继承母体速度，并接受相对首颗恒星的速度校验。

“15 km 岩质小行星”提供直径 15 km、均匀密度 2700 kg/m³ 所对应的约 4.77e15 kg 初值，保留现有位置与速度输入。此后质量与尺寸可独立编辑，尚无密度锁定。向小岩体添加卫星时，默认质量随母体缩小，受最低质量与半径预算限制。

非恒星质量下限由 1e-8 降至 1e-18 太阳质量，输入验证、原生插入、配方保存和 v14 回放读取共用新范围。实体半径仍至少 1 km；估算半径也遵循此下限。低质量带环外观不自动获得动态环：既有固定尺度示踪环要求至少 1e-8 太阳质量，UI 与配方按此限制。

设备压力下曾出现 HiLog 回复缺段。本版降低输出速率，并缓存最近 8 份已计算结果；命令行发现部分回复停滞后，用同一请求 ID 重取缓存，最多 3 次。重取不再次执行原动作，也不会因不确定回复再次插入天体。全部数据丢失、缓存过期或设备不响应仍可能超时，不承诺无限重试。

## 验证

- [105 项主机检查](../evidence/small-body-0.51.0/ui-tests.txt)：真实页面语义实现、单位换算、移动母体速度、固定绝对速度、无效值／重叠拒绝、取消、低质量卫星默认值、项目序列化；另模拟丢失回复中间片段，重取后插入调用仍为一次。
- [数值对照](../evidence/small-body-0.51.0/gravity.txt)：保留十圈卫星基线，并加入 15 km 岩体以 10 km/s 从距地表 25,000 km 处朝地球发射的二体测试。接触约在 2259.69 s；解析接触速度约 14.1269 km/s。默认自适应步进测得约 14.1262 km/s，相对偏差 5.03e-5；0.125 s 步长偏差约 2.64e-6。预算为 1e-4，尚非全场景收敛证明。
- [原生引擎](../evidence/small-body-0.51.0/engine.txt)：在指定模拟器独立进程测试，小质量插入、非法质量拒绝时原状态保持、质量／半径精确 v14 往返、继续运行及最低质量边界；同时执行原连续时钟回归。
- [轨道回归](../evidence/small-body-0.51.0/orbit.txt)与[实体接触回归](../evidence/small-body-0.51.0/contact.txt)：守恒、接触、同时碰撞、失败回退与步长对照。
- [实际应用语义验收](../evidence/small-body-0.51.0/device.json)：物理单位、候选换算、星图语义点放、取消、当前时刻插入、回放恢复、引力加速后的接触与自动暂停。四体背景中的实际接触时间约 2259.69 s、法向相对速度约 14.127 km/s；与孤立二体测试的模型条件不同。
- [参数布局](../evidence/small-body-0.51.0/physical-inputs.jpeg)、[星图预览](../evidence/small-body-0.51.0/launch-preview.jpeg)、[接触画面](../evidence/small-body-0.51.0/small-rock-contact.jpeg)：指定模拟器当前展开窗口的静态检查；不代表触摸、动画流畅度或所有折叠方向验收。
- [通用界面语义回归](../evidence/small-body-0.51.0/ui-regression.json)：添加／编辑、近看切换、外观、面板、时间与批次失败停止通过。首轮曾因 HDC 超时中断，重开应用后复测通过；[中断记录](../evidence/small-body-0.51.0/interruption.json)另保留较早启动时的系统运行库 SIGSEGV，根因未确认，未宣称已修复该退出问题。
- [会话恢复](../evidence/small-body-0.51.0/restoration.json)：恢复测试前五体系统的精确向量、时间、240 帧历史、外观种子及相机，恢复原回放文件，再继续原运行状态；[13 个原有持久文件](../evidence/small-body-0.51.0/files-restored.json)按 SHA-256 核对字节不变。
- [构建](../evidence/small-body-0.51.0/build.txt)与[安装](../evidence/small-body-0.51.0/install.txt)：仅操作 127.0.0.1:5555，不涉及真机录制。

复测前运行 `scripts/preserve-orbit-emulator-session.mjs 127.0.0.1:5555 <新的恢复目录>`，再运行 `scripts/test-small-body-emulator.mjs 127.0.0.1:5555 <证据目录> <恢复目录>`。备份工具要求无未提交草稿、无独立环时钟、无历史回放播放的自定义轨道会话；测试恢复依赖备份成功，不可省略。工具使用当前项目根目录运行。加 `--ui-regression` 可在专项后运行通用界面回归。若设备连接中断使自动恢复未完成，可单独执行 `node scripts/restore-orbit-emulator-session.mjs 127.0.0.1:5555 <恢复目录> <证据目录>`；恢复成功之前保留整个备份目录。

## 仍未完成

含新质量范围的配方／回放需要 0.51.0 或更新版本；旧版应用虽认识 v14 文件结构，其质量校验仍会拒绝此类新状态。

本版推进的是 P1 和 P2 所需的小质量入口。最多仍为 8 体，局部放置中心距离至少约 149.6 km；公里级支持不能宣称米级陨石能力。主场景渲染仍使用浮点显示坐标和放大的可读标记，不代表 15 km 天体在整个太阳系视图中具有真实角直径。

接触仍为理想弹性反弹及自动暂停。轨道碰撞到 SPH、分层行星、熔融、碎片回注、卫星摄动环与环再聚合均未在本版实现。当前接触记录使用步进中的半步速度，且不保留响应前双方完整状态，不能直接作为可信 SPH 初态；下一任务按[产品实施路线](../reference/PRODUCT-ROADMAP.md)补事件与转换，再接入局部材料求解。
