# 0.20.0 · 给环一点额外速度

> 类型：版本记录；实现与验证日期：2026-09-07（Asia/Shanghai）；设备：127.0.0.1:5555。

## 变化

第九个探索主题以 1.12 倍圆轨道速度发射示踪点。192 个无质量粒子沿圆／椭圆轨道运动；调轨面板支持 1.00–1.20 倍切向发射速度、0.1–4 小时/秒慢放与快进、圆轨道对照、归零、跳到内圈首次远点。速度实际改变时归零暂停，倍率只改变播放速度，主星系初值和时间保持。

新增内圈首粒子的俯视轨道预览，以及偏心率、近远点、当前距离和速度读数。标记跟随原生坐标，预览自适应轨道范围。手机时间轴移走归零按钮，为拖动留出空间；归零保留在调轨面板，宽屏时间轴仍有快捷入口。新增动作和两个字段均由 ArkUI 与 CLI 共用。

连续导出时发现 HiLog 回复丢片。修复包括减少重复数据字段、按 UTF-8 字节预算跨请求限速、保护分片边界的代理字符对，以及超过分片上限时返回错误。大响应的传输延时相应增加；未修改模拟器全局日志设置。

## 模型与边界

切向发射比例 f 对应 e=f²−1、a=r₀/(2−f²)，限定 e=0–0.44；从近点出发，解 M=E−e sin E 后求坐标和速度。算法依据公开的 [JPL 轨道坐标与开普勒方程说明](https://ssd.jpl.nasa.gov/planets/approx_pos.html) 独立实现，未引入竞品代码。日志处理参考 [华为 HiLog 超限与丢失说明](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/hilog)，通过官方开发者 MCP 查询。

这是中心引力下的开普勒模型，不是相互碰撞的土星环求解器。假定行星半径 60000 km，12 组初始距离为 76800–133200 km，忽略太阳、卫星、扁率、自引力与接触；只支持加速后的有界轨道，未实现向内发射或逃逸。艺术环带不会随示踪点展开。外圈周期可能超过 24 小时，本版时钟仍限定 0–24 小时。

局部参数、时刻和开关为会话状态，不写入命名初值或 v4 回放。主星系重建、切换天体、全景、放置、回放仍退出局部模式。离开后重新开启恢复圆轨道与默认倍率；选择椭圆主题会设置为 1.12 倍。主系统不会自动续跑。

## 验证

- [43 项主机测试](../evidence/ellipse-0.20.0-host-tests.txt)：共用动作、参数原子校验、局部时钟状态、已有 CLI 回归，以及大响应限速和 Unicode 分片完整性。
- [C++ 数值对照](../evidence/ellipse-0.20.0-numerical-tests.txt)：保留地球圆轨道周期参考；9216 个椭圆状态的力、能量、角动量检查；近远点、周期闭合和独立 leapfrog 积分收敛。1.12 倍发射时，6 小时位置误差在 60/30 秒步长下为 52.6736/13.1685 km，约为二阶收敛。运行时采用开普勒解，数值积分只用于交叉验证。测试启用 ASan/UBSan。
- [投影与镜头回归](../evidence/ellipse-0.20.0-projection-tests.txt)。
- [模拟器椭圆验收](../evidence/ellipse-0.20.0-device-tests.json)：四种发射速度、原生 192 粒子数据、近远点与守恒量、慢放／快进、非法输入不改变状态、展开／折叠／横屏布局。主系统时间、初值、场景版本和渲染表面均保持。
- [圆轨道模拟器回归](../evidence/trace-0.20.0-device-tests.json)：粒子实际像素移动、暂停／定位、后台停钟、24 小时终点、手机和横屏时间轴。手机滑条宽度由首次版本的 158 px 增至最终的 324 px。
- [既有 UI／CLI 回归](../evidence/ellipse-0.20.0-ui-regression.json)：编辑、放置、外观、面板、播放、批次失败停止、文件参数与等待求解状态。
- [构建](../evidence/ellipse-0.20.0-build.txt) 和 [模拟器安装](../evidence/ellipse-0.20.0-install.txt) 成功；当前交付为模拟器未签名 HAP。
- 对照 [测试前状态](../evidence/ellipse-0.20.0-before-state.json) 和 [恢复后状态](../evidence/ellipse-0.20.0-final-state.json)，重新计算并恢复三种世界主题的四天体、3 年终态、相机、外观、面板和展开横屏尺寸；局部示踪已关闭。

这些检查不代表真机触摸命中、折叠传感器、动画流畅度或持续性能测试，也不证明相互作用环或碰撞模型正确。
