# 0.47.0 · 恒星群与中心双向引力

> 类型：版本记录；实现与验证日期：2026-09-08（Asia/Shanghai）。

旧星系实验中的恒星无质量，不能反过来拉动两个引力中心。本版增加独立的 `galaxy-responsive-v1`：20% 总质量分配给恒星群，群间引力与群对中心的反作用均逐对计算；其余 80% 为可移动、形状固定的扩展中心。没有强制粘合或人为减速。旧模型和旧回放保留，方便对照。

## 使用

实验库选择“恒星也能拉动星系”，开始后观察相遇，再用“切换对照实验”比较无质量模型；两者空间质量分配和初始圆速度不同，不能视为只开关一项力的严格因果实验。参数页“恒星参与引力”与 CLI `galaxy.responsive` 共用草稿处理，新模型限制 200–800 群；`setScene` 使用 `galaxyResponsive:true`。盘内天空、相遇预览、曲线和命名实验均接入。

回放 v13 保存新模型身份及全系统误差，v12 仍为限制性模型。本地参照支持两种模型；CSV 维持 18／19 列，但计数与误差表头改为按 model 解释的名称。详见 [模型定义](../reference/GALAXY-RESPONSE.md) 与 [CLI 指南](../CLI.md)。

- [最终视觉检查](../evidence/galaxy-0.47.0-visual.json)核对实际模型标注、完整开关边界、滚动不改变参数、地表渲染时刻；[原有 UI 回归](../evidence/galaxy-0.47.0-ui.json)覆盖行星编辑、近看、回放与 CLI 批处理。截图为展开窗口，不声称重做所有折叠和手机触摸验收。

初次模拟器运行因未优化计算及 CLI 响应等待超时而停止；随后优化星系计算单元。验收脚本另修正了应用草稿后的场景身份预期、观察结果的 data 层级，以及应使用完整 origBounds 而非裁剪 bounds 的判断。一次滚动起点落在滑条区域，修改了草稿；改用滚动区边缘并断言草稿不变。之后遇到与预期不同的回放长度，又捕获了新的完整星系运行记录；未确定触发来源，额外备份后继续。旧 UI 回归的等待上限改为显式 60 秒。截屏工具覆盖旧文件留下尾部字节，打包检查拒绝后已清理本轮旧截屏并重新捕获。失败原始记录保留在 [过程记录](../evidence/galaxy-0.47.0-validation-iterations.txt)，不计入通过项。

## 边界与下一步

孤立盘 800 Myr 的均方根半径从约 7.747 增至 9.895 kpc，数值守恒不代表平衡初态。本版是双向引力原型，尚非科学标定的星系合并：没有可变形暗晕、气体、冷却、恒星形成、完整动力摩擦收敛研究或真实银河系／仙女座初值。下一阶段优先解决孤立平衡、采样和软化敏感性，再接活暗晕、树求解与长时合并验证。
