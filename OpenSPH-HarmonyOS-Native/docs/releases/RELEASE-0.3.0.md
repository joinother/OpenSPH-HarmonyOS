# 0.3.0 · 可编辑天体与实验库

> 类型：版本记录（仅描述该版本）；适用范围：0.3.0。
> 整理日期：2026-09-06（Asia/Shanghai）。

原始发布日期未单独记录；文内明确写出的验证日期保留原义。当前操作以 [CLI 指南](../CLI.md) 为准。

2026-09-06，已构建、安装并验证于 `127.0.0.1:5555` ARM64 API 24 模拟器。未操作另一台连接的平板，未推送远端或发布应用市场。

新增主天体/撞击体名称、半径、初始密度编辑，以及主天体附加自转。界面以球体体积和密度估算质量；真实粒子总质量可通过 CLI 读取。初始密度仅允许在默认岩质模型附近调整（2400–3000 kg/m³），尚未做静力平衡，不等同于自由材料编辑或科研精度认证。旋转预设的附加自转与原有角速度叠加。

新增多实验库：有名称、有模型和数据格式版本、保存随机种子。每次保存创建新实验，最多 50 个；当前尚未加入重命名、删除、缩略图或对外分享。项目保存的是初始条件，载入后重新生成暂停场景；不声称支持中途续算。

回放格式 v2 记录原生求解配置，载入时恢复实际半径、密度、自转、种子等。继续兼容 v1 文件，并标注旧文件参数未知。回放仍最多 240 帧且仅保存一个文件；名称使用通用名称，完整自定义名称保存在实验项目中。仍按帧播放，尚未实现物理时间匀速播放。

界面可从顶栏直接进入实验库，载入后返回实验。滑块只在用户交互事件中写入参数，修复冷启动控件初始化将 CLI 的 1 秒实验改为 10 秒的问题。质量不是独立可编辑量；质量/半径/密度联动锁定待后续加入。

已完成验证：

- 原生 ARM64：三个基准场景、暂停恢复、确定性重复、质量守恒、60 秒实验和 240 帧上限；自定义尺寸/密度的粒子总质量与理论值误差小于 2%；回放 v2 配置恢复、v1 兼容、非法半径事务拒绝。
- CLI 设备：冷启动、命令目录、非法配置、相机、面板、求解、seek、回放往返；多项目另存、重启后载入、目录穿越拒绝与回放恢复原始配置。
- 宿主端：6 项真实 ArkTS 非渲染逻辑与命令传输测试通过。
- UI：通过 UITest 实际点击实验库“载入实验”；半径滑块从 120 km 修改为 160 km，CLI 确认输入 dirty=true、原生配置仍为 120 km；点击“应用并开始”后原生配置变为 160 km，求解完成且 dirty=false。截屏检查状态栏、底部手势区与新面板。

日志见同目录 [scene-native-test-results.txt](../evidence/scene-native-test-results.txt)、[project-device-test-results.json](../evidence/project-device-test-results.json)、[scene-cli-device-test-results.json](../evidence/scene-cli-device-test-results.json) 和 [scene-host-test-results.txt](../evidence/scene-host-test-results.txt)。
