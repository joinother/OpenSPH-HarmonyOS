# 0.31.0 · 准备阶段可见与取消

> 类型：版本记录；版本：0.31.0；实现／验证日期：2026-09-07（Asia/Shanghai）。

## 功能

生成实验时显示主天体、撞击体、运动与材料、轨道、初始画面等真实阶段，以及本次请求的累计耗时。同一阶段持续 15 秒会提示耗时较长，不使用估算百分比。主按钮在准备期间变为取消入口；观察面板可以停止准备／运行／暂停的求解，停止后可从初始条件重新计算。

原生线程在生成和初始化边界检查请求身份，过期请求不能覆盖新场景。当前请求排队时可看到上一轮工作线程的阶段；准备完成、失败或取消后计时冻结。取消不会强制杀线程，上游函数必须返回后才能协作退出。详见 [准备诊断指南](../reference/PREPARATION.md)。

CLI 新增只读 `getPreparation`，与完整状态同源；新按钮共用 `simulation.cancel`。等待状态会核对最初请求身份，遇到替换、取消或求解失败提前返回；超时及后续读取失败保留最后状态、配置与准备记录，便于继续定位。不会自动重试执行或取消。初次未收到有效回复的传输错误仍单独报告，见 [CLI 指南](../CLI.md#准备取消与等待)。

## 边界与下一步

本轮没有重现 0.30 首次 preparing 卡顿，原始根因仍未确定；增加的是可观察性和阶段间取消能力，不能据此宣称修复死锁。15 秒阈值由确定性原生测试验证，没有向正式应用故意注入卡顿；实际触摸覆盖暂停状态停止与重启，准备期间瞬时取消入口由共享动作和主机检查覆盖。

记录仅保留当前会话，不进入实验配方或回放。载入回放清空准备状态，不改变已有 v1–v5 回放格式。物理方程、粒子预算和时间步配置未变；没有加入自引力、轨道到局部 SPH 转换、碎片再聚集或月球形成。

下一步仍按标准冲击／弹性独立参考算例、分辨率与损伤验证、自引力稳定性、局部 SPH 与轨道连接的顺序推进。若再次出现准备停滞，先保存阶段轨迹和对应配置，进一步定位上游构建／资源释放过程。
