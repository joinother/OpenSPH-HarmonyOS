# 0.56.0 · 碎片来源质量与导出

> 类型：开发断点记录；实现与验证日期：2026-09-08（Asia/Shanghai）。

## 本批实现

按公开用户样本中“分析残骸来自谁”的需求，接入真实逐粒子初始来源与双精度质量。碰撞后每个几何团块显示来自双方的比例，可直接打开来源列表、按灰岩／赭岩着色、分页及跟随。按钮与 CLI 共用动作，新增只读分页 CSV，导出带帧、事件和材料身份。新 v20 回放保存逐粒子质量与来源，兼容基础 v15／v17／v19；旧记录缺少数据时明确无法统计。

这一步是 P2 的来源追踪和 P4 的质量核对准备，没有加入新力项、束缚判定、粒子合并或轨道残骸回注。双方仍是同一种玄武岩，比例不代表地核／地幔成分或液相含量。完整定义见 [来源质量](../reference/FRAGMENT-PROVENANCE.md)。

- [既有隔离撞击回归](../evidence/provenance-0.56.0/isolated-native.txt)及 [SPH 专项回归](../evidence/provenance-0.56.0/sph-regression.txt)通过。旧格式字节断言使用显式兼容夹具；SPH 专项使用 `--sph-only`，没有把旧全域轨道格式断言计为通过。
- [主机检查](../evidence/provenance-0.56.0/host-tests.txt)：116 项，包含界面动作／输入绑定、来源 CSV 的实际质量、分页、帧及事件身份、旧记录拒绝、观察入口不改物理状态。
