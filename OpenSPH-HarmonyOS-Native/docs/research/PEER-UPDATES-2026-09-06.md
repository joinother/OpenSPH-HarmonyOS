## SpaceSim：联动参数、状态保存与镜头

通过作者的 [官方公告](https://steamcommunity.com/app/4055380/allnews/)及 [Steam 官方新闻 API](https://api.steampowered.com/ISteamNews/GetNewsForApp/v2/?appid=4055380&count=20&maxlength=0)核对了 0.10（2026-03-11）、0.11（2026-08-08）和 0.11.260809（2026-08-09）。日期取 API 的 UTC 日期，避免把公告只显示的月日误配年份。

0.10 增加轨道要素、希尔球和 Lua 场景生成。0.11 的实用改进包括质量／半径／密度的锁定联动、跟随表面朝向的相机、变量曲线、保存自定义天体和渲染比例。新增恒星结构求解仍有明确限制，不能理解为完整恒星生命周期。随后补丁修复状态续算、应力矩阵保存、空相机路径与纹理分配问题。

这些更新对我们更直接的价值是：

- **编辑关系明确。** 以后引入真实半径和密度时，用户能选择保持密度还是保持半径；提交前显示联动结果。当前模型的显示半径不能直接当作材料半径。
- **保存可恢复的状态。** 把初始条件模板、显示快照与完整求解检查点分开。后者需要速度、材料内部状态、积分器状态和模型版本；先做连续运行与保存后续算的对照。
- **对象模板可复用。** 第一阶段保存初始天体及原创外观；从碰撞结果提取可继续模拟的天体，须等碎片识别与状态重建。
- **镜头有异常路径。** 空路径、目标删除、中途取消和应用恢复都要有定义。对移动设备，渲染质量档位优先于增加昂贵特效。

本轮没有把 SpaceSim 的 GPU 求解器或新增闭源功能视作现有 OpenSPH 导入代码已经具备的能力。

## 收敛成下一批工作

以下名称、顺序和验收标准是本项目设计提案。

| 次序 | 具体交付 | 完成标准 |
| --- | --- | --- |
| 1 | 土星风格环带与选择反馈 | 先完成已承诺的三维薄环、前后遮挡、环影；选择轮廓不遮住目标，动画不改变物理状态 |
| 2 | 复制为待放置草稿、保存完整主题外观 | 复制后先预览位置，不直接重叠插入；取消无副作用，确认是一笔撤销事务；重启后恢复主题与原创外观 |
| 3 | 连续跟随与实验数据卡 | 镜头目标与编辑对象独立；只绘制已有且定义清楚的物理量，曲线有单位、采样范围与暂停状态 |
| 4 | 局部轨道与相对参考系 | 星—行星—卫星层级、合适单位与近距步长先完成，再开放共转视角和环粒子扰动 |
| 5 | 完整检查点与 SPH 可观察性 | 验证保存后续算；接通压力／内能／损伤，之后推进自引力和碎片重聚 |

可以新增的实验题目包括：“复制一颗行星，只改速度会怎样”“在旋转视角里追踪特洛伊轨道”“一颗卫星如何扰动环带”“撞击后哪些物质还留在轨道上”。它们分别依赖上表能力，不能只用预设名称或动画宣称已具备对应物理。

这轮最值得吸收的共同点是：每增加一种现象，同时提供参数说明、观察工具、保存方式和失败反馈。继续沿用 ArkUI 与 CLI 共用动作；本轮仅更新资料，不调整 0.17.0 版本或重新打包。
