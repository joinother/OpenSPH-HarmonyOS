# 国产替代、国内资源分发与后续运营预研

> 类型：预研快照；调研日期：2026-09-07（Asia/Shanghai）；应用基线：0.24.0，提交 c7a6d56f5ce54618ed3c1e9748687cad60b7487b。没有部署云服务、切换供应商、改动模拟器或重新发布安装包。

## 结论与采用顺序

建议先保留可独立使用的离线基础包，建立来源与服务台账；然后准备国内构建缓存和 Git 备份；需要大资源包时再验证境内对象存储与 CDN。国产天文数据按具体产品逐件替换，账号、云存档、收费和工坊按实际产品需要接入。

“国产化”拆成四项验收：内容的原始生产者、实际托管与数据处理地域、软件／SDK 的供应来源、运营主体与用户服务。国内 CDN 上的 NASA 图仍是 NASA 来源；华为品牌服务也需核对具体产品和处理区域；国内 Git 镜像中的 OpenSPH 仍是海外开源引擎。不能把更换域名视为四项全部完成。

当前月面与银河原始图片合计 5315426 字节，均随包读取；项目没有在线资源更新器、第三方插件加载器、账号、支付、广告、云模拟或地图 SDK。当前一方代码抽查和构建依赖见 [服务台账](../reference/SERVICE-INVENTORY.md) 与 [扫描及哈希证据](../evidence/localization-inventory-2026-09-07.json)。这里的“无网络调用命中”有明确扫描范围，未进行抓包，也未把系统 SDK 全部逐行审计。

## 插件与资源包的分发边界

目前没有第三方插件宿主。以后建议建立三类扩展，不能把所有扩展都称为“皮肤”。

| 类型 | 例子 | 分发与验证 |
| --- | --- | --- |
| 声明式数据包 | 初态 JSON、图片、导览步骤、经审核音频 | 本地文件导入优先；将来国内静态分发；限定 schema、解码器、尺寸、展开体积与依赖 |
| 应用功能模块 | 新求解器、导入器、可执行脚本宿主、渲染实现 | 随签名应用更新或使用官方增强模块分发；API/ABI 和商店规则分别验证 |
| 网络服务连接器 | 云模拟、账号同步、查询 API | 独立登记发送字段、认证、计费、超时、地区和退出方式，不能伪装成静态包 |

华为官方“产品特性按需分发”允许把应用拆为基础包和增强模块，支持 Phone、Tablet、PC/2in1，并有模拟器调试能力；正式能力要求应用上架市场。不能由此推断可从任意第三方 ZIP 执行代码，也不能因术语相似就把官方模块机制一律描述为不允许的热更新。[官方按需分发指南](https://developer.huawei.com/consumer/cn/doc/harmonyos-guides/store-moduleinstall_arkts)

第一版内容包拟只接受白名单 JSON 与图片，不开放任意 `.so`、`.abc`、JS 或外来 shader。后续若需要脚本，应作为单独执行模型设计；先明确权限、资源额度、可复现性和更新路径。数据包也需防目录穿越、符号链接、压缩炸弹、超大图像、非法浮点和超出求解器预算的粒子数。

拟定资源清单字段：`schemaVersion`、`sourceId`、`assetVersion`、`packageId`、`minAppVersion`、`contentType`、`bytes`、`decodedBytes`、`sha256`、`license`、`attribution`、`upstreamReference`、`retrievedAt`、`redistributionScope`、`coordinateFrame`、`colorSpace`、`dependencies`、`revocationId`。签名采用独立、受信任的发布密钥；从同一可篡改站点一起下载哈希和文件不足以证明来源可信。此为待实现契约，现有应用还不解析这些扩展字段。

## 更新、回退与运营日常

拟采用的发布路径为：上游或国内合作文件进入构建机暂存区 → 授权登记 → 格式／尺寸／哈希／视觉检查 → 固定版本资源目录 → 签名清单 → 国内对象存储和可选 CDN → 应用显式下载，或随下一次签名 HAP 发布。

纯离线发布时只走构建机与 HAP，客户端不新增公网请求。内置资源是稳定基线；镜像下载失败保留上一版，不在客户端静默回退到海外源。首次安装不能因资源站停机失去基础实验能力。

更新采用不可变版本路径，下载到临时文件、校验完成后原子切换；支持取消、失败重试上限、旧包回滚和损坏缓存清理。原始来源 URL 与交付 URL 分开存储，内容身份不跟随供应商改变。跨云替换先复制同一签名版本并核对哈希，再切流量；国内版本的跨境回退必须另行决定，不能靠 DNS 自动发生。

| 运营事项 | 建议频率／触发条件 | 负责角色与可检查输出 |
| --- | --- | --- |
| 资源许可与署名 | 每个新来源、每次许可变更 | 内容负责人：权利记录与随包通知 |
| 构建输入与版本 | 每次发布 | 研发：工具版本、依赖锁、资源清单、来源哈希、可恢复快照 |
| 资源健康与错误 | 部署在线资源后监测；异常时处理 | 运维：下载成功率、哈希失败、超时、回源率；不采集无关个人字段 |
| 支出 | 开通后按账期核对、设置预算分级告警 | 运营：存储／下行／回源／请求／日志各项账单 |
| 备份与退出演练 | 上线前一次，建议每季度复核 | 运维：独立备份恢复、DNS/证书权限、另一个源的相同哈希验证 |
| 资源撤回 | 授权撤销、恶意文件、严重错误 | 内容与研发：撤回清单、阻止新下载、旧包处置说明和可用回退 |
| 科学数据时效 | 按数据类型更新 | 科学审核：历元、更新时间、过期标签；月面图片不伪称实时观测 |
| 用户反馈与本地化 | 每次功能发布 | 产品：术语一致、横竖屏长文本、字体缩放、中文日期单位与无障碍检查 |

以上是运营职责建议，不是已创建的监控或定时任务。没有运行中服务的现阶段，不为未来需求先安装全部 SDK。

## 费用模型与供应商退出

当前包内资源的客户端请求不会产生本项目自建 CDN 流量费；商店分发、构建机、托管和人员成本仍单独核算。不要把 0.24.0 约 16.96 MB 的 HAP 和未来可选资源包重复算进同一 CDN 账单。

以下仅作容量情景测算，不是用户预测、供应商报价或性能实测。每月下载量 = 用户量 × 选择下载的比例 × 每人本月资源大小 × 1.10（假设重试／重复下载增量）。一次更新、资源大小使用 MiB：

| 情景 | 用户量 | 下载比例 | 单人资源 | 月下行估算 |
| --- | --- | --- | --- | --- |
| 小规模试运营 | 10000 | 25% | 32 MiB | 85.94 GiB |
| 扩展资源上线 | 100000 | 40% | 64 MiB | 2750 GiB |
| 大范围资源分发 | 1000000 | 50% | 128 MiB | 68750 GiB |

换成厂商计费单位后，月费用模型为：存储量×存储价 + CDN 下行量×阶梯单价 + 实际回源量×回源价 + 请求数×请求价 + 备份、证书、日志、函数/数据库及固定运营成本。回源量受命中率、缓存规则与地域影响，不能直接等于下行量；免费额度和临时优惠不作为长期预算前提。

采购比较表至少记录：中国大陆地域、合同主体、传输与存储位置、数据处理例外、带宽与请求计费、欠费行为、下载 Range / ETag、缓存失效、证书续期、日志保留、跨区域复制、接口兼容、全量导出和关闭服务后的数据删除。选择前在真实国内网络做样本下载，记录时间段／运营商／地区和错误率；本轮未做这些测量。

资源以标准文件与独立清单存储，避免只在厂商专用数据库里保存唯一副本。账号标识与内容 ID 解耦，付费订单和权益状态可导出；不向客户端发长期存储密钥。停止云服务时，已安装的离线基础实验继续可用。

## 备案、数据处理与商业化分期

APP 备案、网站／域名备案、应用商店审核、数字商品支付和可能适用的内容资质是不同环节。工信部通知针对在境内从事互联网信息服务的 APP；华为指引要求 HarmonyOS 备案材料选择对应平台与包名。当前离线或未声明 INTERNET 都不能单独证明未来产品无需备案；正式运营须按最终功能和商店要求核实。[工信部通知](https://www.miit.gov.cn/zwgk/zcwj/wjfb/tz/art/2023/art_920db564162e4312916a01bed6540ad8.html)、[华为 APP 备案指引](https://developer.huawei.com/consumer/cn/doc/app/50130)

AGC 数据处理附录将处理位置与所选业务区域关联，并明确存在另行规定的例外；不能只因厂商品牌是国内就承诺所有请求和数据都在境内。后续逐服务核实配置、协议、转委托与实际端点，尤其是账号、崩溃日志、推送和云存档。[AGC 数据处理附录](https://developer.huawei.com/consumer/cn/doc/app/20215)

如以后销售数字权益，IAP Kit 提供购买、发货确认、订阅与退款能力，也要求注意用户账号地区支持情况。权益校验、退款回收、重复回调和离线权益仍由应用业务设计；本次不假设已开通支付或已确定定价。[IAP 官方文档](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/iap-iap)

建议分三期运营：基础离线实验先形成正式签名与可支持版本；可选资源和增强功能完成授权与分发验证后再上线；工坊、云存档或收费服务有明确用户价值与维护预算后再开。工具／科普／游戏等分类按最终功能和分发平台判断，不提前用某种分类规避对应要求。
