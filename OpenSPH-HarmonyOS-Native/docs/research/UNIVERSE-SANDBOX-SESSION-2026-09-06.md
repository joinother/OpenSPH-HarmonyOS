# Universe Sandbox 首次操作记录

> 类型：体验记录；观察日期：2026-09-06（Asia/Shanghai）；本项目基线：0.17.0。只记录本轮实际可见结果，不作为竞品功能完整审计。

## 已观察与操作

用户通过 Steam 启动后，Universe Sandbox 已进入太阳系场景，之前的“需要 Steam”对话框不再出现。此前读取的安装元数据为 36.3.1；本轮未重新核验安装版本。

- 画面以宇宙视口为主体，底部集中放置暂停、日期、时间速率、添加、查找和模型／视图／工具入口。
- 按空格后，暂停图标变为播放图标，出现暂停提示；后续观察日期保持在 2033-01-06 05:24 pm。这是实验时间，不是本轮操作日期。
- 按 Escape 后看到左侧主菜单，包括新建、打开、指南、创意工坊和设置等入口；背景仍保留太阳系画面。菜单关闭后仍显示同一暂停场景。
- 试用 F11 切换窗口模式，结束时再次切回全屏模式，保留暂停的太阳系。未保存、覆盖或发布游戏实验。

## 自动化限制

全屏下鼠标工具反复报告 `noWindowsAvailable`，但截图和键盘操作可用。切换窗口模式后点击调用能够返回，然而点击添加和主菜单入口后只观察到界面隐藏，未成功打开预期面板。可访问性树也没有暴露游戏内按钮，无法按语义控件操作。

因此本轮没有完成放置行星、参数编辑、加载碰撞预设或土星环操作。不能把界面上存在入口写成已验证该功能，更不能据此推断其内部物理或渲染实现。后续体验需先解决鼠标输入与窗口识别的问题。
