# SpaceEngine 调研与实施取舍

> 类型：调研快照；首次调研：2026-09-06；补充调研：2026-09-07（Asia/Shanghai）；当前对照源码：0.20.0。保留首次日期文件名，更新既有主题，避免重复建立入口。本轮为公开手册与 Workshop 选读，未安装或操作 SpaceEngine，未下载作品、检查 shader 或进行性能测试。以下建议均不代表新功能已经实现。

## 结论与阅读范围

SpaceEngine 最值得借鉴的是连续观察、行星外观和内容组织。当前工程继续使用 ArkTS/ArkUI 管理交互、原生 C++ 管理数值与渲染；参考公开行为并独立设计，无需把闭源引擎或其桌面插件搬进鸿蒙。

本轮取得 9 个官方页面，重点阅读导航、图形设置、镜头脚本、行星与纹理配置、外观预设、扩展规则；长篇配置文档按相关章节选读。另浏览 Workshop 首页、选读 6 份作品说明及部分当页评论。未遍历全部工坊、评论或版本变更。来源、阅读范围和失败页面见 [检索记录](../evidence/spaceengine-manual-workshop-index-2026-09-07.json)。

用户提供的 [User manual](https://spaceengine.org/manual/user-manual/) 当前正文主要是图形设置；基础导航另见官方 [0.980 旧版手册](https://spaceengine.org/manual/user-manual-0980/)。脚本、行星配置页也混有旧版本说明，因此只用来提炼设计，不把快捷键、参数范围、桌面显存要求或旧缺陷当成当前版本及鸿蒙的事实。

## 对照 0.20.0 后的十二项改进

| 编号／阶段 | 独立实现提案 | 当前基础与验收条件 |
| --- | --- | --- |
| SE01／近期 | 选中、飞近、跟随中心、跟随表面、朝向跟踪分开建模 | 已有同视口选择／近看；补明确的绑定状态。切换目标、开关编辑和返回全景不重置物理时间；目标删除后有明确退出行为 |
| SE02／近期 | 可取消且可等待的镜头动作，镜头时钟独立 | 物理暂停时仍能飞近；手势取消保留当前姿态；连续请求只允许有效的最后动作更新镜头。CLI 收到完成／取消／失败，不以固定延时判成功 |
| SE03／近期 | 保存完整外观配方、种子和默认基底版本 | 九个主题和程序外观已有基础；局部环时钟／发射参数目前未保存。扩充保存结构并验证往返一致；调颜色、云层开关不改变质量、速度和求解状态 |
| SE04／近期 | 自然曝光与摄影曝光，分别调行星与远景可见度 | 已有 ESO 摄影全景。验证昼面／夜面切换，曝光平滑且不闪；摄影模式明确为展示设定，不能恒亮银河掩盖场景光照关系 |
| SE05／近期 | 云、海洋、大气、环四组外观控件及球面预览 | 已有程序效果与薄环；补分层草稿和恢复默认。检查云层遮挡、明暗交界线、顺逆光和环阴影；不宣称气候或海洋物理 |
| SE06／随后 | 保存观察地点和可恢复的镜头路径 | 默认只恢复视点，另有明确恢复实验操作；地点存参考对象、局部姿态、视场角和适用版本。路径从当前镜头平滑接入，不能跳到第一个航点 |
| SE07／随后 | 搜索结果与天体层级面包屑 | 在活动场景中逐步接入，先不伪造“全宇宙星表”。结果选中不自动切换实验，沿父子层级导航保留镜头与草稿；同名对象不串选 |
| SE08／随后 | 分帧资源加载与画质预算 | 设置目标分辨率上限；分辨率、缓存和生成预算按设备测量。折叠／旋转不销毁实验；低清资源可用时保留画面，过期加载结果不能覆盖新目标 |
| SE09／随后 | 原创配色与材质系列 | 冰裂纹、荒漠、海洋云带、气态条纹分成可组合组件；缩略图由同一配方生成。检查远看／近看、极区、接缝和多级纹理，避免只在平面预览好看 |
| SE10／随后 | 显式资源依赖和兼容性信息 | 保存稳定 ID、父对象、资源版本、许可署名和是否影响地点；不以文件修改时间决定覆盖顺序。缺失依赖给出诊断；存档升级需要迁移与旧样本测试 |
| SE11／后期 | 三维银河／星云与摄影背景分阶段 | 当前只有方向映射的全景，没有立体银河。先解决曝光与背景一致性，后做局部体积原型和移动／静止画质预算；天体目录单独建设 |
| SE12／后期 | 海面近景、体积环与时间降噪 | 当前无地表漫游或体积环。进入该阶段前先测内存、帧时间与发热；验收海岸交界、自动飞行、窗口重建、目标切换和 HUD 拖影 |

所有交互沿用 [开发约定](../../AGENTS.md)：ArkUI 和 CLI 共用语义动作。新增镜头动作应返回请求身份与状态，位置和资源状态能查询；这仅为接口需求，尚未新增 CLI 命令。CLI 验证状态连续性，截图验证外观，真实手势与设备测试验证命中、动画和旋转／折叠表现，三者不能互相冒充。

## 六个原创体验提案

| 体验 | 用户做什么、看什么 | 依赖与边界 |
| --- | --- | --- |
| 环影日落 | 从顺光面连续绕到背光面，调整观察角度看环带与行星阴影变化 | 现有薄环可作基础，先用明确光源方向与环面关系验证；体积环穿越另立阶段 |
| 同一颗星的六种面孔 | 保持轨道与质量，用冰裂纹、荒漠、蔚蓝、厚云、条纹和带环外观作对照 | 需原创组件与配方保存，不将换皮解释为星球演化 |
| 云在走，地表也在转 | 在固定表面视点与跟随中心之间切换，观察相对云速 | 需表面绑定和独立云层运动；属于运动学与视觉演示 |
| 从日面找到银河 | 围绕同一行星观察昼夜，比较自然曝光与摄影曝光 | 需曝光控制；背景全景保持其方向映射边界，不标注未经核验的真实星体位置 |
| 从全景到环，再回到书签 | 一条短导览串联飞近、绕行、暂停、取消和返回；展开折叠屏后继续 | 需 SE01、SE02、SE06；中途操作不重启求解、不闪黑、不丢草稿 |
| 给环一点额外速度：带着镜头看结果 | 在已有圆／椭圆示踪环上增加导览，读近远点并对比外观环 | 数值基线已有，需完整配方和导览。仍是无质量示踪点，不宣称环碰撞、卫星捕获或月球形成 |

这些提案使用我们自己的参数与资源。带巨大环的社区题材可作为创作启发，但不能把候选观测解释直接作为确定的真实系统。

## 实施顺序与物理路线

先合并前几轮共同需求：完整实验配方与保存、可编排镜头、外观组件，再做导览预设和画质预算。SE01–SE05 是近期拆分任务，不能将十二项同时开工或把未完成项计为版本能力。

0.18.0 已实现三维薄环外观；0.19.0–0.20.0 已实现局部圆／椭圆示踪环。因此首次调研中的“先建外观环、再建局部环”已完成基础阶段，后续分别进入视觉改进与可验证扰动物理。见 [当前概览](../../README.md) 和 [0.20.0 记录](../releases/RELEASE-0.20.0.md)。

SPH 目前没有启用自引力；点质量行星模型近距离停止，没有行星合并／破碎或与 SPH 联动。碰撞、自引力、完整物理检查点继续按 [博客论坛路线](UNIVERSE-SANDBOX-BLOG-FORUM-2026-09-07.md) 与 [Steam 补充](UNIVERSE-SANDBOX-STEAM-2026-09-07.md) 的依赖推进。SpaceEngine 视觉文档不足以充当月球形成或行星撞击的数值依据。
