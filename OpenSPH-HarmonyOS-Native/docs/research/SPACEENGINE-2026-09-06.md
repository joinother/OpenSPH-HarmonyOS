# SpaceEngine 调研与实施取舍

> 类型：调研快照；调研日期：2026-09-06（Asia/Shanghai）；项目基线：0.17.0。本轮查阅公开网页，未安装 SpaceEngine、未检查其程序代码、未完成实机体验。以下待办不代表已实现功能。

## 结论与许可边界

SpaceEngine 适合作为宇宙漫游和行星视觉的参考。官方 [FAQ](https://spaceengine.org/manual/faq/) 明确说明产品闭源，没有公开引擎 SDK；不能把下载程序理解为取得源码。这里讨论的是 Cosmographic Software 的 SpaceEngine，不是 Space Engineers。

[标准许可](https://store.steampowered.com/eula/314650_eula_0) 限制反汇编、反编译和逆向，同时保留法律明确允许的例外；“学习用途”本身不是额外授权。标准版使用和输出的授权也有非商业限制。当前路线采用公开文档研究与独立实现，不以拆解程序为前提；若后续涉及商业评估或特殊复用，应核对适用许可或取得明确授权。

[PRO 许可](https://store.steampowered.com/eula/1026970_eula_0)（页面版本 1.8.1，2024-03）允许一定范围的商业输出、导出纹理／模型使用及配置和数据修改，并有署名等条件。这不等于授权移植引擎、复制内置 shader，或将其素材按我们项目的开源许可重新授权。[Workshop 规则](https://spaceengine.org/steam-workshop-guidelines/)同样要求作者权利与复用授权；社区下载不等于自由素材库。

公开的 [插件文档](https://spaceengine.org/manual/making-addons/introduction/) 可用于理解扩展方式。文档介绍的配置格式、随软件可读的文件和采用开源许可的代码是不同层次，逐项看授权。本项目不引入其示例代码、纹理、音乐或安装包中的资源。

## 与当前路线衔接

1. **先做土星风格外观。** 延续 0.17.0 主题实验路线，增加可倾斜的环带、遮挡和光照。先解决视觉问题，不能将装饰环描述成数值环系统。
2. **再做可编排的连续观察。** 明确“选中对象”和“跟随对象”的区别；加入镜头过渡状态、取消与完成反馈，让主题导览和 CLI 使用同一套能力。镜头运行使用自己的时间，不因物理暂停而卡住。
3. **建立局部环实验。** 先补以行星为中心、单位明确的近距轨道模型与无质量试验粒子；必须先修正当前恒星系统的距离约束，不能直接把现有模型缩放成土星环。再设计卫星扰动等可验证实验。
4. **继续碰撞求解。** 压力、内能、损伤、自引力和检查点按既有路线推进。官网描述了行星馆、轨道与飞船物理，但这不足以证明它具备我们需要的行星撞击／月球形成求解；渲染效果不能作为碰撞物理验收依据。

远期宇宙规模采用层级目录和按需加载；只有进入活动实验的局部天体参与昂贵求解。这是本项目的架构建议，不是对 SpaceEngine 内部机制的断言。手机／平板／电脑共享 ArkTS 交互与状态接口，渲染和数值热点继续采用原生 C++，并根据设备预算调节细节。

## 是否下载安装

当前 [官方 Steam 页面](https://store.steampowered.com/app/314650/SpaceEngine/)只列 Windows 系统要求，没有列 macOS 原生版本。现阶段在这台 Mac 上为调研搭建兼容环境收益有限，先用官方手册和演示推进设计，无需为读文档购买 PRO。

后续若有符合授权及配置要求的 Windows 环境，实际体验有价值：依次观察远近飞行、跟随与自转绑定、环的正背面、曝光切换和地点恢复。记录操作与结果，不提取代码或私有资产。下载安装到本地也不会使闭源引擎变成可移植源码。
