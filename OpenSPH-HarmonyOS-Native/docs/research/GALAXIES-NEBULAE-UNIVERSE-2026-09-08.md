# 星系、星云与宇宙尺度模拟路线

> 类型：专题预研；调研日期：2026-09-08（Asia/Shanghai）；应用基线：0.42.0。本文是设计与源码选读记录，未接入新求解器、未执行星系／气体数值实验，也没有发布新应用版本。

## 结论与旧预研的补充

项目可以逐步加入星系相遇、气体云碰撞和宇宙漫游，但要分别建设物理模型和显示层。当前球体接触不能直接放大成为星系碰撞；摄影银河也不能通过增加亮点变成可进入的三维星系。

此前 [全宇宙架构](archive/UNIVERSE-ARCHITECTURE-2026-09-06.md)、[Celestia 专题](CELESTIA-SOURCE-ADDONS-2026-09-07.md) 和 [SpaceEngine 专题](SPACEENGINE-2026-09-06.md) 已提出层级坐标、三维深空对象和局部高精度实验，尚未展开星系动力学的初值、模型边界与验收。本次补齐这部分；历史文件保留原版本判断，当前顺序统一见 [实施核对](../reference/RESEARCH-IMPLEMENTATION.md)。

星系相遇主要表现为整体引力作用下的变形、潮汐尾和物质转移；星系中的恒星通常不会像实体球那样逐一撞击，气体则可能被压缩。这是区分无碰撞引力模型与气体流体模型的依据。[NASA 星系演化](https://science.nasa.gov/universe/galaxies/evolution/)

| 用户想玩的内容 | 需要的模型 | 当前缺口 |
| --- | --- | --- |
| 飞出太阳系、进入银河与星云 | 层级坐标、星表／深空目录、三维体积、按视角加载 | 当前仍是局部实验与摄影背景，没有宇宙对象层级 |
| 两个星系擦过、拉出长尾 | 扩展引力势与无碰撞示踪粒子；之后升级带质量的自洽引力 | 现有 2–8 天体行星接口不能承担星系模型 |
| 星系长期合并、暗晕与恒星盘共同变化 | 恒星盘／核球／暗晕的带质量采样、稳定初态、树形引力 | 尚无星系初值、长期稳定性或树形引力应用验收 |
| 两团星际气体相撞、压缩、激波 | 气体状态方程、流体方程、热能；按目标增加冷却、自引力等 | 当前玄武岩材料及损伤诊断不能直接套用 |
| 宇宙网、结构形成 | 有限宇宙学计算盒、膨胀背景、初始扰动与边界条件 | 适合先用离线科学数据回放，未实现宇宙学演算 |

## 分阶段实施与验收门槛

下面全部是待实施方案。阶段名称不属于当前可调用的 CLI，实验编号也不表示已上架预设。

### G0：共享坐标与模型身份

建立“目录对象—星系局部系—行星系统—碰撞局部系”的层级身份。保存稳定对象 ID、父参考系、局部原点、单位、时刻、模型版本与数据来源。相机切换参考系时先算高精度差值，再把局部相对坐标交给 GPU；不能把全宇宙坐标塞入单精度位置。

目录浏览与活动物理场景分别管理。观测目录、程序生成对象、用户实验分别标注；程序生成的无数星体不意味着同时求解它们的相互引力。进入目标只调整视角和资源层级，不重建已有实验。一个画面可承载不同时间尺度，但必须显示当前实验时钟，不能让百万年星系步长推进秒级岩体计算。

验收：跨参考系往返误差、远处位置下近距离分辨率、单位换算、选择 ID 保持、取消旧加载、旧回放兼容。先完成必要接口，不等待完整宇宙目录才开始 G1。

### G1：首个可玩的星系潮汐相遇

建议模型身份 `galaxy-tidal-restricted-v1`：两组扩展解析引力势，加无质量恒星盘示踪粒子。初版选择参数明确的平滑势，例如 Plummer 势作为教学近似；它不等于真实星系的完整盘／晕分布。中心轨迹与相互作用规则必须明确记录，不能暗中用动画移动中心，也不能凭渲染点数量改变引力质量。

独立采用 kpc、Myr、太阳质量的单位体系，计算引力常数的单位转换；不复用当前 AU／儒略年轨道输入范围。先做单星系静态势中的稳定圆轨道，再加入另一个势的飞掠。试验规模从数百至数千示踪粒子逐档测量，没有手机帧率承诺。

验收包括固定种子重现、静态势轨道误差、步长减半对照、无扰动控制组、改变自转方向后的对照，以及暂停、取消、存档、回放与 CLI。时变势中的示踪粒子会与外场交换能量，不能把它们当封闭系统要求总能量恒定；分别检查静态势基线与时变势做功。示踪粒子没有反作用，首版只承诺潮汐形态实验，不能宣称已算出完整合并和动力摩擦。

### G2：自洽恒星盘与暗晕

将恒星盘、核球和暗晕表示为带质量的采样粒子，用实际相互引力演化；先评估已导入的 BarnesHut。每个粒子代表一群恒星或一份暗物质质量，而非一颗可撞击的实体球。显示尺寸与引力软化长度分开；暗晕不能自动画成发光恒星。

通过孤立星系稳定性后才开放两星系相遇。验收直接求和对照、开角／步长／软化／粒子数变化、质心与角动量、能量漂移、盘厚度和质量分布随时间的变化。检查低粒子数造成的非物理松弛；不能以星盘看起来漂亮替代稳定性验证。长期合并和动力摩擦的可信度在这一阶段评估。

[JSPAM 论文摘要](https://arxiv.org/abs/1511.05041) 描述用于交互星系的限制性模型，并讨论势与动力摩擦近似；其 [仓库 README](https://github.com/jfwallin/JSPAM) 提供多语言实现线索。适合 G1 的方法参考，不能代替 G2 的自洽求解。论文／README 标示 AFL 3.0，若抽取实现或数据，仍须逐项核对对应版本和署名要求。本次 GitHub API 返回 404，未取得固定源码树。

### N1：星云可进入，气体可计算

先把星云视觉与气体演化分成两个能力。三维发射／吸收体积可提供穿行、遮挡与视差；程序化密度只用于显示时必须标明。之后新增理想气体实验路径，维护密度、压力、速度、比内能等字段，以物理结果驱动体积或粒子显示。

第一组物理门槛为激波管（Sod）、强爆炸波（Sedov）及自引力不稳定性（Jeans）对照，分别验证不连续流动、冲击传播、压力与引力竞争。需预先固定边界、初态、解析／独立参照、误差指标与收敛判定，不把运行结束当作通过。

气体云相撞先限定为无磁、绝热模型，再按具体目标增加冷却、化学、磁场和辐射。没有这些模块时，不自动宣称真实恒星形成、星云颜色或反馈。气体温度换算必须明确组成与平均分子量；单位与岩体分开保存。

[GIZMO 作者官网](https://www.tapir.caltech.edu/~phopkins/Site/GIZMO.html) 和 [官方文档](https://www.tapir.caltech.edu/~phopkins/Site/GIZMO_files/gizmo_documentation.html) 可作为气体数值方法和模块选型线索；公开核心与其他开发模块范围不同。本次仅阅读检索返回内容，尚未确认适合鸿蒙的依赖组合，不建议现在整库替换 OpenSPH。

### U1：有限宇宙学场景与科学数据回放

“整个宇宙”在产品上可表现为连续浏览、按需生成和局部实验。在科学演算上应使用明确大小、分辨率与边界的有限计算盒，定义膨胀因子、宇宙学参数、初始扰动以及共动／物理坐标转换。观测光锥与同一宇宙时刻的模拟快照不是同一种数据，界面与导出必须区分。

[GADGET-4 手册](https://wwwmpa.mpa-garching.mpg.de/gadget4/01_index/) 提供无碰撞引力、SPH、宇宙学积分及初值相关能力，并要求按目标进行收敛研究。基于其并行依赖和项目当前范围，本方案优先将它作为桌面基准和离线数据来源候选，先评估分块回放，再考虑可选计算后端；没有移植、构建或运行该软件。数据的分发许可需单独确认，代码公开不代表任意模拟数据可再分发。

## 六个有明确玩法的实验提案

| 提案 | 玩家操作与观察 | 依赖及诚实边界 |
| --- | --- | --- |
| 两条潮汐尾 | 在主视口放置第二个盘，改变接近方向、倾角和速度，观察长尾与物质桥 | G1；是限制性形态实验，尚非完整合并 |
| 顺行还是逆行 | 保持质量、轨迹和随机种子，只反转一侧盘的旋转方向，并列对照 | G1；记录同一条件，避免颜色差异冒充物理差异 |
| 小星系的长溪流 | 改质量比与掠过距离，追踪被剥离的示踪粒子 | G1 可初步观察；长期吸积／合并需 G2 |
| 两团云迎面与擦肩 | 相同气体初态下比较正撞、斜撞的压缩和热能 | N1 气体求解；未加入冷却时不显示“新恒星形成”结论 |
| 走进暗尘带 | 从远处星云连续飞入，比较发射、吸收与背景遮挡 | N1 视觉能力；可先做，不能当作气体动力学结果 |
| 宇宙网的一小块 | 回看有限计算盒中结构成长，点选一个结构进入独立局部实验 | U1；回放与新建实验明确区分，不声称从显示快照精确续算 |

放置星系复用现有“预览—调整—确认／取消”的操作思路，但预览范围改为扩展盘／云体积，并提供倾角、自转与接近速度。UI 与语义 CLI 共用动作，CLI 同步查询模型、草稿和计算阶段。只有实现相应模型后才把动作加入当前命令目录。编辑初值与从当前时刻继续演算须分开；现有可视化回放不足以恢复完整求解器状态。

## 手机、平板与电脑的预算

求解粒子数、可见粒子数、历史帧数和体积纹理预算独立控制。降低显示质量不能改变引力质量或初始条件；允许相同配方选择计算精度，但将参数写入结果。先离线可用，再按实测能力分档，不把云服务设为使用基础实验的前提。

仅作容量估算：假定每粒子每帧记录 24 字节，4096 粒子 × 240 帧需要 22.5 MiB，10 万粒子 × 240 帧约需 549.32 MiB；128³ 单元 × 4 个单精度标量需要 32 MiB。这些还不含求解数组、速度、树、身份、纹理缓存与双缓冲，不是设备峰值内存实测。因此不能沿用当前 240 帧的全量复制策略无限扩容。需评估分块历史、采样显示与完整检查点各自的用途。

## 项目中的执行顺序

当前行星碰撞主线继续推进轨道到局部 SPH 的事件转换、质量／动量映射和材料身份，以及岩体平衡与收敛；星系任务不替代这些缺口。

下一项星系工作限定为 G0 必要接口加 G1 单星系圆轨道最小驱动，形成独立测试后做双星系潮汐尾，不一次引入完整宇宙引擎。G2、N1 气体和 U1 在各自门槛通过后扩展。视觉星云可独立开发，但不得以视觉版本宣布物理阶段完成。
