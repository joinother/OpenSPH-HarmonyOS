# 主题实验、行星外观与碰撞创意

> 类型：调研与设计；调研日期：2026-09-06（Asia/Shanghai）；对照源码：0.15.0。
> 状态：候选设计，尚未实现。本文不代表土星环、行星吞没或月球形成已在应用中可运行。

## 结论

当前六个入口主要按求解器类型组织，缺少主题外观、值得观察的事件和便于反复尝试的变量。应把实验库改成“主题场景＋观察目标＋少量玩法参数”，底层预设继续作为高级编辑入口。

优先顺序调整为：主题实验库和外观基础 → 环世界与岩质撞击对照 → 环的扰动／近距离坠入 → 自引力碎片再聚集 → 月球形成假说。草稿持久化继续属于基础工作，不必等所有基础设施完成才提供有趣的内容。

## 推荐的八个主题

以下名称、玩法与实施排序是本项目的设计建议，不是对同行预设列表的复制。

| 主题 | 用户能做什么、看什么 | 外观方向 | 当前缺口与次序 |
| --- | --- | --- | --- |
| 环世界·土星风格 | 转过环平面，观察前后遮挡、环隙、受光面；调倾角与环宽 | 淡金条纹气态巨行星、薄冰环、环影 | 优先做外观与浏览；环粒子动力学另行接入，外观版不宣称环会碰撞 |
| 碎岩风暴 | 同一组岩质天体，比较低速与高速相撞；看喷射方向、分散程度 | 暗色岩面、断裂截面、来源色／速度色可切换 | 现有 SPH 可作为基础；先补表面表达和对照预设，不能预先保证碎片最终数量 |
| 擦肩而过还是相撞 | 改横向偏移与速度，比较正撞、斜撞和掠过 | 两种可区分的岩质表面、接近路径和冲击局部特写 | 当前初始化偏移范围有限，真正“完全错过”需扩展初始位置；不能仅把 angle 参数叫作物理撞击角 |
| 坠向恒星 | 降低切向速度，比较近掠、逃逸与坠入；看近星点速度变化 | 恒星光球、行星昼夜面；热效应有模型后再显示 | 当前只适合演示接近阶段；实际接触／吸收、质量与动量预算、近距步长需要新增 |
| 撕裂一条行星环 | 让一颗较重卫星从环附近经过，看扰动和缺口 | 冰粒密度纹理、被扰动的波纹与弧段 | 需要以行星为中心的局部尺度、测试粒子与扰动模型；固定环贴图不能实现 |
| 卫星相撞，环会诞生吗 | 调两颗冰卫星相对速度、相位，追踪留轨道、逃逸和回落物质 | 冰岩来源色、碰撞后的稀薄碎片带 | 需要外部行星引力、冰／岩材料、碎片轨道与耗散；参考 NASA 的起源假说 |
| 月球诞生·巨大撞击假说 | 改撞击体质量比、速度与自转，比较环状物质和轨道卫星候选 | 分层原始地球、撞击体来源标记、熔融区域 | 需要自引力、分层天体平衡、适用状态方程、角动量与碎片判定；作为重点后续实验 |
| 碎片重新聚成小行星 | 给碎片不同速度，观察逃逸与重新聚集 | 不规则碎岩、最终聚集体来源分布 | 是进入月球形成前更合适的自引力验证与玩法；需碰撞／耗散和束缚结构识别 |

备用创意包括共振轨道、特洛伊伴星、双星落日、行星被引力弹弓甩出。它们适合填充安静的探索类内容，但双星与卫星系统也需要先解除当前“第 0 颗固定为恒星”的数据模型限制。

## 外观应该怎样补

行星应保存独立的质量／半径／组成与外观设置。海洋世界、灰色撞击坑卫星、冰卫星、条纹气态巨行星、熔融岩质天体是建议补齐的对象模板；外观不再只用三个数字隐式决定一切。

土星风格先实现三维薄环、径向明暗与环隙、透明度、球体遮挡和环影。先生成自己的材质与纹理；若采用外部摄影或地图，逐项记录来源。环的朝向必须与天体参考系一致，不能是贴在屏幕上的椭圆。

SPH 天体不能简单套一个完整球壳：碎裂后球壳仍完整会破坏表现。短期可让初始表面颜色随粒子移动，以平滑粒子表面呈现形变；后续再评估表面重建。压力、内能、损伤接出并验证前，不把速度着色称为温度，不以随机红光表示物理熔融。

## 预设库与操作设计

每张卡片只突出一幅代表画面、一句问题和一个主按钮。进入后先给用户看完整场景，在浮动说明中提示“观察什么”，参数折叠到侧栏。建议分为碰撞、环与卫星、轨道探索三个主题，而非 SPH／N-body 技术分类。

每个预设保存主题 ID、初始条件、外观、随机种子、默认镜头、模型说明和可调变量。先提供速度、偏移／接近距离、质量比这类少量有意义的控制；“恢复预设”和“另存变体”复用现有 CLI 动作体系。

时间轴上的接触、最近接近、最大压缩等标记应来自实际结果。进入时展示接近阶段，回放时可直接跳到关键事件；不在不知道计算结果时硬编码“月球形成”时刻。计算较慢的手机可使用明确标记的预计算演示；修改参数后进入重新计算，不能把旧录像继续冒充当前参数的结果。

## 必须先改的模型问题

对照 [SceneModel.ets](../../entry/src/main/ets/common/SceneModel.ets)、[orbit.cpp](../../entry/src/main/cpp/orbit.cpp)、[engine.cpp](../../entry/src/main/cpp/engine.cpp) 与 [上游审计](../reference/UPSTREAM-AUDIT.md)：

- 当前轨道初始间距至少 0.05 AU，运行中小于 0.02 AU 停止。这些保护阈值不能直接用于行星环和近距离卫星；需要局部单位、步长与遭遇处理一起改。
- 第 0 颗天体固定为恒星质量范围与恒星外观，天体上限为 8。真实土星中心的环系统需要新的对象类型与粒子群表示，不能伪造一个恒星质量的土星。
- SPH 当前是百公里级岩质模型，未启用自引力。把半径和质量整体放大不保证成为合理的地球撞击模型；材料状态、平衡初始化和分辨率也要跟上。
- 当前回放没有完整速度与积分状态。事件后的继续计算、碎片聚集及从某帧分支，需要完整检查点。

## 开源参考与实施顺序

继续以本地 OpenSPH 为主，优先接通已有但未启用的自引力和物理量输出。可以将 [SWIFT](https://github.com/SWIFTSIM/SWIFT) 与 [Durham 的巨大撞击研究及工具](https://astro.dur.ac.uk/~vreke/giant_impacts/)作为独立参考，研究 WoMa 的分层行星初始条件与 SWIFT 的撞击算例。先做离线对照与参数研究；本轮未导入它们的代码、状态方程表或模拟数据，也未完成逐项许可审查。

1. **首批可交付内容：** 有缩略图和目标的实验卡片、岩质撞击的速度／偏移对照、土星风格外观浏览；所有卡片明确能计算到哪一步。
2. **环和近距轨道：** 局部行星中心场景、环测试粒子、近掠与扰动；校验圆轨道稳定性、能量误差及分辨率变化。
3. **可变形碰撞的可观察性：** 输出压力／内能／损伤，建立表面呈现和事件标记，增加自引力稳定与碎片再聚集基线。
4. **月球与成环研究型预设：** 分层初始条件、适用材料、角动量／质量预算、独立参考解和分辨率对照通过后再进入公开实验库。

验收既要看画面，也要看预设是否有可复现的变化：默认镜头必须看见关键事件、CLI 能重复加载同一条件、手机与展开屏能操作全部变量，物理结果不得由播放动画预先决定。本轮只完成检索、源码约束核对与上述设计，不更改 0.15.0 应用或已交付安装包。
